# Adopters

Who is using NovaFabric, and for what.

**This list is honest and it starts empty.** NovaFabric opened to outside
contributions with v0.99.0 (2026-08-05), so there is not yet a public adopter to
list. We would rather show you an empty table than a padded one — a fabricated
adopter list is the fastest way to lose the trust this project is built to provide.

If you are using NovaFabric, adding yourself here is genuinely valuable: it is the
single strongest signal to the next team evaluating whether this is safe to depend
on. It also directly shapes what gets built — see [Why we ask](#why-we-ask) below.

## How to add yourself

Open a pull request editing this file, or
[open an issue](https://github.com/MSKazemi/novafabric/issues/new/choose) and we will
add the row for you. Either is fine; a PR is faster.

You need to provide:

- **Organization** — the name you want shown, optionally linked to your site.
- **Using it for** — one line, concrete. "Capturing nightly eval runs for audit"
  beats "AI governance". Vague entries help nobody, including you.
- **Since** — a month and year, approximately. `2026-08` is fine.
- **Contact** — optional. A GitHub handle or a team alias, so other adopters can
  ask you questions. Leave it blank if you would rather not.

**Only add an organization you are authorized to speak for.** If you are unsure,
you almost certainly need to ask someone first — and we would rather wait.

### If you cannot be named publicly

That is completely normal, especially in regulated industries, and it does not make
you invisible to us. Two options:

1. **Anonymous but counted** — tell us privately (see [SUPPORT.md](SUPPORT.md)) and
   we will list a shape rather than a name, e.g. *"A European public-sector research
   computing centre — HPC job provenance — 2026-08"*. Nothing identifying, no
   approvals needed from your side beyond your own.
2. **Tell us nothing at all** — also fine. NovaFabric has no telemetry, so we
   genuinely do not know you exist unless you say so, and that is by design. You owe
   this project nothing for using it.

## Why we ask

This is not a vanity list. It changes decisions, in three specific ways:

- **It decides what stays supported.** The [support policy](docs/support-policy.md)
  and deprecation windows are set against what people actually run. A backend nobody
  listed is a backend we might drop; a backend three adopters listed is one we keep
  and test.
- **It decides what gets built next.** "Using it for" lines are the highest-signal
  input to [ROADMAP.md](ROADMAP.md) we can get — better than any survey, because it
  describes what you already did rather than what you might want.
- **It is how the next team gets approval.** Engineers evaluating a v0.x dependency
  are usually asked "who else runs this?" by someone who is not in the room. An empty
  answer stops adoption. Your row is the answer for the next person.

## What we will not do with this list

- We will **not** contact you to sell you anything. There is nothing to sell — no
  paid tier, no hosted service, no enterprise edition.
- We will **not** use your name or logo in marketing beyond this file and, if you
  explicitly agree, the project website.
- We will **not** share your contact details with anyone.

Want your entry removed, at any time, for any reason or none? Open a PR deleting the
row, or ask. It will be removed without discussion.
