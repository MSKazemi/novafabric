# Support

Thanks for using NovaFabric! Here is where to get help.

## Documentation first

Most questions are answered in the docs:

- **Getting started:** [docs/getting-started.md](docs/getting-started.md)
- **Concepts** (the five primitives, four replay modes): [docs/concepts.md](docs/concepts.md)
- **CLI reference:** [docs/cli-reference.md](docs/cli-reference.md)
- **Python API:** [docs/python-api.md](docs/python-api.md)
- **Website:** <https://novafabric.ai>
- **FAQ:** see the [FAQ section in the README](README.md#faq)

## Ask a question

- **Bugs and feature requests:** open a [GitHub issue](https://github.com/novafabric/novafabric/issues) using the relevant template.
- **Usage questions and ideas:** open a [GitHub Discussion](https://github.com/novafabric/novafabric/discussions) if Discussions are enabled, otherwise file a `question` issue.

When reporting a problem, please include:

- the NovaFabric version (`nova --version`),
- your OS and Python version,
- the exact command you ran and the full output,
- a minimal capsule or reproduction if possible.

## Security

Do **not** open public issues for security vulnerabilities. Follow the
private disclosure process in [SECURITY.md](SECURITY.md).
