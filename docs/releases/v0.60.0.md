# NovaFabric v0.60.0 — Full-CLI dashboard, streaming object store, PROV-N, OTLP/protobuf ingest

**Released:** 2026-07-16

v0.60.0 is an **additive, backward-compatible** release. Everything new is optional; there is no
Run Capsule / Asset Spec / public-CLI break — `list_objects`, `nova lineage export-prov`'s default,
and the OTLP JSON path all behave exactly as before. NovaFabric stays **record-only**: it captures,
seals, replays, diffs, and audits evidence; it never enforces, adjudicates, serves inference, or trains.

## Highlights

### Dashboard mirrors the complete `nova` CLI
- **CommandsTab now covers all 227 `nova` commands** (was ~35 hand-curated). A generated command
  registry (`web/src/components/dashboard/commands/generatedCommands.ts`), derived from the live
  Typer app by `web/scripts/gen-command-registry.py`, gives every command — including the whole
  experimental cohort (`prompt`, `label`, `annotate`, `score`, `experiment`, `session`, `kg`, `seal
  ratchet`, `energy`, `ledger`, `retention`, …) — a fillable, copyable form. Hand-curated defs still
  win for the most-used commands; the rest are auto-filled from the CLI's own parameter metadata.
  The builder stays **copy-only** (Layer C, ADR-0027) — the dashboard never executes commands. A
  filter box + per-group counts navigate the full surface, and a pytest guard
  (`tests/serve/test_command_registry_coverage.py`) fails CI if the registry drifts from the CLI.

### Object Capsule Store — streaming, bounded-memory rebuild (ADR-0175)
- **`WormAdapter.iter_objects(prefix)`** streams object keys page-by-page (default delegates to
  `list_objects`; S3/MinIO/Ceph/GCS/Azure override it with their native paginators).
  `rebuild_metadata_db` consumes it, so disaster-recovery rebuild's peak memory is bounded by the
  number of distinct `(tenant, run_id)` pairs instead of the total key count — safe for namespaces
  with millions of capsules (closes OQ-028). `list_objects` is unchanged.

### Lineage — W3C PROV-N export (ADR-0176)
- **`nova lineage export-prov --format prov-n`** emits W3C PROV-N text, rendered from the same
  PROV-JSON graph builder so both serializations describe an identical provenance graph. Default
  stays `prov-json` (no CLI-default break).

### OTel — OTLP/protobuf trace ingest (ADR-0177)
- **`POST /api/otlp/v1/traces` now accepts OTLP/protobuf** (the default OTLP encoding) alongside
  JSON, dispatched on `Content-Type` (`application/x-protobuf`). The library functions
  `otel.parse_otlp_protobuf` / `ingest_otlp_protobuf` decode the binary `ExportTraceServiceRequest`
  and reuse the JSON ingest path, so both wire encodings converge on identical events. Adds the
  optional `novafabric[otlp]` extra (`opentelemetry-proto`, Apache-2.0, ADR-0024 Tier A);
  OpenInference span mapping (NF-034) remains planned.

### Evidence Fabric — true multi-hop blast radius
- **DuckDB `query_lineage_summary` now honours `depth`**: it walks the transitive closure of
  `from_ref → to_ref` edges up to `depth` hops (default 3) via a cycle-safe recursive CTE, instead
  of ignoring `depth` and counting only direct children. Direct-neighbour (`depth=1`) results are
  unchanged, so existing callers keep their behaviour.

### Docs & examples (experimental)
- New runnable example `examples/prompt-and-analytics/` and feature-tour §22–§25 for the
  Langfuse-parity cohort (ADRs 0112–0141) — prompt lifecycle, offline analytics, session capsules +
  execution-graph reconstruction, and the team-evaluation workflow. All commands verified live.

## New ADRs

- **ADR-0175** — streaming object listing for the Object Capsule Store.
- **ADR-0176** — PROV-N text export.
- **ADR-0177** — OTLP/protobuf trace ingest.

## Upgrade

Nothing required. To use OTLP/protobuf ingest, install the extra:

```bash
pip install 'novafabric[otlp]'
```

Everything else is available on upgrade with no config or migration.
