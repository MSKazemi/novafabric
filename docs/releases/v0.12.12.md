# v0.12.12 — Lineage Hardening

Released: 2026-05-15

Three targeted hardening changes for the parent/child capsule subsystem: a
server-side lineage injection guard, cycle detection in tree assembly, and a
Prometheus observability counter for orphan-placeholder creation. All three
changes are backwards-compatible — no CLI flags, schema fields, or API
contracts changed.

---

## Security: lineage injection guard

**File:** `src/novafabric/server/routes/capsules.py`

`POST /capsules/upload` now validates `parent_run_id` on child capsules. If
the parent capsule does not yet exist in the store **and** the capsule's
`created_at` timestamp is less than 24 hours ago (the `ORPHAN_PARENT`
timeout window), the upload is rejected with:

```json
{
  "error": {
    "code": "parent_not_found",
    "message": "Parent capsule '<id>' does not exist. Upload the parent capsule first, or wait for the orphan timeout window to elapse before uploading this child."
  }
}
```

**HTTP status:** 409 Conflict.

**Why:** Without this check an adversary could `POST` a child capsule with an
arbitrary `parent_run_id` and inject synthetic lineage ancestry for a run that
never happened. The 24-hour grace window preserves the ADR-0045 fail-open
semantics for legitimate out-of-order arrival from distributed workers.

**After the window:** If `created_at` shows the capsule is older than 24 hours,
the upload is accepted and the standard `OrphanManager` placeholder path applies.
Omitted or unparseable `created_at` values are treated conservatively as "within
the window."

## Fix: cyclic lineage detection

**File:** `src/novafabric/capsule/tree_assembler.py`

`CapsuleTreeAssembler._build_node` now tracks the DFS traversal path in a
`_visiting: set[str]` variable. If a `run_id` appears in the path a second
time, the method raises `CyclicLineageError` immediately:

```python
from novafabric.capsule.tree_assembler import CyclicLineageError
```

Previously, circular `parent_run_id` references (A → B → A) triggered Python's
default recursion limit and produced an unhelpful `RecursionError`. The named
exception enables callers to handle corruption gracefully.

## Added: orphan Prometheus counter

**File:** `src/novafabric/capsule/orphan.py`

A Prometheus counter `novafabric_orphan_created_total` with label `reason` is
incremented each time `OrphanManager` creates an `ORPHAN_PARENT` placeholder.

```
novafabric_orphan_created_total{reason="pending_parent_timeout"} 3
```

The counter is **optional at runtime**. If `prometheus_client` is not installed
the import is caught silently and the counter degrades to `None` — orphan
creation continues normally and no warning is emitted.

To expose the counter, add `prometheus_client` to your environment and mount a
`/metrics` endpoint (e.g. via `prometheus_fastapi_instrumentator` alongside
`nova serve`).

---

## Upgrade notes

No action required. All changes are additive:

- Existing capsule stores are unaffected.
- The `parent_not_found` guard fires only on the server endpoint; the local
  `nova capture` path is unchanged.
- `CyclicLineageError` is a new exception class — existing `except Exception`
  handlers will still catch it.
- The Prometheus counter only registers itself if `prometheus_client` is present.
