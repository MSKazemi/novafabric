# NovaFabric v0.70.0 — 2026-07-24

**The lineage backend menu is complete and verified.** This release gives the
JanusGraph backend its first run against a live server — which surfaced and fixed
two real correctness bugs — and closes out ADR-0053's at-scale backend
progression. Everything new is `experimental`. Full detail: `CHANGELOG.md`
§[0.70.0].

## Highlights

### `JanusGraphLineageStore` — verified, and two bugs fixed

`lineage/backends/janusgraph.py` was implemented (real Gremlin traversals) but had
never been exercised against a live JanusGraph — its tests were
`NOVA_INTEGRATION`-gated. A new testcontainers parity suite
(`tests/lineage/test_janusgraph_backend.py`, against the `janusgraph/janusgraph`
image) runs it against the SQLite reference on a run-only graph and pins two fixes
the first live run surfaced:

- **GraphSON serializer.** The default GraphBinary deserializer crashes on
  JanusGraph's custom vertex-id type (`KeyError: DataType.custom`). The store now
  connects with `GraphSONSerializersV3d0`.
- **`.emit()` in `provenance` / `blast_radius`.** Without it,
  `repeat(out()).times(depth)` returned only the vertices at *exactly* `depth`
  hops — so a 3-hop chain queried at depth 5 returned nothing. It now returns all
  nodes within depth, matching the SQLite / Postgres / AGE backends.

### The at-scale lineage tier is complete

All four of ADR-0053's at-scale backends are now implemented **and**
testcontainers-verified against the SQLite reference:

| Backend | Engine | Since |
|---|---|---|
| Kuzu | embedded openCypher (benchmark-cleared) | prior |
| Postgres | recursive CTEs, plain PostgreSQL | v0.68.0 |
| AGE | openCypher, Postgres extension | v0.69.0 |
| JanusGraph | Gremlin, distributed | v0.70.0 |

There are now **zero `NotImplementedError` lineage-backend stubs**. (This corrects
the v0.69.0 note that described `janusgraph.py` as a stub — it was
implemented-but-unverified.) `SqliteLineageStore` remains the local-mode default.

## Upgrade notes

Additive — no breaking changes, no new dependencies (gremlinpython is the existing
`[janusgraph]` extra). The JanusGraph backend is run-centric (models run vertices).

## Verification

- `tests/lineage/test_janusgraph_backend.py` (4 parity tests, real JanusGraph via
  testcontainers) green; the mock-based unit tests updated to the corrected
  traversal chain; broader lineage suite (305 passed) and `make test-fast`
  (10,961 passed) unregressed. `ruff` + `mypy` clean.
