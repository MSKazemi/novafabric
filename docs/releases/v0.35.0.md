# v0.35.0 — 2026-05-20

## AIBOM / CRA Compliance Completion

### What's new

- **`nova aibom status`** — CRA SBOM compliance status: regulation name, deadline (2026-09-11),
  export format (CycloneDX ML-BOM 1.6 / ECMA-424 2nd Edition), capsule directory, and
  per-capsule AIBOM coverage (`aibom.json` present vs. total). Mirrors `nova euaiact status`.
- **`nova export-aibom --output` is now optional** — defaults to `<capsule_dir>/aibom.json`,
  allowing `nova aibom status` to track coverage without extra configuration.
- **ADR-0073 promoted Proposed → Accepted**; implementation deviations documented (stdlib JSON
  instead of `cyclonedx-python-lib`; `compliance/export/` location; evidence-fabric
  `AIBOMBundle` signing deferred to a future milestone).
- 19 new tests for the AIBOM module (`tests/compliance/test_aibom.py`).

### Upgrade notes

No breaking changes. `nova export-aibom` output path defaults to `<capsule_dir>/aibom.json`
if `--output` is omitted (previously required). Existing scripts that pass `--output`
explicitly continue to work unchanged.
