# NovaFabric v0.58.0 — Container image + Helm chart publishing

**Released:** 2026-06-25

A deployment-packaging release. NovaFabric now ships to **three install channels** from
the public repository, each cut automatically from a single `v*` tag alongside the
existing PyPI Trusted Publisher. No Python package, CLI, schema, or API behavior changes —
this release is purely about how NovaFabric is distributed and deployed.

---

## Highlights

### Container image → GHCR (+ optional Docker Hub mirror)

A new `publish-image.yml` workflow builds the runtime image (`deploy/docker/Dockerfile`)
for **`linux/amd64` and `linux/arm64`** and pushes it to **GHCR**:

```bash
docker pull ghcr.io/novafabric/novafabric:0.58.0
```

- Auth uses the built-in `GITHUB_TOKEN` (OIDC) — **no stored secret required**, mirroring
  the PyPI Trusted Publisher.
- **Docker Hub is an optional mirror** (`kazemi/novafabric`): pushed only when a
  `DOCKERHUB_TOKEN` secret is configured, so it is a no-op until opted in.
- Tags published: `:0.58.0`, `:0.58`, and `:latest`.

### Helm chart → GHCR (OCI)

A first-party Helm chart (`deploy/helm/novafabric/`) deploys `nova serve` (the
experimental read-only dashboard + REST API) backed by Postgres. A new
`publish-chart.yml` workflow lints, packages, and pushes it as an **OCI artifact** to
GHCR — one registry and one auth model for both the image and the chart:

```bash
helm install nova oci://ghcr.io/novafabric/charts/novafabric --version 0.58.0
```

Chart features:

- **Bundled Postgres** for evaluation, or **external managed Postgres** for production
  (`postgres.enabled=false` + `externalDatabase.*`).
- Optional **persistence** (PVC for capsules + registry + embedded KuzuDB) and **ingress**.
- Schema migration runs in an **init container** (`nova db upgrade … --revision v001`),
  matching the Docker entrypoint.
- **Non-root by default** (uid/gid/fsGroup 1000, `allowPrivilegeEscalation: false`, all
  capabilities dropped) — no host networking, no privileged access.

### Release safety

All three publish jobs are guarded `if: github.repository == 'novafabric/novafabric'`, so a
tag pushed to the private mirror never publishes images, charts, or packages. The PyPI
publisher gained the same guard.

---

## Upgrade notes

- No breaking changes. Existing `pip install novafabric` and Docker Compose workflows are
  unaffected.
- The experimental dashboard's access model is unchanged — front `nova serve` with TLS
  before exposing it publicly (see [`deploy/helm/novafabric/README.md`](../../deploy/helm/novafabric/README.md)
  and [the server deployment guide](../ops/server-deployment.md)).

## Try it

```bash
# Kubernetes (evaluation, bundled Postgres)
helm install nova oci://ghcr.io/novafabric/charts/novafabric --version 0.58.0
kubectl rollout status deploy/nova-novafabric
kubectl port-forward svc/nova-novafabric 4321:4321
# open http://localhost:4321/dashboard  (token in `kubectl logs`)
```
