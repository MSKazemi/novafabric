# v0.33.0 — 2026-05-20

## Regulatory Exporters: C2PA + EU AI Act

### What's new

- **`nova export-c2pa <capsule_dir>`** — C2PA v2.3-compatible provenance manifest from a
  Run Capsule (ADR-0074). Emits `c2pa.ai.generated: true` (EU AI Act Art.50 machine-readable
  disclosure), model identity, NovaSeal reference, and optional
  `c2pa.training-mining: notAllowed` assertion (`--training-mining` flag).
  Default output: `<capsule_dir>/c2pa-manifest.json`. No new runtime dependencies.
  Deadline: **2026-08-02** (EU AI Act Art.50 obligation date).

- **`nova euaiact export`** — structured Art.12 log events for authority access requests
  (Art.74). Date range filtering (`--from`/`--to` ISO-8601), `--pretty` Rich table,
  `--output` file. Event taxonomy: `interaction_timestamp`, `output_record`,
  `human_review_event`, `input_classification`. (ADR-0076)

- **`nova euaiact status`** — shows `NOVA_EUAIACT_HIGH_RISK` / `NOVA_EUAIACT_PROVIDER`
  configuration and retention floor (deployer = 6 months, provider = 120 months / Art.18).

- `is_within_retention()` in `src/novafabric/compliance/euaiact.py` for use by
  `nova pii erase` GDPR Art.17(3)(b) deferral gate.

- 35 new tests (`tests/evidence/test_c2pa_exporter.py`, `tests/compliance/test_euaiact.py`).

### Upgrade notes

No breaking changes. New env vars: `NOVA_EUAIACT_HIGH_RISK` (default: `false`),
`NOVA_EUAIACT_PROVIDER` (default: `false`). Both default to the less-restrictive
retention floor; set to `true` in production deployments as required.
