# NovaFabric v0.29.0 — KG Multi-Layer Topology + Policy UX + Rekor Integration

**Released:** 2026-05-19

## Highlights

- **KG MCPServer layer** — tool names like `filesystem:read_file` are now automatically
  split into an `MCPServer` node + `Tool` node with a `SERVED_BY` edge.  Five node types,
  four relationship types.  `nova serve` ingests `tool-calls.jsonl` automatically.
- **`GET /api/kg/topology`** — new endpoint returns the full multi-layer KG graph for
  dashboard visualization; KGTab now shows per-layer counts.
- `nova export-evidence --sigstore` is now functional — publishes the DSSE envelope to
  a Rekor transparency log after signing. Set `NOVA_REKOR_URL` to activate.
- Policy Explain panel gains live autocomplete on decision IDs via
  `GET /api/policy/recent-decisions`.
- `TraceDiffGraph` span-path stability fix.

---

## What's new

### `nova export-evidence --sigstore` (Rekor integration)

The `--sigstore` flag now works. After the Evidence Bundle is built and optionally
timestamped with RFC 3161, the DSSE envelope
(`attestations/run.intoto.json`) is extracted from the ZIP and submitted to the Rekor
transparency log.

```bash
export NOVA_REKOR_URL=https://rekor.sigstore.dev
nova export-evidence ./capsule --key keys/ed25519.pem --output evidence.zip --sigstore
# ✓ evidence bundle written: evidence.zip (18432 bytes)
# ✓ Rekor transparency log entry: 24296fb24b3c…
```

If `NOVA_REKOR_URL` is not set, the step prints a skip warning and exits 0:

```
⚠ Rekor publish skipped (set NOVA_REKOR_URL to enable)
```

Network errors are warnings only — they never fail the build (fail-open). This is
consistent with the `rekor_client.maybe_publish()` contract.

**Scope:** This ships the Rekor *publication* leg (ADR-0055 / ADR-0071 partial).
Fulcio OIDC certificate issuance (`nova seal --profile sigstore`) remains deferred
pending full ADR-0071 implementation.

### Policy Explain autocomplete (`GET /api/policy/recent-decisions`)

The decision-ID input in the Policy Explain panel now uses `SuggestInput` powered by
the new `GET /api/policy/recent-decisions` endpoint. The endpoint returns up to 50
recent decision IDs from `dashboard-audit.jsonl`, most-recent-first, deduplicated
across `audit_id`, `args.decision_id`, and `extra.decision_id` fields.

### KG MCPServer layer + multi-layer topology dashboard

The Capsule Knowledge Graph now includes a fifth node type (`MCPServer`) and a fourth
relationship type (`SERVED_BY`: Tool → MCPServer).  Auto-detection rule: tool names
containing `:` (e.g. `filesystem:read_file`, `github:search_code`) are split on the
first `:` — the left side becomes an `MCPServer` node, the right side the `Tool` node.

`nova serve` now ingests both `model-calls.jsonl` **and** `tool-calls.jsonl` on every
60-second auto-ingest tick (previously only model-calls were ingested).

`GET /api/kg/topology` returns all nodes and edges with per-type counts for graph
visualization.  The dashboard KGTab's new **Multi-Layer Topology** panel shows:
- Node counts per layer (Agent / Model / MCPServer / Tool / InferenceEndpoint)
- Edge breakdown (CALLS / USES_TOOL / SERVED_BY / ROUTES_TO)
- Auto-ingest activity indicator

### Architecture docs — Data layer quick-reference table

`design/architecture/architecture.md` now includes a compact service × property table in the Data
layer section (port, default-enabled, local-only flag) for scanning storage topology
at a glance.

## Bug fixes

- **KG auto-ingest missed tool-calls.jsonl** — `_ingest_one_capsule_dir` in `nova serve`
  previously read only `model-calls.jsonl` (or `events.jsonl`), so MCP tool-call events
  were never ingested automatically.  Now reads both files explicitly on every tick.
- **`TraceDiffGraph` span path** — path key now uses `sp.name` instead of
  `sp.span_id ?? sp.name`. Span IDs are not stable across re-runs; using the span name
  keeps diff labels consistent.
- **`export_evidence.py` mypy** — `cfg: dict` → `cfg: dict[str, str]` in the GDPR
  RoPA command (line 509) resolves a `[type-arg]` mypy warning.

---

## Upgrade notes

No breaking changes. No new required environment variables.

To activate Rekor publication: set `NOVA_REKOR_URL` (e.g. `https://rekor.sigstore.dev`
for the public Sigstore instance, or your private Rekor endpoint).
