# v0.48.0 — Dashboard 10x: faster, more reliable, more scalable

**Released:** 2026-06-12

`nova serve` dashboard sprint focused on four axes: performance, reliability,
scalability, and UX. No breaking changes; no schema or CLI changes.

## Highlights

### Frontend performance
- **All 20 tabs are code-split** with `React.lazy`/`Suspense` — each tab is its
  own JS chunk, loaded on first navigation. Initial bundle parse time drops
  accordingly (20 separate chunks confirmed in the build).
- **`usePolling` hook** replaces ad-hoc `setInterval` patterns; polling pauses
  when the tab is hidden and resumes on focus, avoiding wasted requests and
  stale-closure bugs. Wired into app auto-refresh, InfraTab (5 s), HomeTab (30 s).

### Reliability
- **Per-tab `ErrorBoundary`** — a crash in one tab no longer takes down the
  whole SPA; the tab shows a "Reload tab" button instead.
- **Managed SSE reconnect** — `openManagedRunStream` wraps the bare
  `EventSource` in RunsTab: hard failures (token expiry, long outages) now
  reconnect with capped exponential backoff (1 s → 30 s), and live connection
  state is reported to the UI.
- **Bounded fetches** — PolicyTab `listAssets`/`listRuns` capped at 500 rows.

### Backend scale
- **`/api/assets` is SQL-paginated** — new `list_assets_paginated()` in
  `registry/service.py` does `LIMIT`/`OFFSET` + `COUNT` + column projection
  (omits the `spec_json` blob) instead of fetching every row into Python.
- **Composite index `(status, created_at DESC)`** on `runs_cache` speeds up
  filtered + time-ordered run queries.
- **`_StatsCache.get_or_compute()`** — double-checked locking so concurrent
  cold-cache `/api/stats` requests compute once, not N times.
- **Cache-first reports** — `report_run_history` / `report_cost_burn` query the
  `runs_cache` index first and fall back to the capsule filesystem scan only
  when the cache is empty or unavailable.

### UX
- **Command palette (⌘K / Ctrl+K)** — fuzzy keyboard navigation across all 20
  tabs and actions.
- **`Skeleton` loading component** for consistent placeholders; SchemaTab gains
  loading and error-with-retry states.

### Type-integrity fix (web)
The web typecheck gate had been silently broken: under TypeScript 6 the
deprecated `baseUrl` option aborts `tsc` with a config error *before any
type-checking runs*, masking 8 real type errors. This release migrates `paths`
off `baseUrl`, widens `request()`'s query parameter to
`Record<string, unknown>` (values were already stringified internally), and
fixes `unknown`-into-JSX leaks plus an unsound `coverages` assignment in
`ComplianceTab`. `tsc --noEmit` is green again, and the static dashboard bundle
is rebuilt and synced.
