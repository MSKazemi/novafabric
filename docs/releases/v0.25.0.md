# v0.25.0 — C-Tier Compliance Audit Sprint

Released: 2026-05-19

This release closes the v0.25.0 C-tier compliance documentation track: 9 new
Architecture Decision Records (ADRs 0069–0077) based on 6-domain regulatory
research, 12 compliance reference documents, and a schema correctness fix for
OQ-021. The KG Tier-2/3 entity resolution stack is migrated from PostgreSQL to
SQLite (no extra dependency for local mode). Two urgent regulatory deadlines
were identified during research and elevated to the v0.26.x backlog.

Test suite: **3 473 passed, 59 skipped** (exit 0).

### OQ-021 fix — lineage edge schema

`schemas/lineage-edge.schema.json` `edge_type` enum locked to the Phase 3
four-type vocabulary (`contains`, `spawned`, `delegated_to`, `replayed_from`).
Legacy strings (`consumed`, `produced_by`, `derived_from`, `evaluated_by`,
`attested_by`, `depends_on`) are now documented in `x-deprecated-values` and
must not appear in new records. Existing records are coerced at read time by
`coerce_legacy_edge_type()` (unchanged).

### KG Tier-2/3 — SQLite migration

`AliasTableResolver` and `HumanReviewQueueWriter` migrated from PostgreSQL to
SQLite (stdlib, no extra dependency). Local-mode KG resolution now requires no
external database. Heuristic version-stripping (date suffix, `-vN`, vendor
prefix) added to alias resolution. REST endpoints added to `nova serve`:

- `GET /api/kg/entity-queue` — list pending human review items
- `GET /api/kg/alias/{alias}` — resolve a single alias
- `POST /api/kg/alias` — create or update an alias entry

## Upgrade notes

- `pyproject.toml` version bumped to `0.25.0`.
- `schemas/lineage-edge.schema.json` is a breaking schema change for any
  producer that still emits legacy edge types. The `coerce_legacy_edge_type()`
  coercion layer at read time is unchanged; existing JSONL files remain
  readable.
- KG Tier-2/3 SQLite databases default to
  `<NOVAFABRIC_HOME>/.nova/kg/alias.db` and
  `<NOVAFABRIC_HOME>/.nova/kg/review_queue.db`. Override via
  `NOVA_KG_ALIAS_DB` and `NOVA_KG_QUEUE_DB` env vars.
