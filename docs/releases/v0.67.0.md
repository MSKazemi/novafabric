# NovaFabric v0.67.0 — 2026-07-24

**The `@novafabric/sdk` evidence lane.** The TypeScript SDK (ADR-0194) had one
lane its README flagged as planned — evidence helpers. This release ships it.
Everything new is `experimental` and additive. Full detail: `CHANGELOG.md`
§[0.67.0].

## Highlights

### Evidence-bundle helpers in the TypeScript client

Three typed methods over the `/v0` evidence surface, matching the existing
client's fetch-thin, zero-dependency style:

```ts
// Build a signed Evidence Bundle, wait for it, then download the ZIP bytes.
const { data: bundle } = await client.exportEvidence({
  run_id: "run-01H...",
  allow_unsafe_skips: false,
});
const { data: zipBytes } = await client.downloadEvidenceBundle(bundle.bundle_id);
// zipBytes is a Uint8Array — write it to disk, or wrap it in a Blob in the browser.
```

- `exportEvidence(request)` — `POST /evidence`, returns the `202` `BundleSummary`
  (requires the `writer` role server-side).
- `getEvidenceBundle(bundleId)` — `GET /evidence/{bundle_id}`, metadata poll for
  when the bundle is on disk (`auditor` role).
- `downloadEvidenceBundle(bundleId)` — `GET /evidence/{bundle_id}/download`,
  returns the ZIP as a `Uint8Array` (the body is `application/zip`, not JSON).

New exported types `EvidenceExportRequest` and `BundleSummary`, generated from
`api/openapi.yaml`. Errors still map to the typed `NovaFabricApiError`;
deprecation/sunset headers still surface on every result's `meta`.
