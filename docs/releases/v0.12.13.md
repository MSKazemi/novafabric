# v0.12.13 — Security Test Suite

Released: 2026-05-15

Adds the regression test suite for the three v0.12.12 security/hardening
changes and corrects the `pyproject.toml` version field, which was not bumped
in the v0.12.12 commit.

No source code, schema, CLI, or API changes from v0.12.12.

---

## Added: security regression tests

Four new pytest cases validate the P0 hardening shipped in v0.12.12.

### Lineage injection guard (Cap-6, `test_server_routes.py`)

**Test 1 — injection blocked within window**

```
TestCapsules::test_upload_child_with_missing_parent_within_window_returns_409
```

Uploads a child capsule with a fresh `created_at` and a `parent_run_id` that
does not exist in the store. Asserts HTTP 409 with error code `parent_not_found`.

**Test 2 — golden path**

```
TestCapsules::test_upload_child_after_parent_uploaded_succeeds
```

Writes the parent capsule directly to the capsule directory, then uploads the
child. Asserts HTTP 201 and correct `run_id` in the response body.

**Test 3 — fail-open after orphan timeout (ADR-0045)**

```
TestCapsules::test_upload_child_after_orphan_timeout_elapsed_succeeds
```

Sets `created_at` to `2020-01-01T00:00:00+00:00` (well beyond 24 h). The
upload succeeds with HTTP 201 even though the parent is absent, preserving the
fail-open semantics required for distributed worker environments.

### Cycle detection (Cap-7, `test_tree_assembler.py`)

**Test 4 — circular reference raises named exception**

```
test_cyclic_parent_reference_raises_cyclic_lineage_error
```

Writes two capsule manifests where A claims B as parent and B claims A as
parent. Calls `CapsuleTreeAssembler.assemble_tree(A)` and asserts that
`CyclicLineageError` is raised. Previously this would have hit Python's default
recursion limit and produced an opaque `RecursionError`.

## Fixed: pyproject.toml version

`version = "0.12.11"` → `"0.12.13"`.

The v0.12.12 commit tagged the security hardening without updating
`pyproject.toml`, leaving the file one minor version behind the tag. This patch
realigns both.
