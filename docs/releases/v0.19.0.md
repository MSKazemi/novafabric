## Feature details

### `KGInitPanel` + `KGIngestPanel` (KGTab)

- **Init**: one-click button → `POST /api/kg/init`. Shows db_path. Idempotent — safe to run multiple times.
- **Ingest**: path input (with SuggestInput autocomplete) + "NovaSeal verified" toggle → `POST /api/kg/ingest`. Shows ingested/skipped/written event counts. Degrades gracefully if `novafabric[scale-kg]` is not installed.

### `NewRunIdPanel` (AdminTab)

- Generates a fresh ULID via `GET /api/admin/new-run-id`.
- Two copy buttons: copy the raw ID, or copy the full `NOVAFABRIC_GLOBAL_RUN_ID=<ulid> nova capture ...` shell command.

### `DatabaseOpsPanel` (AdminTab)

- CLI reference cards with copy buttons for three maintenance commands.
- Useful when the user needs to run migrations or a metadata rebuild without switching to the terminal.

### `ValidateDistributedBlock` (RunsTab)

- Shown for parent capsules with `capsule_type == "parent"`.
- Lists all worker run IDs as clickable chips (jumps to that worker's capsule detail).
- "Validate distributed run" button → `POST /api/runs/{id}/validate-distributed`. Shows green/red result with status and message.
- CLI hint: `nova validate-distributed {run_id}`.

### `CostTab` (DB-COST-1)

- Report panel: run_id (optional) + window-in-days form → `/api/cost/report`.
- Backend badge: green "clickhouse" when `NOVA_CLICKHOUSE_URL` is set, yellow "stub" otherwise.
- Price table: read-only `CostInterceptor.PRICE_TABLE` per-1k-token prices for six models.

### `SchemaTab` (DB-SCH-1)

- 25 `CapsuleEventType` values grouped into 9 categories.
- `RunEnvelope` and `CostFacet` Pydantic field chips.
- Copy-button on the JSON Schema path.
