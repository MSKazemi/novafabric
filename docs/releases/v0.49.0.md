# v0.49.0 — SOTA gap-closure Wave 1

**Released:** 2026-06-12

Six capabilities identified by the 2026 SOTA landscape sweep land in one
release, integrated from six parallel work streams. Five new ADRs (0081–0085)
plus ADR-0080 promoted to Accepted. Everything is additive — no breaking CLI,
API, or schema changes.

## Highlights

### `nova promote --significance-gate` (gap-004, ADR-0080 → Accepted)
Promotion can now be gated on a *statistically significant* eval regression
instead of a single passing eval: a Wald SPRT over the asset's recent pass/fail
sequence blocks only on `ACCEPT_H1`. Noise (`ACCEPT_H0`) and inconclusive
evidence (`CONTINUE`) never block, so a single-run dip cannot fire the gate.
Opt-in; the legacy gate is unchanged when the flag is omitted; `--force`
bypasses. Defaults `p0=0.9, p1=0.7, alpha=0.05, beta=0.05`.

### CloudEvents v1.0 envelope interop (gap-009, ADR-0081)
`novafabric.envelope.to_cloudevents()` / `from_cloudevents()` map an
`EventEnvelope` to/from CloudEvents structured-mode JSON, so evidence events
route through any CloudEvents-aware broker (Kafka/NATS/HTTP) without body
parsing. Extension attributes (`novarunglobal`, `novarun`, …) match the shipped
Go collector byte-for-byte, so Python↔Go round-trips on the same topic.

### Extended span taxonomy (gap-011, ADR-0082)
Eight new `CapsuleEventType` members — `StateTransition`, `MemoryOperation`,
`GuardrailEvaluated`, `EvaluatorScored`, `RerankerApplied`,
`VectorRetrievalStarted/Completed/Failed` (25 → 33) — with matching Pydantic
event models. Append-only and backward-compatible; raw content fields stay
opt-in per ADR-0021.

### Hot in-memory lineage impact index (gap-013, ADR-0083)
An optional materialized adjacency index over lineage edges for O(1)
blast-radius/impact lookups on hot paths, kept in sync by the store.

### `nova diagnose` failure attribution (gap-006, ADR-0084)
`nova diagnose <run-id>` ranks the most likely responsible step for a failed
run by walking the lineage/causal graph. Read-only analysis layer; scores are
relative ranking weights, not calibrated probabilities.

### Sealed system cards + eval version pinning (gap-014, ADR-0085)
`nova export-system-card <capsule_dir>` generates a system/audit card from
capsule + eval + lineage facts and seals it via the existing DSSE/Ed25519 path
(predicate `https://novafabric.io/system-card/v0`). `run_evals` now pins the
resolved asset version (and optional `dataset_version`) into every eval result.

### Web test salvage
The dashboard-10x agent worktrees' e2e contract tests were adapted to the
shipped v0.48.0 API and landed: backoff math extracted into an exported pure
`nextBackoffDelay()` + `RUN_STREAM_BACKOFF` tunables (semantics unchanged),
10 tests covering backoff math, reconnect lifecycle, and the ErrorBoundary
contract.

## Integration notes
This release resolves a five-way ADR numbering collision: five parallel agents
each claimed ADR-0081. Renumbered in integration order — 0081 CloudEvents,
0082 span taxonomy, 0083 lineage index, 0084 failure attribution, 0085 system
card. The deferred D3c virtualization work (incomplete — depends on a
never-created `lib/format` module) is preserved as a patch in the local plans
directory.
