# v0.4.2 — Cluster-Scale Architecture + Quality Hardening

Released: 2026-05-08

## What's new

### Architecture documentation

Three new ADRs and one new architecture document establish the design intent for
cluster-scale, AI-factory, and HPC deployments. These are design commitments, not
implemented features — they prevent architectural dead ends in v0.6 and beyond.

- **[ADR 0020 — Low-overhead cluster capture](../decisions.md)**
  and the **Cluster-scale design document**
  codify the two-plane architecture: compute nodes emit minimal evidence; dedicated
  service nodes handle heavy processing.

- **[ADR 0021 — AI-factory design intent](../decisions.md):**
  Eleven numbered design principles governing every cluster-scale component —
  reliability and ingestion, federation topology, consistency model, privacy by default,
  self-observability, cost/overhead budgets, schema evolution, testing discipline,
  anti-patterns, deployability, and a twelve-question definition-of-done checklist.

- **[ADR 0022 — Polyglot persistence and object storage](../decisions.md):**
  Commits object storage (S3/MinIO/Ceph/Lustre/POSIX) as the source-of-truth for raw
  capsules at cluster scale. Metadata and lineage indexes are derived views, rebuildable
  from raw capsules if lost. Local filesystem remains correct through v0.x.

- **[ADR 0023 — Cache architecture](../decisions.md):**
  Establishes the L0–L4 hierarchical content-addressed cache model. Compute-plane code
  touches L0 (process-local) and L1 (node-local daemon) only. Mutable cache keys must
  include schema version, policy version, and tenant context. LLM-specific caches
  (prompt, semantic, prefix, KV) are deferred and require their own ADR before shipping.

### Quality

- **mypy clean:** Removed two stale `# type: ignore[import-untyped]` comments from
  `lineage/_openlineage.py` and `lineage/_writer.py`. `types-PyYAML` (already a dev
  dependency) now provides stubs, making these annotations false positives. `mypy src/`
  now returns `Success: no issues found in 61 source files`.

- **End-to-end smoke test:** `tests/test_smoke_capture_validate.py` exercises the full
  golden path — `nova capture` → capsule on disk (8 structure and content assertions) →
  `nova validate` exits 0 — with no mocking. If the capture → validate path ever drifts,
  this test fails loudly. Test count: 325 → 333.
