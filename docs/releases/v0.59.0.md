# NovaFabric v0.59.0 — Supply-chain provenance, evidence-grade eval & the Security/Provenance Knowledge Graph

**Released:** 2026-07-15

v0.59.0 is an **additive, backward-compatible** release. Everything new is optional and most of it
is labeled **experimental** (API may change). No Run Capsule / Asset Spec / public-CLI break; every
new capability is off unless you opt in. NovaFabric stays **record-only** — it captures, seals,
replays, diffs, and audits evidence; it never enforces, adjudicates, serves inference, or trains.

## Highlights

### Supply-chain & dataset provenance (experimental)
- **NF-058 — signed dataset provenance cards** (`nova dataset provenance-card <asset> --sign`, ADR-0105):
  records `source`/`version`/content-`hash`/`license`/`tlp` plus a content-addressed **transform history**
  (operation digests only — never raw values, prompts, or cell contents). `--from-capsule` derives the
  history from a capsule's `lineage.jsonl` derivation edges. Ed25519-signed on the NovaSeal keyring; an
  unsigned card is schema-invalid (not evidence).
- **NF-057 — SLSA-for-ML promotion provenance** (`nova promote direct --slsa-provenance --slsa-ml-profile`,
  ADR-0105): extends the SLSA emitter with the ML profile — `buildType https://novafabric.dev/promote-ml/v1`,
  dataset versions/hashes + seeds + eval-container digest, and an **`eval-verdict` digest** binding the
  promoted model to the exact gating eval verdict. DSSE-signed and `nova verify-envelope`-verifiable.
- **NF-056 — AI-BOM CycloneDX 1.7 extensions**: emit an AI bill-of-materials with NovaFabric provenance.
- **Standard outer envelopes**: DSSE/in-toto outer-envelope binding for evidence artifacts.

### Evidence-grade evaluation (experimental)
- **NF-028 — dataset-provenance facet + `nova eval contamination-check`**: records the dataset + split
  content hashes an eval ran against, so a capsule can be flagged when a benchmark version is superseded
  or contaminated (contamination silently inflates scores).
- **Trace-first zero-token offline eval** (`nova eval offline`): re-score recorded capsules without
  re-running the model.
- **Statistical regression diff** (`nova diff --significance`): significance-tested score comparison;
  `nova promote direct --significance-gate` can source from `scores.jsonl` (NF-007).
- **NF-009 — metamorphic check-spec CLI**.

### Security & Provenance Knowledge Graph — SPKG (experimental)
- A knowledge-graph layer over capsules/evidence for attack-path and provenance queries, with build,
  detect, and entity-resolution commands and a `/kg/detect` serve endpoint.

### Observability & lineage (experimental)
- **NF-032/033 — OTel GenAI canonical-span emitter** + opt-in content bridge.
- **NF-036 — OpenLineage custom run facets**.

### Ecosystem & repository
- **NovaFabric Claude Code plugin** (`integrations/claude-plugin/`) — a distributable plugin with
  deploy/instrument skills.
- **Repo discoverability / LLM-SEO pass** — crawlable public repository and answer-engine metadata.
- **Positioning** reframed from "self-contained" to "self-hosted, runs from laptop to cluster".
- **Dependency advisories** patched across all three ecosystems (Dependabot).

### New commands & endpoints (2026-07-15 additions, experimental)
- **`nova pii status <capsule>`** — read-only per-capsule PII encryption/erasure report against the
  DEK store (closes the CLI reference's long-standing `planned` gap).
- **`nova comment add | list`** — append-only capsule comments (ADR-0121 first slice): annotations
  live beside the sealed evidence, never mutate it; secrets are refused at the gate.
- **`nova evidence attest-replay --certify / --anchor`** (Spine-B2, ADR-0094) — DSSE-signed
  determinism certificate + accountability-ledger anchoring for replay attestations.
- **`nova export --html <capsule>`** — single-file, fully offline capsule viewer (ADR-0140 P1+P2):
  zero external references, redaction markers preserved.
- **`nova diagnose --intervene`** (ADR-0101 first slice) — hypothesis-verifying counterfactual
  replay loop: CONFIRMED / REFUTED / INCONCLUSIVE verdicts, never guessed.
- **`nova eval import-inspect / export-inspect`** (NF-024) — score-level Inspect-AI eval-log bridge,
  pure stdlib, honesty ledger for unmapped/omitted fields.
- **`POST /api/otlp/v1/traces`** (NF-034) — OTLP/HTTP JSON GenAI-span ingest → valid Run Capsule,
  for agents instrumented with vanilla OTel GenAI SDKs.
- **Capture-overhead CI gate** — pytest-benchmark p95 < 2000 ms gate on the fast-emit capture path
  (`make benchmark-capture`, `capture-overhead-gate` CI job).

### Langfuse-parity cohort — first six slices (2026-07-15 additions, experimental)
- **`nova prompt register|get|list|history|diff`** (ADR-0112) — prompts as immutable,
  content-addressed registry versions with a replay-verifiable
  `prompt:<id>@<version>+sha256:<hex>` reference; zero registry schema change.
- **`nova query`** (ADR-0129) — offline metrics query DSL over a local capsule dir (filters +
  count/sum/avg/percentile aggregations, group-by; DuckDB with SQLite fallback, byte-identical
  results); no server, read-only.
- **Pluggable PII masking pipeline** (ADR-0135) — `nova capture --masker/--masking-config`,
  `novafabric.maskers` entry-point plugins running after the built-in ADR-0009 scanner;
  fail-closed registration, crash/hang/leak containment, findings recorded in the redaction proof.
- **Lifecycle event webhooks** (ADR-0137) — `nova events tail|emit`, strictly opt-in
  `NOVA_EVENTS_*` file/webhook sinks, HMAC-signed payloads with IDs/digests only (never content),
  fail-open with bounded retries; `capsule.created`/`capsule.validated` wired.
- **`deployment_environment` capsule field** (ADR-0126) — `nova capture --environment` /
  `NOVAFABRIC_ENVIRONMENT` / SDK arg; additive-optional schema change, absence changes nothing.
- *(plus `nova comment` (ADR-0121) and `nova export --html` (ADR-0140) listed above.)*

### Langfuse-parity cohort — five more slices (wave 6, experimental)
- **`nova label protect|propose-move|approve-move|status`** (ADR-0114) — protected deployment
  labels: direct `set` refused; moves require two distinct Ed25519 principals (SoD at the crypto
  level via the ADR-0058 keyring), optional Rego gate, append-only audit.
- **Observation log levels** (ADR-0127) — additive `log_level`/`status_message`/`log_level_source`
  on model + tool calls, write-time domain gate, OTLP error-span mapping, `nova query` filter.
- **Tool-call schema validation** (ADR-0128) — record-only verdicts at capture when a schema ref
  is declared, `schema_drift` at replay (exact mode hard-refuses), `nova validate --schemas`
  with optional CI gate; local-only schema resolution, never fetches.
- **Local model-pricing catalog** (ADR-0133) — `nova pricing list|show|add` + `nova cost estimate`:
  layered, effective-dated per-usage-type prices; recorded cost never overwritten; estimates
  labeled with catalog digest.
- **Batch capsule blob export** (ADR-0141) — `nova export-blob` to local dir or any S3-compatible
  store: content-addressed resumable writes, one DSSE-signed export manifest written last,
  offline `nova verify <manifest>` returns VALID/INCOMPLETE/INVALID.

### Suite health & correctness (2026-07-15)
- Full test suite now runs **parallel in ~2 min** (`make test-par`; `make test-fast` ~90 s dev tier)

## Compatibility & honesty
- **Additive only** — absence of any new facet/field leaves prior behavior unchanged.
- **Experimental** features may change API before stabilizing; treat their schemas as v0.
- **Record-only / fail-open** preserved throughout; secrets are never captured (content-addressed
  digests only).
- Design/ADR governance for future-design programs (NF-001..400) lives in the private design tree and
  is **not** shipped by this release.
