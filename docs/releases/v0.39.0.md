# Release notes — v0.39.0 (2026-05-20)

## CycloneDX ML-BOM upgrade: 1.6 → 1.7 (ECMA-424 2nd Edition)

### What's new

`nova export-aibom` now emits **CycloneDX ML-BOM 1.7** (ECMA-424 2nd Edition,
October 2025) instead of 1.6. This upgrade is required to satisfy the EU Cyber
Resilience Act (CRA) SBOM obligation ahead of the 2026-09-11 deadline.

### Changes in the emitted BOM

| Field | Before (1.6) | After (1.7) |
|---|---|---|
| `specVersion` | `"1.6"` | `"1.7"` |
| `metadata.tools` | Array (`[{name, version}]`) | Object (`{components: [{type, name, version}]}`) — required by CycloneDX ≥ 1.5 |
| `metadata.lifecycles` | absent | `[{phase: "post-build"}]` — documents BOM lifecycle phase |
| `modelCard.limitations` | absent | Populated from capsule `limitations` field — supports CRA Art.9 disclosure |
| Dataset components | absent | `type: "data"` components from capsule `lineage_datasets` — CRA dataset provenance |
| Tool version | `"unknown"` | Reflects installed `novafabric` package version |

### Compliance context

- **EU CRA Art.9** — `modelCard.limitations` satisfies the disclosure obligation for
  known model restrictions in AI-enabled products.
- **CRA SBOM deadline** — 2026-09-11. `nova export-aibom` is CRA-ready with 1.7.
- The `metadata.tools` array format from CycloneDX 1.6 is deprecated in 1.5+ and
  removed in 1.7. This upgrade resolves that breakage for strict validators.

### Tests

9 new tests in `TestAIBOMExporterV17`; **28 total AIBOM tests**, all green:
`test_spec_version_is_1_7`, `test_export_json_spec_version_1_7`,
`test_metadata_tools_uses_components_object`, `test_metadata_tools_component_has_type_field`,
`test_metadata_lifecycle_phase_present`, `test_model_card_limitations_from_capsule`,
`test_dataset_components_from_lineage_edges`, `test_tool_version_matches_package`,
`test_backwards_compat_no_limitations_field`.

### Upgrade

No breaking changes to the CLI interface. The only change is the emitted JSON
structure, which is now CycloneDX 1.7 compliant.

```bash
pip install --upgrade novafabric
nova export-aibom <capsule_dir>   # now emits CycloneDX ML-BOM 1.7
nova aibom status                 # "ML-BOM v1.7" in status line
```

If downstream tooling validates against CycloneDX 1.6 schema only, update it
to accept 1.7. CycloneDX 1.7 validators will accept this output.
