# NovaFabric v0.62.0 — 2026-07-17

The audit-closure release. A full-repo enterprise audit (2026-07-16) was executed
end-to-end: confirmed defects fixed, scalability paths hardened, the
documentation drift closed, five follow-up ADRs (0191–0195) accepted and their
first slices shipped, and the dependency backlog triaged across all three
ecosystems. Everything new is labelled `experimental` unless stated otherwise.
Full detail: `CHANGELOG.md` §[0.62.0].

## Highlights

### New enterprise surfaces (ADRs 0191–0195, first slices)
- **SIEM egress** — `nova audit-log export` renders the local audit logs in
  OCSF or native JSONL with deny-by-default redaction and in-walk hash-chain
  verification (tamper evidence sets exit 3). Your shipper does transport.
- **Operational alerting** — an `ops.*` event family (quota breach, sustained
  rate limiting, policy violation, drift, seal-verify failure, backup failure)
  over the existing lifecycle-webhook emitter: dedup windows, severity routing,
  per-endpoint allowlist, default OFF; `ops.quota.breached` wired first.
- **API keys** — `nova server api-key create|list|revoke`: `nvfk_`-prefixed,
  hashed-only, shown once, scoped by the existing RBAC roles, audited, with a
  secret-scanner rule for our own credential.
- **TypeScript SDK** — `@novafabric/sdk` (`packages/nova-sdk-ts`): types
  generated from `api/openapi.yaml` with a CI drift gate, a
  zero-runtime-dependency `fetch` client with typed pagination and error
  envelope, and RFC 9745/8594 deprecation-header surfacing.
- **FIPS 140-3 posture** — `SECURITY.md` now answers the question precisely:
  no product claim (modules are validated, not applications), a tree-verified
  crypto inventory, the validated-module recipe, and the Ed25519 caveat.

### Audit defect fixes & scalability (shipped on main since v0.61.0)
- Dashboard SSE new-run feed no longer breaks past 10,000 indexed runs
  (watermark tracker); topology WebSocket backpressure is an explicit
  drop-oldest policy; collector health can no longer be spoofed via `/tmp`;
  fail-open capture loss is now visible (`capture-health.json`).
- Bounded-memory run-file serving (`NOVA_SERVE_MAX_FILE_BYTES`, default 5 MB);
  keyset cursor pagination on `/api/runs`; batched query-index build; a nightly
  CI tier now exercises the previously always-skipped Postgres/MinIO
  scale-and-concurrency tests with real services.
- New dashboard **Analytics tab**: run volume + failure stacked bars, duration
  p50/p95 lines, stat tiles, 7/30/90-day ranges, chart/table toggle — backed by
  `GET /api/analytics/summary` (server-side day-bucket aggregates).

### Documentation
- 26 previously undocumented top-level commands added to the CLI reference with
  a CI drift guard; ten new docs (monitoring, encryption-at-rest, quotas/rate
  limits, trust surfaces, drift gate, assurance cases, sizing, upgrade,
  incident runbook, air-gapped install).

### Security & supply chain
- `mcp` 1.28.1 (3 HIGH CVEs closed), `setuptools` 83, `vite` advisory fixed,
  Go toolchain 1.26.5 (govulncheck: 0 affecting findings);
  `api/openapi.yaml` dangling `$refs` fixed.

## Upgrade notes

- All new surfaces are additive and off/opt-in by default; no CLI, schema, or
  API break. The Go collector now builds with Go ≥ 1.26.
- Security-Architect review remains a **pre-production blocking condition**
  for ADRs 0178/0184/0185/0186; ADR-0193 (API keys) carries the same
  recommendation.
