# NovaFabric v0.69.0 — 2026-07-24

**The Apache AGE lineage backend, implemented.** `AGELineageStore` — the third
of ADR-0053's at-scale backend options — was a `NotImplementedError` stub. It is
now real and parity-proven. Everything new is `experimental` and additive. Full
detail: `CHANGELOG.md` §[0.69.0].

## Highlights

### `AGELineageStore` (ADR-0053) — openCypher over Postgres

`lineage/backends/age.py` stores the lineage graph as an Apache AGE property
graph (`LNode` vertices, `LEDGE` relationships) and answers `provenance`,
`blast_radius`, and `replay_chain` with openCypher variable-length paths.

- **Parity-proven.** A testcontainers suite (`tests/lineage/test_age_backend.py`,
  against the `apache/age` image) loads the same graph into AGE and the SQLite
  reference and asserts identical query answers — including depth bounds and
  replay-chain step ordering. Skips cleanly when Docker / testcontainers is
  unavailable.
- **Idempotent `MERGE` inserts**; the graph name is created once per store.
- **Zero new dependencies** — psycopg is the existing `[server]` extra.

### The at-scale lineage tier now has three working backends

- **Kuzu** (embedded, openCypher) — the accepted production backend, benchmark
  cleared (ADR-0053, p99 45.5ms at 10M edges).
- **Postgres** (recursive-CTE, plain PostgreSQL) — v0.68.0.
- **AGE** (openCypher, Postgres extension) — this release.

Only `lineage/backends/janusgraph.py` remains a stub; it needs a JanusGraph /
gremlin server and is redundant given the three working backends.
`SqliteLineageStore` remains the local-mode default.

### AGE implementation notes (for future maintainers)

AGE's openCypher subset differs from Kuzu's: the graph name must be a SQL
*literal* in `cypher()` (not a bound parameter); cypher parameters pass as a
single `%s::agtype` JSON argument referenced as `$name`; AGE has no
`all(r IN relationships(p) ...)` predicate, so `replay_chain` walks one
property-filtered hop at a time (bounded, cycle-guarded); and results come back
as `{...}::vertex` agtype strings, parsed by stripping the `::vertex` suffix and
`json.loads`.
