# v0.27.0 — Full CLI-to-Dashboard Parity

Released: 2026-05-19

All CLI commands now have interactive dashboard panels. This release adds 11
new backend endpoints and corresponding frontend panels covering the remaining
CLI surfaces that had no UI equivalent.

---

## What's new

### SealTab — bypass SoD via the dashboard (`nova seal bypass`)

A `BypassSodPanel` is added to `SealTab`. Users can submit a capsule ID,
reason, and expiry date to trigger `POST /api/seal/{capsule_id}/bypass` and
create a time-limited, DSSE-signed SoD override with a permanent audit trail
— the same operation previously only reachable via `nova seal bypass`.

### AdminTab — role assignment and revocation

`assignRole` and `revokeRole` forms are wired into `AdminTab`. The backing
REST routes (`POST /v0/admin/roles`, `DELETE /v0/admin/roles`) were shipped in
v0.14.3; this release adds the frontend forms that make them reachable without
the CLI.

### AdminTab — JWKS cache flush (`nova server flush-jwks`)

A "Flush JWKS Cache" button calls `POST /api/admin/flush-jwks-cache`. This
was previously a server-only maintenance step with no UI equivalent.

### AdminTab — DB upgrade (`nova db upgrade`)

A "Run DB Upgrade" card calls `POST /api/db/upgrade` and displays the
migration outcome inline. Previously only reachable via `nova db upgrade`.

### AdminTab — capsule format migration (`nova capsule-migrate`)

A capsule migration panel calls `POST /api/capsule-migrate` with a capsule
path and target schema version and shows the result inline.

### RegistryTab — spec validation (`nova validate-spec`)

`ValidateSpecPanel` calls `POST /api/validate-spec` with a pasted or uploaded
asset spec YAML/JSON and returns a structured validation report (errors and
warnings) rendered in-place.

### RegistryTab — asset report (`nova report`)

`ReportPanel` calls `GET /api/report` and renders the full asset registry
summary report, previously only accessible as `nova report` CLI output.

### InfraTab — MCP risk report (`nova mcp risk-report`)

`MCPRiskReportPanel` calls `POST /api/mcp/risk-report` with an MCP server
manifest and renders the structured risk score, finding counts, and remediation
guidance — distinct from the existing MCP scan panel (which runs the scanner)
and now surfacing the detailed risk-report view.

### RunsTab — capsule delete (`nova capsule delete`)

A delete button on each run row calls `DELETE /api/runs/{run_id}`. A
confirmation dialog prevents accidental deletion. Previously only reachable via
the CLI.

### LineageTab — lineage import (`nova lineage import`)

`LineageImportPanel` calls `POST /api/lineage/import` with a lineage file path
or uploaded JSON-LD document and reports import status and edge count.

### GovernanceTab — eval comparison (`nova eval compare`)

`EvalComparePanel` calls `POST /api/eval/compare` with two run IDs and renders
a side-by-side comparison of eval suite scores, regression flags, and metric
deltas.

## Upgrade notes

No breaking changes. No new dependencies. Drop-in replacement for v0.26.5.

All 11 new endpoints are local-mode compatible — they do not require Postgres
or any external service. Endpoints that touch optional subsystems (e.g., KMS,
external JWKS providers) return `{ok: false, backend: "stub", reason: "..."}` 
when the relevant backend is not configured.
