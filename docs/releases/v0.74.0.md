# NovaFabric v0.74.0 — 2026-07-25

**A security review of the envelope-encryption + cloud-KMS surface — and the one
real bug it found, fixed.** ADR-0185 lists a Security-Architect review as a
pre-production blocking condition; this release records a rigorous delegated-
authority audit of that surface and ships the fix it surfaced. `experimental`.
Full detail: `CHANGELOG.md` §[0.74.0].

## Highlights

### Cloud-KMS unwrap failures now surface a clean `DekUnwrapError`

The audit found a real robustness gap introduced by the v0.71–v0.72 cloud-KMS
wrap backends. `decrypt_blob` caught only `cryptography.InvalidTag` around
`kms.unwrap_key()` — correct for the local/mock backends, but the AWS/Azure/GCP
backends raise their **own SDK exceptions** (botocore `ClientError`, Azure/GCP
errors, transport failures) when a KMS `Decrypt` fails. A tampered or failed
cloud unwrap would therefore propagate a raw SDK exception — and its message,
which can carry backend internals — instead of the typed `DekUnwrapError`.

`decrypt_blob` now treats **any** unwrap failure from **any** backend as
`DekUnwrapError` (typed envelope errors still propagate unchanged), with the
original exception chained for diagnostics but never exposed in the returned
error message. A regression test signs and then fails an unwrap through a
cloud-style backend and asserts the clean typed error.

### The rest of the module: reviewed, sound

The audit confirmed the envelope scheme is otherwise solid:

- a **fresh random 256-bit DEK and 96-bit nonce per object** — so no AES-GCM
  nonce is ever reused under a key (each DEK encrypts exactly one blob);
- **AES-256-GCM** authenticated encryption;
- `content_sha256` computed over the **ciphertext** and checked **before** any
  KMS call (integrity verification needs no key material);
- correct single-key **crypto-shred** (removing the wrapped DEK renders the
  ciphertext permanently unrecoverable while it stays intact in its WORM window).

A human Security-Architect ratification remains recommended before production
enablement — this release records the engineering security review, not that
sign-off.

## Upgrade notes

Additive bugfix — no breaking changes, no new dependencies. Callers that already
handle `DekUnwrapError` now get it uniformly across local and cloud KMS backends.
