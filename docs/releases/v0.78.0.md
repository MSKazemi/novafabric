# NovaFabric v0.78.0 — 2026-07-25

**Reproducible-build eval provenance — pin the closure, prove the divergence.**
ADR-0100's pure-hashing slice (§NF-023) ships: a sealed manifest that pins exactly
what an eval suite ran against, and a verifier that tells you precisely which piece
of a rebuilt run diverged. `experimental`. Full detail: `CHANGELOG.md` §[0.78.0].

## Highlights

### The eval provenance manifest (§NF-023)

`eval/provenance_manifest.build_eval_manifest(...)` pins an eval suite's full
reproducibility closure — the container image digest, the kernel/determinism flags
(batch-invariant ops, TF32, …), the seeds, and the dataset+split hashes — and
**content-addresses that closure**. The timestamp is deliberately excluded from the
digest, so two runs with an identical closure share a `manifest_digest`: the
manifest is the "reproducible build as copyleft" carrier a third party rebuilds
from.

### `verify_eval_closure` pinpoints the divergence

Reproducibility failures are useless if all you learn is "it differs."
`verify_eval_closure(observed, manifest)` is a **pure hashing / comparison** check
— it executes nothing and touches no GPU — and returns *exactly which element*
diverged:

- `container_digest` — a different image;
- `seed:torch` — a specific seed changed;
- `dataset:mmlu` — a dataset/split hash moved;
- `flag:tf32` — a determinism flag flipped.

It is robust to a partial observed closure (missing sections are reported as
mismatches, never an exception), so it degrades honestly.

### Composes with the existing evidence surfaces

The manifest is an Evidence Bundle payload (in-toto/DSSE-wrappable), not a new
top-level format, and composes with the ADR-0099 eval card. **Zero new
dependencies** — stdlib hashing and the existing Pydantic.

### Scope, honestly

This is the verifiable, pure-hashing half of ADR-0100. The GPU-gated
bitwise-attestation parts (NF-012 attested-`exact` replay, NF-013 TP-size facet,
NF-014 verified speculation) and the empirical rebuild-and-reproduce validation
(SPK-DET-5) remain future design behind their determinism spikes. ADR-0100 was
accepted (NF-023 slice) under delegated authority.
