# v0.16.1 — Live Topology Dashboard v0.1 (Track C)

Released: 2026-05-17

This release ships the Live Topology Dashboard v0.1, closing the
`nova serve --topology` design intent from the nova-design companion repository.
It resolves three open design questions (OQ-02, OQ-03, OQ-ADR-002) from the
dashboard architecture study.

## What's new

### `nova serve --topology`

New CLI flag that enables three topology endpoints on the existing `nova serve`
server and serves the `packages/nova-dashboard/` SPA from `/topology/`.

```bash
nova serve --experimental --topology
nova serve --experimental --topology --port 8080
```

Requires `novafabric[serve]` and `pip install novafabric[serve]`. The topology
endpoints are guarded by `--topology`; they are absent when the flag is omitted.

### Python server-side (`src/novafabric/serve/topology/`)

Four new modules:

| Module | Description |
|---|---|
| `ads_encoder.py` | ADS v1 Arrow IPC encoder (4 schemas: `metric_frame`, `cluster_layer`, `subgraph_page.nodes`, `subgraph_page.edges`) + `AdsValidator` |
| `delta_buffer.py` | 60-second in-memory ring buffer (≤ 60 000 events), monotonic checkpoint IDs for TDP gap-recovery replay |
| `cluster_store.py` | DuckDB in-process store for cluster layer, agent nodes, and agent edges; async-serialised writes; Arrow IPC fetch |
| `topology_extractor.py` | `networkx.DiGraph` + Louvain (10% edge-change trigger) + FA2 `spring_layout` approximation; thread-pool executor |

### Three topology endpoints

| Endpoint | Protocol | Schema |
|---|---|---|
| `GET /topology/clusters` | HTTP + Apache Arrow IPC | `ads.v1.cluster_layer` |
| `WS /topology/stream` | WebSocket — TDP v1 | `Sec-WebSocket-Protocol: nova-tdp-v1` required (rejects 4400 otherwise) |
| `GET /metrics/stream` | SSE | `ads.v1.metric_frame`; `Last-Event-ID` reconnect |

Auth token required on all three endpoints (query param `?token=...`).

WebSocket supports three client message types:
- `{"type": "subgraph_expand", "cluster_id": N}` → two Arrow IPC byte frames (nodes + edges) + checkpoint
- `{"type": "subgraph_collapse", "cluster_id": N}` → checkpoint
- `{"type": "resume_from", "checkpoint_id": N}` → batch\_checkpoint with missed events

### Browser SPA (`packages/nova-dashboard/`)

TypeScript SPA (Vite 8, React 19, Sigma.js 3, Graphology 0.26, Apache Arrow 21):

| Source | Description |
|---|---|
| `src/ads/schema.ts` | ADS v1 schema IDs + TypeScript row types |
| `src/tdp/types.ts` | TDP discriminated union (7 event types) |
| `src/tdp/client.ts` | `TDPClient`: WS + SSE, exponential backoff reconnect, `resume_from` gap recovery |
| `src/graph/fa2-worker.ts` | Web Worker for FA2 incremental layout settling; pins existing nodes via `{ fixed: true }` |
| `src/graph/model.ts` | `GraphologyModel`: delta apply, expand/collapse, LOD ceiling = 5 |
| `src/renderer/renderer.ts` | `SigmaRenderer`: `partialGraph + skipIndexation` on partial refresh |
| `src/App.tsx` | SPA shell: cluster fetch on mount, TDP stream, metric bar |

### Tests

- 49 new Python tests: 11 (ADS encoder) + 8 (DeltaBuffer) + 6 (ClusterStore) + 7 (TopologyExtractor) + 11 (serve integration — Arrow IPC, WebSocket auth, SSE)
- 16 new TypeScript vitest tests: schema IDs, TDP types, TDPClient reconnect/dispatch, GraphologyModel delta/LOD

### Open questions resolved

| Question | Outcome |
|---|---|
| **OQ-02** — FA2 WASM pin/unpin mixed mode | `{ fixed: true }` node attribute; `spring_layout(seed=42, fixed=pinned_ids)` falls back correctly |
| **OQ-03** — `sigma.refresh({ skipIndexation: true })` | `renderer.refresh({ partialGraph: { nodes: newIds }, skipIndexation: true })` — full canvas redraw avoided |
| **OQ-ADR-002** — WebSocket behind nginx HTTP/2 | Standard `proxy_http_version 1.1` + `Upgrade` headers; no HTTP/2 multiplexing issue |

## Upgrade notes

No breaking changes to existing `nova serve` behaviour. The `--topology` flag is
opt-in. `NOVA_DASHBOARD_DUCKDB_PATH` env var controls the topology DuckDB path
(default: `~/.novafabric/dashboard.duckdb`).

To build the SPA locally:

```bash
make topology-build    # builds packages/nova-dashboard/ → static/topology/
make serve-topology    # build + start with --topology
```
