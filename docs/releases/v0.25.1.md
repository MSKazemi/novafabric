# v0.25.1 — Compliance Exporters + OWASP Assure + Evidence Fabric

Released: 2026-05-19

Completes the v0.25.0 compliance sprint with three new compliance exporters
(cap-007/008/009), the OWASP LLM Top 10 assurance checker, the MCP supply-chain
scanner, Evidence Fabric infrastructure, and operations tooling.

---

## What's new

### cap-007 — GDPR Art.30 RoPA exporter (`nova export-ropa`)

- `GDPRRoPAExporter` (`src/novafabric/compliance/export/gdpr_ropa.py`) derives
  Records of Processing Activities from `capsule.yaml` + `redaction_manifest.json`.
- JSON-LD output with `gdpr:` and `nova:` namespaces.
- Operator config fills controller name/contact and third-country transfer flags.
- 8 tests covering minimal entry, security measures, PDA derivation, third-country
  transfers.

### cap-008 — CycloneDX 1.6 AI-SBOM (`nova export-aibom`)

- `AIBOMExporter` (`src/novafabric/compliance/export/aibom.py`) builds CycloneDX
  ML-BOM v1.6 from model + tool metadata in capsule.
- No external SDK required — plain JSON per CycloneDX 1.6 spec; bom-ref UUIDs per
  component.
- Reads `eval_result.json` for quantitative model card embedding.
- 9 tests covering model components, tools, eval model card, serial number
  uniqueness.
- **Note**: CycloneDX ML-BOM v1.7 (ECMA-424 2nd edition, Oct 2025) upgrade deferred
  to v0.27.x.

### cap-009 — NIST AI RMF 1.0 risk reporter (`nova export-nist-rmf`)

- `NISTAIRMFReporter` (`src/novafabric/compliance/export/nist_rmf.py`) scores four
  RMF functions (GOVERN/MAP/MEASURE/MANAGE) from capsule evidence files.
- 8 metrics: GV-1.1, GV-1.2, MP-2.1, MP-2.2, MS-2.5, MS-2.6, MG-2.2, MG-4.1
  with pass/fail thresholds.
- `risk_level` = `low` / `medium` / `high` / `critical` based on overall score +
  non-compliant metric count.
- 12 tests covering all 4 RMF functions, risk levels, missing evidence tracking.

### `nova assure` — OWASP LLM Top 10 (2025) evidence checker (E-10)

- `OWASPAssureChecker` (`src/novafabric/assure/`) runs 10 evidence checks across
  LLM01–LLM10 categories from capsule artifacts.
- Exits 1 on any check failure (for CI use); JSON report output (`--format json`).
- 62 tests.

### `nova mcp scan` — MCP supply-chain risk scanner (E-9)

- `MCPScanner` (`src/novafabric/mcp_scanner/`) checks MCP server manifest tool
  schemas against 25 OWASP LLM Top 10 risk rules.
- Severity scoring: `critical` / `high` / `medium` / `low`.
- `nova mcp scan <manifest.json>` — full scan output.
- `nova mcp list-checks` — enumerate all 25 rules.
- 45 tests.

### Evidence Fabric (`novafabric.evidence_fabric`)

- `DuckDBAccumulator` — append-only DuckDB capsule event store; 5 performance
  indexes; Parquet export path.
- `EventQueueConsumer` — bounded asyncio queue (default 1000); backpressure;
  drain-on-close.
- `LocalPIITable` — SQLite-backed PII detection table for cap-003 local mode
  (no ClickHouse dependency).
- 63 tests.

### Operations & infrastructure

- **OpenSSF Scorecard** (`.github/workflows/scorecard.yml`) — weekly security
  scorecard with SARIF upload to GitHub Advanced Security.
- **PgBouncer deploy config** (`deploy/pgbouncer/`) — production transaction-pool
  config, SCRAM-SHA-256 auth, userlist template for
  `novafabric_app` / `migrator` / `admin` roles.
- **Cluster-scale migration guide** (`docs/ops/cluster-scale-migration.md`) — 6-phase
  step-by-step guide: SQLite → Postgres → KuzuDB → OCS → JanusGraph → NATS → RLS DDL.
