# v0.104.0 — Secrets redacted from every capsule file, run-to-run diff that pairs separate captures, and replayable tool-calling turns

**Released 2026-10-08.** A correctness and security release. It closes a secret-redaction gap,
makes `nova diff` compare two separately captured runs, and lets mocked replay serve a recorded
tool-calling turn back. **Read the upgrade notes: `nova diff --assert-no-regressions` can now
fail a CI step that passed before.**

Maturity labels follow the project convention: **works today**, **experimental**, **planned**,
**future design**. Features below are labelled in the [CHANGELOG](../../CHANGELOG.md) entry for
this version.

## What's in it

| Area | What changed |
|---|---|
| **Secret scanning (security)** | Every file ADR-0009 names is now scanned before the capsule is finalized: `outputs/**`, `inputs/**`, `env.lock`, `assets.jsonl`, `lineage.jsonl`, plus the manifest. Before, a key the workload printed stayed in `outputs/stdout.txt`, and a key on the command line stayed in `capsule.yaml` and in the signed seal payload. The manifest is now redacted before it is written or signed. |
| **Rule pack 0.6.0 (security)** | OpenAI project, service-account and admin keys (`sk-proj-…`, `sk-svcacct-…`, `sk-admin-…`) were not detected at all; Anthropic keys longer than 87 characters were masked with their tail left visible; Langfuse secret keys (`sk-lf-…`) were not detected. All three are fixed. |
| **Diff** | Model calls from two separate captures now pair (span match, then sequence position anchored on identical requests). Before, every call showed as one added plus one removed. Tool calls still match order-independently, then by position with the same tool name, and report `arguments_changed`. |
| **CI gate** | `--assert-no-regressions` exits 1 on **any** change, including added or removed calls, as documented; the `name@version` asset path now honours it too. |
| **Replay** | Capture records the assistant's tool-call requests (OpenAI `tool_calls`, Anthropic `tool_use`), and mocked replay serves them back, so a function-calling agent sees its own requests. Tool *responses* are still not substituted: tools run live. Running out of recorded responses now warns. |
| **Dashboard** | `/api/adapters` lists all 11 framework adapters (three were missing). |
| **Docs** | Comparison page, feature tour, standards table, GitHub Action README, both tutorials and README corrected. Prompts and responses **are** stored in the capsule (only OTel export of content is opt-in); sealing and RFC 3161 timestamping are opt-in; there are five replay modes; a mocked replay is not a new capsule. |

## Upgrade notes

- **`nova diff --assert-no-regressions` may now fail where it passed.** It counts added and
  removed calls, and calls from two captures now pair, so a model-behaviour change between
  captures is reported as a change. That is the documented contract; review gated pipelines.
- **A binary file in `inputs/` or `outputs/` that contains a detected key is dropped from the
  capsule** and recorded in `redaction-proof.json` (ADR-0009). Text files are redacted in place.
  Files over 64 MiB are recorded as `skipped`, not scanned.
- **Redaction-proof `targets` now list artifact files**, and the scanner version is 0.3.0 /
  pack 0.6.0. The proof schema is unchanged (the target kinds already existed).
- **Model-call records may carry `message.tool_calls`** in response choices — the existing
  optional `Message.tool_calls` field of `model-call.schema.json`. Absent on text-only turns.
- **Replay results no longer record a `--mock-tools` flag**, which never existed.
- Capsules written by earlier versions validate and verify unchanged. Re-capture a run to get the
  wider redaction coverage; existing capsules are not rewritten.
