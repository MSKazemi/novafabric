# NovaFabric v0.29.4 — Dashboard MCP servers panel + architecture/ROADMAP sync

**Released:** 2026-05-19

## Highlights

- The `AgentQueryPanel` in KGTab now shows a **MCP servers** table (2-hop path
  Agent→Tool→MCPServer), making the full multi-layer graph queryable from the dashboard.
- `GET /api/kg/agents/{id}/edges` includes `mcp_servers` in its JSON response.
- `design/architecture/architecture.md` fully documents the KG subsystem env vars, API surface,
  IngestTracker, topology cache, and dashboard components.
- ROADMAP rows added for v0.29.1 / v0.29.2 / v0.29.3.

---

## What's new

### Dashboard — MCP servers in AgentQueryPanel

The Query Agent panel in KGTab now shows three result sections:

| Section | Edge | Description |
|---|---|---|
| `model_id` | `CALLS` | Models the agent called directly |
| `tool_id` | `USES_TOOL` | Tools the agent invoked |
| `mcp_server (via tool)` | `USES_TOOL + SERVED_BY` | MCP servers reachable via any tool |

The MCP servers table lists `server_id` and `calls` count, aggregated across all
Tool intermediaries.  Empty when no MCP-namespaced tool calls were recorded.

### `GET /api/kg/agents/{id}/edges` includes `mcp_servers`

The JSON response now always includes a `mcp_servers` key (empty list when no
MCPServer nodes exist for this agent).  The TypeScript `kgAgentEdges` return type
is updated to match.
