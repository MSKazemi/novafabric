# v0.13.4 — LineageGraph UX fix + test coverage restored to 90%

Released: 2026-05-15

A maintenance release. Double-clicking a node in the Lineage tab now selects it
(same as single-click) instead of triggering React Flow's default zoom-to-fit.
Test coverage is restored to 90% after the v0.13.2 OPA trace additions dropped it
to 89%.

---

## Background

React Flow's default behaviour maps double-click on a node to **zoom-to-fit** the
entire graph. This collides with the natural expectation that double-clicking a
node drills into it — users exploring deep lineage graphs were accidentally
resetting their zoom level and losing their position.

The fix disables zoom-on-double-click at the `<ReactFlow>` level and adds an
`onNodeDoubleClick` handler that calls `setSelectedNodeId`, making both click
actions consistent (select the node and show its edge list in the side panel).

The coverage restoration adds:

- **`test_opa_engine.py`** — `OpaEngine._explain()` (success path, `FileNotFoundError`,
  `TimeoutExpired`), `evaluate()` with `TimeoutExpired`, and
  `NOVAFABRIC_POLICY_BUNDLE_PATH` env var override.
- **`test_serve_app.py`** — `GET /api/storage/stats`, `GET /api/storage/manifest-chain`,
  `GET /api/infra/collector`, `GET /api/admin/tokens`, `DELETE /api/admin/tokens/{fp}`
  (path-traversal guard + missing-file 404). Three existing policy-check mocks were
  also updated to accept the `explain` kwarg added in v0.13.2.

## Changed

### `web/src/components/lineage/LineageGraph.tsx`

- `zoomOnDoubleClick={false}` added to `<ReactFlow>` props — disables the default
  zoom-to-fit on node double-click.
- `onNodeDoubleClick` handler added: calls `setSelectedNodeId(node.id)`, making
  double-click equivalent to single-click (select node, reveal edge panel).

### `tests/test_opa_engine.py`

- Three mock functions updated to accept `explain: bool = False` kwarg.
- Six new tests added: env var bundle path, evaluate timeout, explain happy-path,
  `_explain` FileNotFoundError fallback, `_explain` TimeoutExpired fallback.

### `tests/test_serve_app.py`

- Seven new tests for previously untested serve endpoints (storage/stats,
  manifest-chain, infra/collector, admin/tokens, revoke guards).

## Upgrade Notes

No Python, CLI, or API changes. The `nova promote` command, REST API, and all
data formats are identical to v0.13.3.

The `zoomOnDoubleClick` change only affects the LineageGraph React component.
If you embed `LineageGraph` in a custom host, double-click now selects rather than
zooms. Single-click behaviour is unchanged.
