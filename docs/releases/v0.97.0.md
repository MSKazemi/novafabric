# NovaFabric v0.97.0 — 2026-07-30

**The dashboard modernization release.** One program, both sides of the wire: the
operator dashboard gets a real design system, a balanced information architecture,
and honest big-data behavior; `nova serve` gets the security and scale fixes that
make those behaviors true rather than cosmetic. The dashboard remains
**experimental** (ADR-0027) — nothing in this release changes that gate.

## Highlights

### A design system instead of ad-hoc Tailwind

`web/src/components/ui/primitives/` now holds the dashboard's building blocks —
Button, Input, Select, Textarea, Field, Card, Badge, StatusPill, SegmentedControl,
Modal (with a real focus trap), Drawer, Tooltip, Toolbar — built on an extended
token set (elevation, semantic tints, focus ring, motion). Icons are real SVGs via
a semantic wrapper over lucide-react (ISC, Tier-A per ADR-0024), replacing the
unicode glyph set. The 8–9px micro-type is gone: 10px (`--text-2xs`) is the floor.
Both ConfirmDialogs now share one Modal implementation; the Layer-B variant keeps
its CLI-equivalent + audit-log notice (ADR-0027).

### Navigation you can hold in your head

The 29 tabs (ids unchanged — command-parity classification and `?tab=` deep links
are untouched) are regrouped from 8 lopsided groups (one held 13 tabs) into 7
balanced ones: Overview · Runs & Debug · Govern & Promote · Provenance & Trust ·
Compliance · Platform · Reports & Export. Navigation shortcuts are now stable
mnemonic sequences — `g` then a per-tab key (`g h` Home, `g r` Runs, `g c`
Compliance) — instead of positional 1–9 that silently remapped whenever the
sidebar changed. Press `?` for the full map.

### Monoliths → modules (behavior frozen)

- **ComplianceTab: 2,531 → 81 lines.** Its 22 panels live in
  `tabs/compliance/`, one file each, behind a deep-linkable `?sub=` hub
  (Frameworks · Audits · Privacy · Exports · Assurance) that also surfaces in
  the ⌘K palette. A shared `PanelScaffold` owns the load/error/result state
  machine those panels each re-implemented.
- **RunsTab: 2,110 → 327. RegistryTab: 1,561 → 342.** Data layers, lists,
  inspectors, and dialogs extracted verbatim into `tabs/runs/` and
  `tabs/registry/`.

### Honest at scale, end to end

- Every bounded list can now say so: the shared truncation affordance renders
  "Showing N of ~M — load more" (ADR-0199's no-silent-truncation rule), backed
  by `usePaginatedQuery` speaking both server pagination models.
- The last unbounded-read endpoints are bounded: the two policy endpoints page
  the audit log via O(page) reverse tail reads instead of `read_text()` on the
  whole file; `/api/lineage/edges` gained a real keyset cursor + `total` +
  `truncated`; entity queue, admin listings, and per-asset eval history are
  limit-bounded with additive totals. `/api/runs/search`'s fast path is now a
  true keyset seek — the O(offset) `COUNT(*)` conversion is gone.
- Conditional GET everywhere the dashboard polls: 8 hot endpoints serve
  content-addressed ETags and empty-body 304s.
- The event loop breathes: stats, runs, evidence-zip, KG-topology, report, and
  diff work runs in worker threads (whole sqlite lifecycle included), so a slow
  query no longer stalls SSE/WebSocket heartbeats. Registry schema DDL runs
  once per process, not once per request.

### Security fixes (serve)

- `/api/tv5/*` was mounted with **no auth at all** — HTTP routes are now
  token-gated and the TV-5 WebSocket enforces the localhost host guard (4403)
  and token (4401) before accepting.
- `Authorization: Bearer` is accepted everywhere `?token=` is; the header, when
  present, is authoritative. The query form keeps working for the SPA and
  printed URLs.
- The token comparison is hash-then-`compare_digest` (the previous early return
  leaked token length). Server mode's `GET /v0/replays/{id}` + events SSE now
  require the reader role.

## Upgrade notes

- No breaking changes. All response-envelope changes are additive
  (`next_cursor`, `total`, `truncated`, `eval_results_total`, …).
- New dashboard dependency: lucide-react (ISC). Removed: motion (was unused).
- `/api/policy/explain` now returns matches newest-first (was oldest-first) and
  accepts `limit`/`cursor`.
- Rebuild the bundle with `npm run build:dashboard` if you serve from source.
