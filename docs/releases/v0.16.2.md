# v0.16.2 — Topology Runtime Dependency Patch

Released: 2026-05-17

Patch release. No functional changes.

## Changes

- **`pyproject.toml`** — added six topology runtime dependencies that were missing
  from `novafabric[serve]`: `duckdb`, `pyarrow`, `networkx`, `python-louvain`,
  `pyjwt`, `python-multipart`. These are required when running
  `nova serve --topology` and were causing `ModuleNotFoundError` on a clean install.
- **`design/architecture/architecture.md`** — added Live Topology Dashboard section (Python
  server-side modules, SPA, endpoint table, OQ spike outcomes, open question resolution).
- **Test files** — removed five unused imports flagged by ruff after the topology
  merge (`original_schedule` variable in `test_topology_extractor.py`,
  unused `ws` alias in `test_topology_serve.py`).

## Upgrade notes

Run `pip install -U 'novafabric[serve]'` (or `uv sync`) to pick up the new deps.
No schema or API changes.
