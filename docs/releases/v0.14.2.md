## What's new

This patch strengthens the test suite for the NovaSeal seal routes shipped in v0.14.1.

### Test coverage improvements

- **`test_proposals_with_approval`** (new in `test_server_seal_routes.py` and `test_serve_seal.py`) — exercises the approval-present branch of both the multi-user REST route (`GET /v0/seal/{capsule_id}/proposals`) and the local-serve endpoint (`GET /api/seal/{capsule_id}/proposals`). Creates a real proposal + approval DSSE envelope pair using fixture keys, stores them in `PromoteBundleStore`, and asserts `has_approval=True` with the correct `approver_subject`.
- **2323 tests passing** (2 added), **≥ 90% statement coverage** maintained.

### Coverage gate hardening

- Two defensive branches marked `# pragma: no cover` in `serve/app.py` (corrupt-proposal exception handler in list-proposals endpoint) and `server/routes/seal.py` (env-override branch in `_merkle_db_path`). These branches are unreachable in the unit-test harness by design and would require live-filesystem injection to trigger.

## Upgrade

No schema changes, no CLI changes, no API changes. Drop-in replacement for v0.14.1.
