# NovaFabric v0.75.0 — 2026-07-25

**The witness-cosigned transparency log — its structural core, implemented.**
ADR-0097 was pure design intent; this release ships its anti-split-view core
(§NF-042 checkpoint + §NF-043 witness cosigning) on top of the transparency log's
already-shipped Merkle consistency proofs. `experimental`. Full detail:
`CHANGELOG.md` §[0.75.0].

## Highlights

### Checkpoint note (§NF-042)

A C2SP-style `tlog-checkpoint` — the canonical signed-tree-head note
`<origin>\n<tree_size>\n<base64(root)>\n` that witnesses cosign. `Checkpoint` is a
small frozen value built directly from `MerkleLog.current_root()` /
`tree_size()`.

### Witness cosigning (§NF-043) — non-equivocation

`trust/novaseal/witness.py` implements the `tlog-witness` protocol. A `Witness`
holds the last checkpoint it cosigned per log origin and cosigns a new one **only**
when it is a verifiable append-only extension — a valid consistency proof (from
the existing `MerkleLog.consistency_proof`) from the last size to the new size.
It **refuses** (`WitnessRefusedError`):

- a **split view** — the same `tree_size` with a different root than the last
  cosigned checkpoint (the classic equivocation attack);
- a **size regression** — a checkpoint behind the last cosigned one;
- a **missing or invalid consistency proof** for a larger checkpoint.

This is what makes a quorum meaningful: `verify_quorum(note, witness_pubkeys, k)`
accepts a head only with **K-of-M** valid Ed25519 cosignatures from known
witnesses (duplicate names and unknown signers never inflate the count).

### Built on what already exists

No new tree machinery and **no new dependencies**: witnesses reuse the transparency
log's RFC-6962-style consistency proofs, and cosignatures are Ed25519 via the
existing `cryptography`. Verified end-to-end against a real `MerkleLog` extension.

### Scope, honestly

This is the first slice. §NF-041 (tiles over WORM object storage), §NF-044 (the
`nova monitor` independent auditor CLI), §NF-045 (COSE receipts for Evidence
Bundles), and §NF-047 (portable offline-verifiable bundle) remain future design.
The full C2SP note's 4-byte key-hash disambiguation is deferred — here a witness
name maps 1:1 to a verifier-supplied public key. ADR-0097 was accepted (first
slice) under delegated authority.
