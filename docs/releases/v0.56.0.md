# NovaFabric v0.56.0 — Accountability Spine: court-admissibility, measured energy, Annex IV, dashboard

**Released:** 2026-06-19

A follow-on to v0.55.0 (which shipped the three Accountability Spine feature *cores*).
v0.56.0 deepens all three — court-admissible evidence, *measured* energy, regulatory
safety-case rendering, Evidence-Bundle integration, and a dashboard tab. Everything is
**additive and opt-in**; no existing schema, CLI default, or capture behavior changes, and the
only two top-level formats remain Run Capsule and Evidence Bundle
([ADR-0034](../../design/adr/0034-v1-spec-stability-policy.md)).

---

## Highlights

### Court-admissible evidence binding (ADR-0095) — the "court-admissible" half made real

`nova evidence bind-custody` / `check-admissibility`, and `nova export-evidence --with-custody`,
build an **FRE-902(14)** chain-of-custody + self-authentication block (additive `$defs` on the
Evidence Bundle schema), mapping to US FRE 902(13)/(14), FRE 901(b)(9), SWGDE, and the Berkeley
Protocol. Custody events come from the hash-chained audit log — a broken chain sets
`integrity_continuous=false`. **Invariant I3** is enforced: any field NovaFabric cannot witness
is `null` + `operator_declared`, never fabricated. A five-point gate yields
`self-authenticating` / `requires-foundation` / `incomplete`; with a signing key the capsule hash
is really signed and verified.

### Measured energy on real hardware (ADR-0093)

- **`EnergySampler`** — a bounded, fail-open RAPL sampling daemon writing `energy-samples.jsonl`.
- **Measured time-share attribution** — when samples exist, node joules are integrated
  (wraparound-safe) and apportioned per-action by wall-clock share, producing
  `confidence="apportioned"` receipts; the honest `unavailable` fallback is unchanged.
- **Slurm `sacct ConsumedEnergyRaw`** capture → a *measured* `sacct_energy` receipt (fail-open).
- Energy receipts now ride into **Evidence Bundles** as a signed `PREDICATE_ENERGY` attestation.

> **Honest by design.** On hardware where per-action energy isn't readable (e.g. RAPL is
> root-only, the common case), receipts are marked `unavailable` — never a fabricated number.

### EU AI Act Annex IV + NIST RMF safety-case renderers (ADR-0095)

`nova safety-case export --format annex-iv|nist-rmf` renders the Claims-Arguments-Evidence tree
as regulator-facing documentation. The Annex IV template binds to the same 15 element ids as the
existing compliance mapping. Honesty is structural: CONTESTED claims surface their reason,
UNSUPPORTED is never laundered to "compliant", and a `not-quantified` residual risk renders as
such.

### Dashboard — Accountability Spine tab

A new **Spine** tab plus token-gated read-only serve endpoints
(`GET /api/runs/{id}/energy|ledger|safety-case`): energy receipts + conservation status, ledger
verify status + tamper class, and on-demand safety-case build with color-coded backing states.

### Packaging fix

The four spine schemas (energy-receipt, replay-attestation, ledger-checkpoint, safety-case) are
now mirrored into the runtime-packaged `src/novafabric/schemas/` (v0.55.0 shipped them only in the
non-packaged top-level `schemas/`), and the additive custody `$defs` were added to the packaged
Evidence-Bundle schema so custody manifests vendor and validate.

## What is *not* yet in this release (honest limitations)

- **Live n1 Slurm `sacct`** end-to-end — needs a cluster with
  `AcctGatherEnergyType=acct_gather_energy/rapl`; the parser, receipt builder, and runner wiring
  are implemented and unit-tested against captured `sacct` output, but the live joule query on
  real hardware is unvalidated.
- RFC-3161 timestamp **auto-check** inside the custody gate (currently operator-asserted via
  `--timestamp-ok`); the optional FRE-902(14) Rego gate.

## Upgrade

No action required — all new surfaces are additive and opt-in; old Run Capsules and Evidence
Bundles remain valid unchanged. GPU energy (NVML) stays behind the optional extra:

```bash
pip install 'novafabric[energy-gpu]'   # only for NVML on a GPU box
```

## Quality

Full suite **4984 passed / 0 failed**; new spine code is 98–100% covered. `mypy --strict` and
`ruff` clean across the source tree; the dashboard `astro build` (TypeScript) is clean. Every
slice was built test-first.
