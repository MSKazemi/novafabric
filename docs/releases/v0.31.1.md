## What changed

### KGStore Prometheus metrics

`src/novafabric/kg/store.py` gains optional `prometheus_client` counters and gauges.
The import is wrapped in a `try/except` so the library remains optional — if
`prometheus_client` is not installed the metrics silently degrade to `None` and all
call sites are guarded.

| Metric | Type | Labels | Description |
|---|---|---|---|
| `novafabric_kg_node_merge_total` | Counter | `node_type` | KG node MERGE upserts |
| `novafabric_kg_edge_upsert_total` | Counter | `edge_type` | KG edge upserts (CRDT G-counter writes) |
| `novafabric_kg_crdt_merge_total` | Counter | `edge_type` | CRDT merges where `call_count` incremented |
| `novafabric_kg_node_count` | Gauge | — | Total KG node count across all node types |

To expose these metrics add a Prometheus scrape endpoint (e.g. via the `prometheus_client`
`start_http_server()` or a WSGI middleware) and install the optional dependency:

```bash
pip install prometheus_client
```

No schema changes. No breaking changes. 3835 tests (2 pre-existing JWKS cache failures unrelated to this change).
