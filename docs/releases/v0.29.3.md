# NovaFabric v0.29.3 — KG ingest completeness + Decimal fix + NovaSeal path precedence

**Released:** 2026-05-19

## Highlights

- `nova kg ingest` now reads `tool-calls.jsonl` in addition to `model-calls.jsonl`,
  so MCPServer nodes from namespaced tools are created when using the CLI directly
  (not only via `nova serve` auto-ingest).
- `KGStore.query_agent_mcp_servers()` call_count no longer throws a `TypeError`
  on JSON serialisation — KuzuDB `sum()` returns `Decimal`; now cast to `int`.
- `resolve_merkle_db_path()` env-var precedence fixed: `NOVAFABRIC_SEAL_DB_PATH`
  now beats `novaseal.yaml` (as documented).

---

## What's new

### `nova kg ingest` reads `tool-calls.jsonl`

Previously the CLI only looked for `model-calls.jsonl` (or `events.jsonl` as
fallback).  MCP tool-call events live in `tool-calls.jsonl`, so any tool name
containing `:` (e.g. `filesystem:read_file`) — which triggers MCPServer node
creation — was silently ignored when running `nova kg ingest`.

Now the CLI mirrors the `nova serve` auto-ingest logic: it collects
`model-calls.jsonl` + `tool-calls.jsonl` from the capsule directory and falls
back to `events.jsonl` only when neither specialised file exists.

### Developer-guide MCPServer extension point section

`docs/developer-guide.md` now has a dedicated subsection covering:
- `nova kg alias register --type mcp_server`
- `nova kg query` MCP server JSON output
- `NOVA_KG_INGEST_INTERVAL` and `NOVA_KG_PATH` env vars
- `IngestTracker` SQLite sidecar persistence
- `/api/kg/topology` 30-second TTL cache

## Bug fixes

- **`query_agent_mcp_servers()` Decimal** — `sum()` in KuzuDB returns a
  `Decimal` object; added `int(r[2]) if r[2] is not None else 0` cast so JSON
  serialisation does not raise `TypeError`.
- **`resolve_merkle_db_path()` precedence** — env var `NOVAFABRIC_SEAL_DB_PATH`
  is now resolved *before* reading `novaseal.yaml`; a Docker environment
  variable was silently overridden by a stale config file on disk.
- **Test event type** — `test_kg_query_cli_mcp_servers` used `"ToolCalled"`
  which is not in `_TOOL_EVENT_TYPES`; fixed to `"ToolCallCompleted"` so the
  test actually exercises the MCPServer creation path.

---

## Upgrade notes

No breaking changes.  No new required environment variables.

`nova kg ingest` now processes `tool-calls.jsonl` from the same capsule
directory, which may create additional MCPServer / SERVED_BY edges for
capsules you re-ingest after upgrading.  Because KuzuDB MERGE is idempotent,
re-ingesting is safe.
