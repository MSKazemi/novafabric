# NovaFabric v0.84.0 — 2026-07-25

**Map your evidence to ISO/IEC 42001 — without inventing any.** ADR-0107's ISO/IEC
42001 + 42005 exporter (NF-095) ships: bind a declared 42001 control catalog to the
governance evidence NovaFabric actually holds for a capsule, and emit a structured
42005 AI-system impact-assessment object. `experimental`. Full detail: `CHANGELOG.md`
§[0.84.0].

## Highlights

### ISO/IEC 42001 control-mapper (ADR-0107 §NF-095)

`build_iso42001_mapping(catalog, present_evidence, capsule_ref=…, declared_controls=…)`
takes a *declared* ISO/IEC 42001 control catalog and marks each control against the
governance evidence present for a capsule:

- **`evidenced`** — the control's mapped evidence is present *and* a re-performable
  `EvidenceSourceRef` (ADR-0197) was supplied; the ref is carried so a third party can
  re-check it offline. Provenance is `operator_asserted` (the ref is carried, not
  re-performed in the exporter).
- **`not_evidenced`** — the evidence is absent. An honest gap, never fabricated. (An
  `evidenced` mapping with no ref supplied degrades here, marked `unverifiable`.)
- **`declared`** — the operator asserts the control with no NovaFabric backing.

It reuses the ADR-0087/ADR-0170 criterion→evidence pattern (`control_attestation.py`).
Like every NovaFabric compliance exporter, it certifies *presence of evidence*, never
that a control is *adequate* — that judgment stays with the auditor.

### ISO/IEC 42005 impact-assessment object

`build_iso42005_impact_assessment(system_name, sourced_sections=…, operator_sections=…)`
emits a structured impact-assessment with the six canonical AI-system-impact sections
always present, so a missing one is a *visible* gap:

1. intended purpose and context of use
2. affected individuals, groups, and society
3. reasonably foreseeable harms and benefits
4. likelihood and severity assessment
5. risk mitigation and control measures
6. residual risk and accountability sign-off

Each section records whether it was **capsule-sourced** (`capsule_verified`, with a ref)
or **operator-declared** (`operator_asserted`). Section names outside the canonical set
are ignored — the exporter never fabricates a non-standard section.

### Scope, honestly

This is a pure projection over existing evidence — no infrastructure, no new
dependencies. It is the **second** ADR-0107 exporter (NF-090 Art. 12 shipped in v0.80.0;
NF-092 Annex IV is already served by the shipped `AnnexIVExporter`). The remaining four
— NF-091 (Art. 72 post-market monitoring), NF-093 (GPAI Art. 53 form), NF-094 (Art. 50
marking log), NF-097 (NIST GenAI / CSA Agentic mapper) — remain future design. A
`nova export-*` CLI wrapper is a deliberate follow-on (kept out of this slice to avoid
regenerating the command registry mid-change). ADR-0107 §NF-095 marked shipped under
delegated authority.
