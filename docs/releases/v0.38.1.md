# Release v0.38.1 — `nova init`

**Released:** 2026-05-20
**Type:** patch — new CLI command (pip install path only)

---

## What's new

### `nova init` — first-run setup for pip-installed NovaFabric

After `pip install novafabric` (or `uv tool install novafabric`), run once:

```bash
nova init
```

Output:

```
Initialized: /home/<you>/.novafabric
  capsules  → /home/<you>/.novafabric/capsules
  keys      → /home/<you>/.novafabric/keys/signing_key.pem

Next steps:
  nova capture python my_agent.py
  nova serve --experimental
```

**What it creates:**

| Path | Purpose |
|---|---|
| `~/.novafabric/capsules/` | Default capsule storage |
| `~/.novafabric/keys/signing_key.pem` | Ed25519 private key (mode 600) |
| `~/.novafabric/keys/signing_key.pub.pem` | Ed25519 public key |
| `~/.novafabric/replays/` | Replay result storage |

**Flags:**

| Flag | Effect |
|---|---|
| `--home PATH` | Override `NOVAFABRIC_HOME` |
| `--force` | Regenerate keypair even if one already exists |

**Idempotent:** running twice prints "Already initialized" and exits 0. Existing keys are never overwritten unless `--force` is passed.

---

## Who needs this

**Pip/uv users:** run `nova init` once after install, before any other command.

**docker-compose users:** skip it — `make dev-up` (the container entrypoint) handles all first-boot setup automatically.

---

## Upgrade

```bash
pip install --upgrade novafabric==0.38.1
# then:
nova init   # safe to run even if you have existing data
```

No schema migrations. No breaking changes.
