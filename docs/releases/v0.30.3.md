# v0.30.3 — 2026-05-20

Dashboard polish sprint: `ReportsTab` with 10 report types, `SuggestInput` 100% coverage across all ID input fields, and a full icon + UX overhaul.

---

## What changed

### New: ReportsTab

A new **Reports** tab provides a Catalog+Builder layout with 10 report types grouped by audience:

| Group | Report types |
|---|---|
| Developer | Run History, Eval Regression, Capsule Compare |
| Ops | Cost Burn, Throughput |
| Compliance | Evidence Inventory, Policy Audit, Seal Verification |
| Management | Executive Summary, Release Comparison |

Each report supports date-range filtering and exports as **CSV**, **JSON**, or **PDF** (via browser print). The TypeScript API client gains `api.reports.fetch(type, params)`.

Backend: 10 new FastAPI endpoints under `GET /api/reports/*` in `serve/app.py`, backed by query functions in `serve/reports.py`. All 10 endpoints gracefully degrade when no capsules are present. 13 new backend tests.

### SuggestInput 100% coverage

All dashboard panels that accept a typed ID now use the `SuggestInput` autocomplete component. The remaining 6 bare inputs from earlier versions are now wired:

| Panel | Field | Strategy |
|---|---|---|
| AnnexIVPanel | `deploymentId` | `useLocalMru` — localStorage MRU populated on each successful Annex IV export |
| NIS2Panel | `incidentId` | `useLocalMru` — localStorage MRU populated on each successful NIS2 report export |
| SubjectProofPanel | `subjectId` | `useLocalMru` — subject identifiers accumulated locally (privacy-preserving; never sent to backend) |
| GdprErasurePanel | `subjectId` | `useLocalMru` + live `runIds` — accepts both subject IDs and run IDs per label |
| AssurancePanel | `runId` | Live `runIds` via `GET /api/runs`; prop from `ComplianceTab` |
| StorageOpsCard | `runId` | Live `runIds`; `InfraTab` now fetches on mount and passes to `StorageOpsCard` |

**`useLocalMru` hook** — new reusable hook in `ComplianceTab.tsx` that stores up to 12 most-recently-used values per key in `localStorage`. Suggestions are empty on first use and grow automatically after each successful API call.

### Dashboard UX polish

- Favicon SVG: path corrected to draw **N** (was accidentally M); hex frame added.
- Apple-touch-icon added to `Layout.astro` and `DashboardLayout.astro`.
- Brand mark (hex+N) visible in collapsed sidebar header.
- Sidebar groups are now collapsible; state persisted in `localStorage`.
- Connection status dot visible in collapsed sidebar footer.
- Breadcrumb top bar replaces plain topology button bar; shows `NovaFabric / {tab}` + live connection pill.
- `DashboardApp.tsx` now derives `TABS` from `ALL_TABS` (single source of truth for tab order).
- `KeyboardHelp` component lists all tabs dynamically by name.
- `EmptyState` accepts an optional `icon?: ReactNode`; padding reduced `p-12 → p-8`.
- Sidebar label badges use neutral `color-text-faint`; `experimental` badge uses info blue.
