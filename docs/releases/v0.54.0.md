# NovaFabric v0.54.0 — `nova capture --fast-emit` (import-deferred hook install)

**Released:** 2026-06-18

This release ships **slice B** of the warm-capture / resident-emitter work
([ADR-0092](../../design/adr/0092-warm-capture-daemon.md), extends
[ADR-0020](../../design/adr/0020-cluster-scale-low-overhead-capture.md)). Slice A
(v0.52.0) removed the per-run *orchestrator* cold-start with a warm daemon. Slice B
attacks the other startup cost — the **workload subprocess's own** hook-install
import — with a new `--fast-emit` flag. No new dependencies; pure standard library.

## Why

When `nova capture` runs a workload, a `sitecustomize` loader installs NovaFabric's
in-process wire hooks at the workload interpreter's startup. The default installer
(`install_all`) **eagerly imports every present target SDK** — `openai`,
`anthropic`, `mcp`, `requests`, `httpx`, `aiohttp`, `urllib3` — purely to
monkeypatch it. Measured with `-X importtime` in this repo: importing `openai` to
patch it is ~717 ms and `mcp` ~340 ms. That cost is paid at startup **even when the
workload never calls those SDKs**, and it is fixed regardless of the workload. For a
fleet of short agent runs it dominates the per-run overhead.

## Highlights

### `nova capture --fast-emit`

`--fast-emit` (equivalently `CaptureOrchestrator(fast_emit=True)` or the
`NOVAFABRIC_FAST_EMIT=1` env var) selects an **import-deferred** installer. It
imports **no** SDK at startup. For each built-in hook it registers a one-shot
`sys.meta_path` post-import callback (`novafabric.capture.hooks._deferred`) that
fires only if/when the workload itself imports that SDK — at which point the SDK is
already loaded (the workload's own cost) and patching adds ~nothing. An SDK the
workload never imports is never imported by capture. The `EventRecorder` singleton
(and its pydantic event models) is likewise created lazily inside the callback,
before the first event — so a workload that imports no instrumented SDK pays neither
the SDK nor the recorder import.

### Measured (warm-fs, orchestrator, 4-run median)

| workload | eager (default) | `--fast-emit` | reduction |
|---|---|---|---|
| pure compute (imports no instrumented SDK) | ~2068 ms | ~464 ms | **−78 %** |
| `import openai` (one SDK, used) | ~2223 ms | ~1509 ms | **−32 %** |

The saving scales inversely with how many of the 7 instrumented SDKs the workload
uses: maximal for compute-only workloads, ~32 % when one heavy SDK is used.

### Fidelity preserved

When a hook *does* install (its SDK is imported), it is the identical hook class on
the identical recorder. A real-subprocess test
(`test_fast_emit_fidelity_records_network_event`) runs the same workload eager vs
`--fast-emit` against a local AI endpoint and asserts both record the network event.
Already-imported SDKs are patched immediately, so no import is ever missed.

### Safety

- **Pure stdlib** (ADR-0024 trivially satisfied) — a thin `MetaPathFinder` that
  delegates spec-finding to the other finders and wraps the loader's `exec_module`.
- **Fail-open** — a callback that raises is swallowed; a broken hook never breaks
  the workload's own import of its SDK.
- **In-process only** — `--fast-emit` is excluded from warm-daemon delegation (the
  thin client carries only argv/cwd/env, so delegating would silently drop the
  flag), consistent with the other behavior-changing capture flags. It composes
  with the daemon when a daemon worker runs a `fast_emit` orchestrator.
- **Cross-platform** — unlike the daemon (`os.fork`, Linux-only), `--fast-emit`
  uses only the portable import machinery.

## Try it

```bash
# Compute-heavy or single-SDK agents: skip importing the SDKs you don't use.
nova capture --fast-emit python agent.py

# Equivalent via env var (e.g. inside a runner or container):
NOVAFABRIC_FAST_EMIT=1 nova capture python agent.py
```

```python
from novafabric.capture.orchestrator import CaptureOrchestrator

orch = CaptureOrchestrator(base_dir="runs", fast_emit=True)
orch.run(command=["python", "agent.py"])
```

## Compatibility

- Additive and opt-in. The default (`--fast-emit` unset / `NOVAFABRIC_FAST_EMIT`
  unset or `"0"`) is byte-for-byte the previous eager path.
- No schema, capsule-format, or public-API breaks. New: `--fast-emit` flag, the
  `fast_emit` keyword on `CaptureOrchestrator`, the `NOVAFABRIC_FAST_EMIT` env var,
  and `install_all_deferred` / `novafabric.capture.hooks._deferred`.
