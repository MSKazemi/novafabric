# v0.4.1 — emit-openlineage

Released: 2026-05-08

## What's new

- **OpenLineage emission**: Every `nova capture` run now emits OpenLineage events automatically when configured.
  - Set `OPENLINEAGE_URL` to forward events to Marquez or any compatible backend (Atlan, DataHub, etc.).
  - Set `OPENLINEAGE_FILE` to write NDJSON to a local file for inspection or batch upload.
  - Both can be set simultaneously.
  - Neither set → silent no-op (zero performance impact on unconfigured runs).
- **`nova lineage emit-openlineage <path>`**: Replay OpenLineage events from any existing capsule dir or parent runs directory. Useful for backfill after configuring `OPENLINEAGE_URL`.
- **`replayed_from` → ParentRunFacet**: NovaFabric replay chains are propagated natively as OpenLineage `ParentRunFacet`, enabling Marquez lineage graphs to show replay lineage.
- **Dataset mapping**: `consumed` edges → `InputDataset`, `produced_by` edges → `OutputDataset`. Identical run → same UUID (idempotent backfill).

## Breaking changes

None.

## Upgrade

```bash
pip install novafabric==0.4.1
```

## Backfill existing capsules

```bash
export OPENLINEAGE_URL=http://localhost:5000
nova lineage emit-openlineage ~/.novafabric/runs/
```
