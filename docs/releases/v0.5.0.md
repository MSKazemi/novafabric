# v0.5.0 — Trust Layer completion + Integrations first slice

Released: 2026-05-09

This release completes the v0.4 Trust Layer with signed Evidence Bundles and
opens the v0.5 Integrations track with MCP capture, a transparent MCP proxy,
and the wire-level + plugin foundation accepted in
RFC-0001.

## What's new

### Trust Layer completion (v0.4.3 work)

- **`nova scan-secrets <capsule>`** — read-only post-hoc scan of a capsule's
  `redaction-proof.json`. Supports `--fail-on <severity>` for CI gates and
  `--json` for machine output.
- **`nova redact <capsule>`** — re-scan and re-redact an existing capsule with
  strategy overrides. `--mark-unsafe-skip` and `--clear-unsafe-skips` let you
  whitelist false positives explicitly. Updates `redaction-proof.json` in
  place.
- **`nova export-evidence <capsule>`** — build an Evidence Bundle ZIP per
  [ADR-0011](../decisions.md) with **local-key ed25519
  signing**. Emits in-toto Statement v1 + DSSE envelopes for the run,
  redaction, and lineage predicates; vendors all schemas; embeds a
  `manifest_hash` for tamper detection. Verifiable with stock
  `sha256sum` + any ed25519 verifier — no NovaFabric runtime required to
  audit a bundle. (`--sigstore` keyless flow is queued for v0.5.x.)
- **`cryptography>=44.0`** added as a runtime dependency for signing.

### Integrations — MCP (v0.5 first slice)

- **MCP client-wrapper hook** (`capture/hooks/_mcp.py`) — auto-installed
  during `nova capture`. Wraps `mcp.client.session.ClientSession.call_tool`
  and records every invocation into `tool-calls.jsonl` with
  `transport=mcp` and synthesized JSON-RPC envelopes. Works today, no
  configuration. Primary path per
  [ADR-0015](../decisions.md).

### Integrations — `nova mcp-proxy` (experimental)

- **`nova mcp-proxy --capsule-dir <path> -- <upstream-cmd>`** —
  transparent stdio proxy for uninstrumented MCP clients (Claude Desktop,
  Cursor, third-party SDKs). Records verbatim JSON-RPC envelopes for every
  `tools/call` and tags records with
  `extensions.io.novafabric.capture_method=proxy`.
- **Stdio transport only.** HTTP/SSE transport (`--listen <port>`) is
  deferred to v0.6. Secondary path per ADR-0015.

### Integrations — wire-level + plugins (RFC-0001 Option C)

RFC-0001 was accepted
on 2026-05-08, choosing **Option C — wire-level + plugin entry-point
hybrid** as the primary growth axis. The first two tracks landed in this
release.

- **C-1 — `requests` capture hook + externalized URL registry.**
  - New hook at `capture/hooks/_requests.py` mirrors the `httpx` hook for
    sync `requests` users.
  - **URL registry** at `capture/hooks/_url_registry.yaml` (vendored
    default) classifies outbound HTTP requests as
    `{model_call, tool_call, ignored}`. Users can extend it with
    `~/.novafabric/url_registry.yaml` to teach NovaFabric about new
    providers or self-hosted endpoints — **no package change required**.
  - The existing `httpx` hook re-uses the same registry; behavior is
    consistent across both transports.
- **C-2 — `novafabric.hooks` plugin entry-point contract (experimental).**
  - Third-party packages can publish capture hooks via the
    `novafabric.hooks` entry-point group. Plugins are auto-discovered at
    capture start and installed alongside built-in hooks.
  - `HookProtocol` published as **experimental** — see
    [`docs/integrations/writing-a-hook-plugin.md`](../integrations/writing-a-hook-plugin.md)
    for the author manual and reference plugin.
  - Failure-isolated: a broken plugin logs and is skipped; capture
    continues with the remaining hooks.

## Breaking changes

None. All additions are new files, new CLI subcommands, or additive
schema fields. Existing capsules from v0.4.x validate unchanged.

## Upgrade

```bash
pip install novafabric==0.5.0
# or:
uv add novafabric@0.5.0
```

No migration required.

## Try it

```bash
# Capture an MCP-using agent — tool calls auto-recorded
nova capture python my_mcp_agent.py

# Or wrap an uninstrumented MCP client (Claude Desktop, Cursor):
nova mcp-proxy --capsule-dir .novafabric/runs/manual/ -- \
  npx -y @modelcontextprotocol/server-filesystem /some/path

# Scan a capsule for secret-detection findings
nova scan-secrets .novafabric/runs/<run-id>/ --fail-on high

# Build a signed Evidence Bundle (verifiable with sha256sum + ed25519)
nova export-evidence .novafabric/runs/<run-id>/ --output bundle.zip
```
