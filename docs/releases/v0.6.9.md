# v0.6.9 — Hook installer explicitness + a measured (and disproven) perf hypothesis

Released: 2026-05-09

A small honest release. Refactored `install_all()` to make
SDK-availability checks explicit (find_spec before importing the hook
module), then measured the impact and found the perf hypothesis
behind the refactor was wrong.

The change is kept anyway because the new code is slightly clearer.
This release exists to ship the negative finding and the cleaner
code together — not to claim a perf win that didn't materialize.

## What's new

### `install_all()` now explicitly checks SDK availability before importing each hook module

Previously, `install_all()` eagerly imported all 7 built-in hook
modules at the top of the function, then each hook's `install()`
method did its own `import openai` / `import httpx` / etc. and
caught `ImportError` if the SDK wasn't installed.

Now `install_all()` checks `importlib.util.find_spec(sdk_module)`
first and only imports the hook module if the SDK is actually
present. The hook modules for absent SDKs never enter `sys.modules`.

```python
# v0.6.9 — explicit
for sdk_module, hook_module_path, hook_class_name in _BUILT_IN_HOOKS:
    if not _is_sdk_available(sdk_module):
        continue
    hook_module = importlib.import_module(hook_module_path)
    hook_cls = getattr(hook_module, hook_class_name)
    hook = hook_cls(writer=writer, parent_span_id=parent_span_id)
    hook.install()
    _installed.append(hook)
```

vs

```python
# v0.6.8 — implicit (relied on each hook's install() catching ImportError)
from novafabric.capture.hooks._aiohttp import AiohttpHook
from novafabric.capture.hooks._anthropic import AnthropicHook
# ... 5 more eager imports ...
for HookClass in (...):
    hook = HookClass(writer=writer, parent_span_id=parent_span_id)
    hook.install()  # silently no-ops if SDK not importable
```

## Honest measurement: the perf hypothesis was wrong

The hypothesis behind the refactor: `find_spec()` should be
substantially cheaper than full hook-module imports for absent SDKs,
saving ~150 ms of subprocess startup for workloads that have no AI
SDKs installed.

Apples-to-apples measurement (inner subprocess + sitecustomize
running `install_all()` 30 times each, in identical envs):

```
v0.6.9 (find_spec) median= 186.6 ms  stdev= 10.6 ms
v0.6.8 (eager)     median= 188.2 ms  stdev= 10.7 ms
                                               ──────
                                               1.6 ms (within noise)
```

The hypothesis was wrong because **`find_spec()` walks the same
import-system machinery as a real import**. For the small hook
modules in this package (~5–10 KB each), the find_spec call costs
about as much as the import itself. Calling find_spec 7 times
balances out the avoided imports.

The change is kept anyway because:

- Intent is more explicit (check then import vs try-then-recover)
- Hook modules for absent SDKs no longer pollute `sys.modules`
- If a future hook module ever has a slow import (e.g., adds heavy
  schema validation), the skip will start mattering

## Where real subprocess-startup wins live (queued)

Real subprocess-startup reduction now requires architectural changes:

- **Leaner novafabric package init chain.** The `novafabric` package's
  `__init__.py` and the `novafabric.capture.*` subpackage `__init__.py`
  files have transitive imports (typer, rich, opentelemetry-sdk,
  pydantic models). Each is paid on every subprocess startup. Slimming
  them is a real win but invasive.
- **`sys.audit` / `sys.meta_path`-based deferred install.** Don't
  install hooks at sitecustomize time — register an audit hook that
  fires when the target SDK is imported, and only then install. Most
  workloads import few or no SDKs, so most subprocesses pay zero
  hook-install cost. More complex; risks missing the first call if
  the SDK has heavy module-level code.
- **In-process capture mode.** `python -m nova.capture` runs the
  workload in the same Python process. Saves the ~200 ms inner-
  subprocess startup entirely. Loses subprocess isolation — a
  workload crash crashes `nova` itself.

These are queued for v0.7.x with their trade-offs documented in
`benchmarks/README.md`.

## Quality

- **667 tests passing** (unchanged from v0.6.8)
- **90.03% coverage** maintained
- ruff clean, mypy strict clean across 90 source files

One existing test was inverted: `test_install_all_continues_when_plugin_install_fails`
previously asserted "OpenAIHook always installed"; now correctly
asserts "HttpxHook (always-available built-in) installed AND the
broken plugin is not". Same contract being tested (failed plugin
doesn't break built-ins), expressed against the correct
post-v0.6.9 behavior.
