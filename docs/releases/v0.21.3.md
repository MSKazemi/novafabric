# v0.21.3 — Graceful WebSocket catch-all

**Released:** 2026-05-19

## What changed

### Fixed

- **WebSocket 403 on unknown paths** — added catch-all WebSocket handler before the `StaticFiles` mount so unknown WS connections are closed cleanly with code 4404 instead of falling through to the static file handler (which returned HTTP 403 on WebSocket upgrade).

## Upgrade

```bash
pip install novafabric==0.21.3
```

No migration required.
