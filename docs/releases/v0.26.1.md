# v0.26.1 — Ecosystem Framework Adapters + Differentiation Verification

Released: 2026-05-19

Four new native framework adapters (E-5..E-8, ADR-0078) using each SDK's own
extensibility interface, plus an executable differentiation verification script
(E-3) that machine-tests 10 competitive claims against the live codebase.

---

## What's new

### ADR-0078 — Ecosystem adapter design

[`design/adr/0078-ecosystem-adapters.md`](../decisions.md)
documents why NovaFabric uses native SDK hooks (tracing processors, plugins,
interceptors) rather than executor wrapping — avoiding double-instrumentation,
preserving SDK error semantics, and requiring zero changes to the user's agent
code.

### E-5 — OpenAI Agents SDK adapter (`novafabric[openai-agents]`)

```python
from novafabric.adapters.openai_agents import register_openai_agents
register_openai_agents()  # registers NovaCapsuleTracingProcessor globally
```

- `NovaCapsuleTracingProcessor` implements `TracingProcessor`; registered via
  `add_trace_processor()`.
- Captures every OpenAI Agents SDK trace as a run capsule (tool calls, model
  outputs, error traces).
- Optional extra: `pip install novafabric[openai-agents]` (openai-agents≥0.17.3,
  MIT, Tier A per ADR-0024).

### E-6 — Google ADK adapter (`novafabric[google-adk]`)

```python
from novafabric.adapters.google_adk import make_google_adk_plugin
runner = Runner(..., plugins=[make_google_adk_plugin()])
```

- `NovaAdkPlugin` implements `BasePlugin` with `before_run_callback` /
  `after_run_callback`.
- Optional extra: `pip install novafabric[google-adk]` (google-adk≥1.34.0,
  Apache-2.0, Tier A per ADR-0024).

### E-7 — AWS Bedrock AgentCore adapter (`novafabric[bedrock-agentcore]`)

```python
from novafabric.adapters.bedrock_agentcore import wrap_bedrock_agentcore
client = wrap_bedrock_agentcore(boto3.client("bedrock-agent-runtime"))
```

- `_WrappedBedrockClient` wraps `invoke_agent()` + EventStream parsing for
  `orchestrationTrace`, `preProcessingTrace`, `postProcessingTrace`.
- Optional extra: `pip install novafabric[bedrock-agentcore]` (boto3≥1.43.10,
  Apache-2.0, Tier A per ADR-0024).

### E-8 — A2A adapter (`novafabric[a2a]`)

```python
from novafabric.adapters.a2a import make_a2a_interceptor
client = A2AClient(..., interceptors=[make_a2a_interceptor()])
```

- `NovaA2AInterceptor` implements `ClientCallInterceptor` with `before()` /
  `after()` hooks.
- Implements RFC-0002 §Q4 deferred A2A capture.
- Optional extra: `pip install novafabric[a2a]` (a2a-sdk≥1.0.3, Apache-2.0,
  Tier A per ADR-0024).

### Top-level adapter aliases

```python
from novafabric.adapters import (
    register_openai_agents,
    make_google_adk_plugin,
    wrap_bedrock_agentcore,
    make_a2a_interceptor,
)
```

### E-3 — Executable differentiation table

`scripts/verify_differentiation_table.py` — 10 machine-executable differentiation
claims (D-01..D-10) verified against the live codebase:

```bash
python scripts/verify_differentiation_table.py          # human-readable output
python scripts/verify_differentiation_table.py --json   # CI-friendly JSON
```

Exits 0 if all claims pass, 1 on any failure. Claims cover: capsule schema,
lineage edge vocabulary, evidence bundles, OPA policy gate, RFC 3161 timestamps,
KuzuDB lineage, NIST RMF scoring, OWASP assure, MCP scanner, PII gate.
