# v0.26.0 — Dashboard Scale Hardening + KG Type Fixes

Released: 2026-05-19

Dashboard scale hardening (BL-1/BL-5/BL-6), real-time SSE event feed, DuckDB cost
reporting, and KG pipeline Protocol type fixes eliminating mypy errors.

---

## What's new

### BL-1 — SQLiteMetadataStore hot-path indexes

Six `CREATE INDEX IF NOT EXISTS` indexes added to `SQLiteMetadataStore.__init__()`:

| Index | Column | Benefit |
|---|---|---|
| `idx_runs_started_at` | `runs.started_at` | Dashboard date-range queries |
| `idx_runs_status` | `runs.status` | Status filter in RunsTab |
| `idx_runs_global_run_id` | `runs.global_run_id` | Parent/child lookup |
| `idx_runs_tenant_status` | `(runs.tenant_id, runs.status)` | RBAC-filtered status count |
| `idx_capsules_run_id` | `capsules.run_id` | Capsule-per-run join |
| `idx_capsules_tenant_id` | `capsules.tenant_id` | Tenant isolation scans |

Eliminates full-table scans on all dashboard hot paths. No migration required —
`CREATE INDEX IF NOT EXISTS` is idempotent.

### BL-5 — TanStack Virtual scroll in RunsTab

- `useVirtualizer` (TanStack Virtual) with 65px row height and 10-row overscan.
- Only visible rows are rendered into the DOM; handles 10K+ runs without page bloat.
- Scroll position preserved on re-renders.

### BL-6 — RegistryTab cursor pagination

- Bounded page size (50 assets per page) with **Load More** button.
- Eliminates unbounded `SELECT * FROM assets` on registry open.
- Compatible with the existing SuggestInput autocomplete.

### SSE live feed — `/api/events/runs`

- Server-Sent Events endpoint streams run state-change events to the dashboard.
- Dashboard RunsTab subscribes on load; new runs appear without polling.
- Falls back gracefully when SSE is unavailable (browser close, proxy timeout).

### DuckDB cost reporting

- When `NOVA_EVIDENCE_DUCKDB_PATH` is set, `/api/cost/report` reads real aggregate
  cost data from the DuckDB accumulator (v0.25.1) instead of the stub backend.
- Stub backend remains active when `NOVA_EVIDENCE_DUCKDB_PATH` is unset.

### B-2 — KG pipeline Protocol types

- `_AliasResolverProtocol` and `_ReviewQueueProtocol` replace `object | None`
  parameters in `KGIngestionPipeline.__init__()`.
- Resolves 8 `mypy attr-defined` errors in Tier 2/3 KG wiring.
- No API change — callers pass the same `AliasTableResolver` / `HumanReviewQueueWriter`
  objects as before.

---

## Upgrade notes

- No breaking changes.
- Indexes are created at startup; existing SQLite databases are upgraded
  automatically on first run.
- To enable live cost data: set `NOVA_EVIDENCE_DUCKDB_PATH=<path/to/evidence.db>`.
