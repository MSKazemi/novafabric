# NovaFabric v0.12.10 Release Notes

**Released:** 2026-05-14
**Type:** Dashboard crash fix (patch)
**Prior release:** [v0.12.9](v0.12.9.md)

---

## Summary

Two React components — `AuditTab` and `LineageTab` — crashed with React error #310
("Rendered more hooks than during the previous render") when navigated to, producing
a completely blank white page. Root cause: `useMemo` calls placed after conditional
early-return guards, violating the [Rules of Hooks](https://react.dev/warnings/invalid-hook-call-warning).

No CLI, schema, server API, or Python changes. Dashboard bundle rebuilt to
`DashboardApp.DQMSHUV2.js`.

---

## Bug fixes

### AuditTab — blank page on navigation (React error #310)

**File:** `web/src/components/dashboard/tabs/AuditTab.tsx`

The `availableActions` memo was declared after the `if (error && !entries)` and
`if (!entries)` early returns. On the first render, `entries` is `null`, so the
component returned `<Loading />` before the memo hook ran. On a subsequent render
with data, React saw more hooks than on the first render → fatal hook-count mismatch.

**Fix:** Moved `useMemo` before the early-return guards; added `(entries ?? [])` null
guard so the memo runs safely with no data yet.

### LineageTab — blank page on navigation (React error #310)

**File:** `web/src/components/dashboard/tabs/LineageTab.tsx`

Same pattern: `ancestors = useMemo(…)` was positioned after `if (!edges || !assets)`
on line ~300, while the loading guard was on line ~268. Same null-data / hook-count
mismatch on first render.

**Fix:** Moved `ancestors` memo before all early returns; rewrote to depend only on
`selectedNode` and the raw `edges` state (no derived `adaptedEdges` / `filteredEdges`
needed at that point). Added `if (!selectedNode || !edges) return []` as the first
line inside the memo to short-circuit safely.

## Upgrade notes

No migration required. Restart `nova serve --experimental` to pick up the new bundle.

```bash
pkill -f "nova serve"
uv run nova serve --experimental
```

If accessing the dashboard from a remote host via the `lpt` toolbox:

```bash
cd ~/scratch/lpt
make -f Makefile.local nova-serve-stop
make -f Makefile.local nova-serve-start
make -f Makefile.local nova-dashboard
```

## Verification

After upgrade, navigate to the **Audit** and **Lineage** tabs. Both should render
immediately without a blank page. The Audit tab shows the action-type filter dropdown
(DU-6) and entry list; the Lineage tab shows the graph canvas, query panel, and edge
legend.
