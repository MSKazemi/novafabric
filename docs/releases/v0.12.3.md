# v0.12.3 — Per-Tenant Merkle Log (ADR-0057)

Released: 2026-05-14

Formalizes ADR-003 from the regulated-industries SoA2Prod study as ADR-0057, resolving
the final "Postgres conflict check" blocker on D-3. The SQLite Merkle log already ships
in `src/novafabric/trust/novaseal/merkle.py`; this release freezes the design for the
Postgres backend (v0.13+) and integrates the Merkle log into ADR-0022's authoritative
polyglot-persistence storage tier map.

## What's new

### ADR-0057 — Per-Tenant Append-Only Merkle Log

`design/adr/0057-per-tenant-merkle-log.md`

Formalizes the transparency log topology decision. Key design points:

**Why per-tenant?** Regulated operators (banks, hospitals, pharma) cannot send capsule
hashes or audit metadata to third-party infrastructure — even hashes without payload can
constitute metadata leakage in M&A or clinical-trial contexts. Per-consortium and
public-Rekor topologies are rejected for the default deployment.

**Tree structure:** RFC 6962 §2.1 domain separation (leaf: `H(0x00 ‖ entry_bytes)`,
internal: `H(0x01 ‖ left ‖ right)`), SHA-256, padded to next power-of-two root.
Identical to Certificate Transparency — existing CT verification tooling validates the
tree shape.

**Leaf entry format:** Signed JSON bound to the DSSE capsule manifest hash:

```json
{
  "event_type": "capture | promote | rollback | retain | delete_proposal",
  "capsule_id":  "<ulid>",
  "tenant_id":   "<str>",
  "actor":       "<subject from signing cert or key-id>",
  "timestamp":   "<RFC 3339>",
  "payload_hash": "<sha256 hex of capsule manifest>"
}
```

**Storage tiers:**

| Mode | Backend | Status |
|---|---|---|
| Local / single-operator | SQLite (`src/novafabric/trust/novaseal/merkle.py`) | **ships today** |
| Server / multi-user | Postgres table in `PostgresMetadataStore` | **deferred to v0.13+** |

**Federation:** CAP-016 (sharing signed tree-head checkpoints with a consortium
witness) is documented as a future track. The per-tenant log is the stepping stone.

### ADR-0022 update — storage tier table

The polyglot-persistence map in ADR-0022 now includes:

```
| Merkle log (NovaSeal) | SQLite (local) → Postgres (server, v0.13+) | ADR-0057 |
```

This was the "conflict check" that had previously blocked D-3 — resolved by a
one-row addition that keeps ADR-0022 as the single authoritative storage tier index.
