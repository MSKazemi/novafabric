# NovaFabric v0.51.0 — Collector Productization Slice

**Released:** 2026-06-12

The SPK-COL spike gate on ADR-0020 closed this morning (all three spikes PASS
on real infrastructure); this release ships the first productized increments
from those results. Everything here is **experimental**.

## Highlights

### `nova collector rebuild` — offset-replay recovery (SI-1)

```bash
nova collector rebuild --target ./rebuilt --report rebuild-report.json
```

Replays the durable JetStream event buffer from offset 0 into per-run JSONL
partitions, reporting per-run sha256 digests and `seq`-order preservation —
the disaster-recovery property proven by SPK-COL-1 (byte-equal rebuild,
per-run order, zero loss across an RF1 broker restart). Unattributed events
are partitioned, never dropped; order violations exit 2. Requires
`novafabric[scale]`.

### OTel-Arrow wire profile (SI-3)

`deploy/collector-arrow/` carries sender/receiver configs for stock
`otelcol-contrib` (v0.154.0+) putting the spool→central hop on OTel-Arrow:
**31.5 % measured egress reduction** vs OTLP+zstd at identical batch settings
(SPK-COL-3, reproducible via `benchmarks/spk_col3/`), with
`disable_downgrade: true` so a misconfigured pair fails loudly. Sender memory
stayed bounded (237 MiB max RSS) under a 10× burst.

### Decision records caught up with reality

- **ADR-0020 Accepted** — its spike gate (SPK-COL-1/2/3) fully closed:
  offset-replay 3/3 · +0.36 % per-call hot-path overhead · 31.5 % Arrow
  egress reduction. The full resident-emitter collector rework is the next
  feature branch.
- **ADRs 0086–0090 + ADR-0041 v0.2 Accepted** — the Wave-2 first slices
  shipped and tested in v0.50.0.

### Test depth

43-test serve coverage campaign across the largest previously-uncovered
handlers (seal log verify, audit routes, governance classify, reports, KG
topology cache, SSE auth, evidence routes), plus 10 rebuild tests including
an env-gated live-JetStream integration round-trip.

## Compatibility

No breaking changes. `nova collector` is a new sub-app; all other surfaces
are unchanged from v0.50.1.
