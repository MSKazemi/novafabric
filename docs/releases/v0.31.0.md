# NovaFabric v0.31.0 — Dashboard CLI parity sprint: 7 gaps closed

**Released:** 2026-05-20

## Highlights

- Seven CLI commands that previously had no dashboard equivalent now have dedicated panels
  across KGTab, ComplianceTab, and RunsTab.
- 2 new REST endpoints (`GET /api/kg/aliases`, `POST /api/kg/aliases`); 8 new API client
  methods; 9 new backend tests.
- 3837 total tests passing.

---

## What's new

### Dashboard — KG Query panel (KGTab)

`nova kg query` now has a dashboard equivalent.  Enter a Cypher-style entity search in the
new **KG Query** panel and view results in a structured table.

Backed by: existing KG query endpoints.

### Dashboard — KG Audit panel (KGTab)

`nova kg audit` now has a dashboard equivalent.  The new **KG Audit** panel displays:

- Orphaned-edge count
- Zero-call-count anomalies

Backed by: `GET /api/kg/audit`

### Dashboard — Entity Queue panel (KGTab)

`nova kg entity-queue` now has a dashboard equivalent.  The new **Entity Queue** panel
provides:

| Feature | Description |
|---|---|
| Pending items | List of entities awaiting review |
| Approve / Reject | One-click actions per queue item |
| Queue stats | Aggregate counts for pending, approved, and rejected items |

Backed by: `GET /api/kg/entity-queue`, `GET /api/kg/entity-queue/stats`,
`POST /api/kg/entity-queue/{id}/approve`, `POST /api/kg/entity-queue/{id}/reject`

### Dashboard — KG Alias panel (KGTab)

`nova kg alias list` and `nova kg alias register` now have a dashboard equivalent.  The new
**KG Alias** panel shows an alias → canonical mapping table and includes a registration form
for adding new aliases.

Backed by: `GET /api/kg/aliases` (new), `POST /api/kg/aliases` (new)

### Dashboard — Erasure Status section (ComplianceTab → GdprErasurePanel)

`nova erasure status` now has a dashboard equivalent.  An erasure-status check section has
been added to the existing **GDPR Erasure** panel in ComplianceTab.

Backed by: existing erasure endpoints.

### Dashboard — Audit Map panel (ComplianceTab)

`nova audit map --profile` now has a dashboard equivalent.  The new **Audit Map** panel
displays a compliance coverage grid for 6 audit profiles.

Backed by: `GET /api/compliance/audit/map`

### Dashboard — Children view (RunsTab)

`nova run show --with-children` now has a dashboard equivalent.  Selecting a parent run in
RunsTab surfaces a children view showing:

- Parent capsule metadata
- Child-run tree for distributed runs

Backed by: `GET /api/runs/{run_id}/children`
