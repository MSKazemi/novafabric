# v0.9.0 — Standard Eval Suites

Released: 2026-05-11

This release closes the eval gap that has existed since v0.1: agent promotion gates now
execute real benchmarks in reproducible OCI-pinned containers, detect statistical
regressions between runs, and block promotion via Rego when a regression is detected.
All features work locally without a server.

## What's new

### Eval suite protocol + CLI (E-0 through E-3)

- **`EvalSuiteAdapter` protocol** (`evals/adapter.py`) — the extension point for any
  benchmark. Conforming classes are discovered via the `novafabric.eval_suites`
  entry-point group.
- **`EvalResult` / `Metric` / `StatisticalContext`** Pydantic v2 models
  (`evals/result.py`) — structured benchmark output that the policy engine can
  interrogate.
- **`EvalSuiteError`** — domain exception raised by all adapters on infrastructure or
  parsing failure.
- **`load_eval_suite(suite_id)`** — entry-point loader; raises `EvalSuiteError` with a
  clear message when the suite is not installed.
- **`novafabric-smoke-v1` adapter** — host-env adapter that validates capsule schema
  without a container. Useful for CI pipelines that do not have Docker.
- **`nova eval run <capsule> --suite <id> [--config k=v ...]`** — runs a suite against
  a capsule and prints a rich table result; exit 1 on failure.

### Container-deterministic execution (E-4)

- **`DockerRunner.run_eval_container()`** — verifies the OCI image digest before
  running; pulls if absent; launches `docker run` with the capsule directory mounted
  read-only; parses stdout as `EvalResult` JSON. `ContainerEvalError` raised on any
  infrastructure failure.
- **`EvalSuiteAdapter` protocol extended** with `oci_image()` and `container_argv()`.
  Host-env adapters return `""` / `[]`; container adapters return the pullable image
  reference and the in-container argv. `ContainerEvalRunner` dispatches transparently.

### Built-in eval suite adapters (E-5, E-7, E-8)

Five adapters ship out of the box, all registered as `novafabric.eval_suites`
entry-points:

| Entry-point | Class | Benchmark |
|---|---|---|
| `novafabric-smoke-v1` | `SmokeAdapter` | Schema validation (host-env) |
| `gaia-v1` | `GaiaAdapter` | GAIA General AI Assistants |
| `swe-bench-verified-v1` | `SweBenchAdapter` | SWE-bench Verified |
| `agentbench-v1` | `AgentBenchAdapter` | AgentBench multi-environment |
| `mmlu-v1` | `MmluAdapter` | MMLU (57 academic subject areas) |
| `truthful-qa-v1` | `TruthfulQaAdapter` | TruthfulQA |

All OCI-based adapters use env-var-configurable digests. Set
`NOVAFABRIC_{SUITE}_OCI_DIGEST` and `NOVAFABRIC_{SUITE}_OCI_IMAGE` to pin real
published images. When the digest env var is unset (the default), the adapter returns
`""` and `ContainerEvalRunner` falls back to host-env mode via `adapter.run()`.

Example for GAIA:
```bash
export NOVAFABRIC_GAIA_OCI_DIGEST="sha256:<64-hex>"
export NOVAFABRIC_GAIA_OCI_IMAGE="ghcr.io/novafabric/gaia-eval:v1"
nova eval run /path/to/capsule --suite gaia-v1
```

### Statistical regression detection (E-6)

- **`RegressionDetector`** (`evals/_stats.py`) — two-sample z-test (Python stdlib
  only, zero new runtime dependencies) with delta-threshold fallback for when
  `StatisticalContext` is absent from either result. Configurable `alpha` and
  `min_samples` thresholds.
- **`RegressionReport` / `MetricComparison`** — structured output of a comparison run;
  includes per-metric delta, relative delta, p-value, and a top-level
  `regression_detected` flag.
- **`nova eval compare <baseline.json> <candidate.json> [--alpha 0.05] [--min-samples 30]`**
  — prints a rich table of metric deltas, p-values, and significance; exit 1 when
  `regression_detected` is true.

### Rego regression gate (E-9)

- **`regression_gate.rego`** — new built-in Rego policy (alongside `promote_gate`,
  `evidence_export`, `replay_mutating`, `dataset_license`):

  | Condition | Result |
  |---|---|
  | `regression_report.regression_detected == false` | allow |
  | `regression_report.regression_detected == true` | deny — "regression detected in eval comparison" |
  | `regression_report` field absent | deny — "regression_report not present in policy input" |

- **`PolicyResource.regression_report`** — new optional field (`dict | None`). Callers
  populate it with `RegressionReport.model_dump(mode="json")` before passing to
  `get_policy_engine().evaluate()`.

  Example promotion gate with regression check:
  ```python
  from novafabric.evals._stats import RegressionDetector
  from novafabric.policy import PolicyInput, PolicyResource, PolicySubject, get_policy_engine

  report = RegressionDetector().compare(baseline_result, candidate_result)
  engine = get_policy_engine()
  decision = engine.evaluate(PolicyInput(
      action="promote",
      subject=PolicySubject(user=current_user, roles=current_roles),
      resource=PolicyResource(
          kind="capsule",
          ref=capsule_id,
          regression_report=report.model_dump(mode="json"),
      ),
  ))
  if not decision.allow:
      raise PolicyDeniedError(decision.reason)
  ```

## Upgrade notes

No breaking changes. All new fields are optional. Existing `PolicyResource` instances
without `regression_report` continue to work.

The `novafabric-smoke-v1` entry-point from v0.9-p1 is unchanged.
