# v0.21.4 — nova doctor novaseal_db path + OPA in Docker image

**Released:** 2026-05-19

## What changed

### Fixed

- **`nova doctor` novaseal_db path** — replaced hardcoded `~/.novafabric/novaseal.db` path with `NOVAFABRIC_HOME`-resolved path so the health check passes when data lives under a custom root directory (e.g. `/data/nova` in Docker deployments).
- **OPA health check in Docker** — added OPA binary health check to `docker/Dockerfile` so `nova doctor` in container mode correctly reports OPA as available.

## Upgrade

```bash
pip install novafabric==0.21.4
```

No migration required.
