# v0.12.14 — Static Bundle Rebuild

Released: 2026-05-15

Rebuilds the pre-built static dashboard that ships inside `nova serve`. No
Python source changes; the only artefact updated is
`src/novafabric/serve/static/`.

---

## Background

`nova serve --experimental` serves a pre-built Astro/React site from
`src/novafabric/serve/static/`. That directory is **not tracked by git** and
must be rebuilt explicitly with `make bundle` (or `npm run build:dashboard`
inside `web/`) before each tagged release.

The v0.12.10 release fixed a React Rules-of-Hooks crash (`useMemo` placed
after early-return guards in `LineageTab` — React error #310). The fix was
committed to `web/src/` but `serve/static/` was not rebuilt at the time of
tagging, so every user of `nova serve` between v0.12.10 and v0.12.13 still
experienced the broken behaviour.

---

## Fixed

### Lineage node click — detail panel now updates

**Symptom:** clicking a run or asset node in the Lineage tab of
`nova serve --experimental` left the right-side panel showing "No node
selected" regardless of which node was clicked.

**Root cause:** the stale bundle still contained the pre-v0.12.10 code where
`useMemo(ancestors)` was placed *after* the `if (!edges || !assets) return
<Loading />` guard in `LineageTab.tsx`. On navigation to the tab React threw
error #310, the component remounted, and `selectedNodeId` reset to `null` —
erasing any click before it could render.

**Fix:** `serve/static/` rebuilt from v0.12.14 source; contains the hook
reordering already committed in v0.12.10 (commit `7131641`).

## Infrastructure note for maintainers

Add `make bundle` to the release checklist **before** tagging. The Makefile
target is:

```makefile
bundle:
    cd web && npm run build
    rsync -a --delete web/dist/ src/novafabric/serve/static/
```

Alternatively, from `web/`:

```bash
npm run build:dashboard   # astro build + node scripts/copy-dashboard.mjs
```

---

## Upgrade notes

No action required for users who run `uv pip install novafabric` from source
or PyPI — the corrected `serve/static/` is included in the wheel.

Users who cloned the repository and are running directly from source should
run `make bundle` (or `npm run build:dashboard`) once to refresh their local
`serve/static/`.
