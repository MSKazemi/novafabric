### RFC 3161 chain tests (+12 in modified file)

Added to `tests/trust/test_rfc3161.py`:

- `test_http_error_non_transport_raises` — `HTTPStatusError` (non-`TransportError`) wraps to `TimestampError`
- `test_parse_pki_status_wrong_status_tag_raises` — non-INTEGER first child → `TimestampError`
- `test_parse_pki_status_generic_exception_wraps` — truncated inner sequence → `TimestampError`
- `test_extract_nonce_long_form_outer_sequence` — nonce extraction with 2-byte outer-length encoding
- `test_extract_nonce_long_form_inner_sequence` — nonce extraction with 2-byte inner-length encoding
- `test_verify_tsa_chain_stub_der_no_cert` — empty cert set → early return, `chain_ok=False`
- `test_verify_tsa_chain_empty_trusted_ca_pem` — empty CA PEM → `chain_ok=False` (no crash)
- `test_verify_tsa_chain_never_raises` — guaranteed no-raise on garbage input
- `test_extract_signing_cert_empty_der` — empty bytes → empty list, no raise
- `test_extract_signing_cert_garbage_der` — garbage bytes → empty list, no raise
- `test_get_ocsp_url_non_cert` — non-cert object → `None`, no raise
- `test_get_crl_urls_non_cert` — non-cert object → `[]`, no raise

- Patching pattern documented in tests: local imports inside function bodies must be patched at the *source* module (`novafabric.X.Y`) not at the caller's namespace.
- `novafabric.trust._rfc3161._der_null` is now imported at the test module level alongside other DER helpers.
