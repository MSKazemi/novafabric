# NovaFabric v0.89.0 — 2026-07-25

**The ADR-0107 compliance exporters now have a command line.** `nova export-compliance`
surfaces four shipped exporters — NIST GenAI/CSA profile, ISO/IEC 42001, GPAI Art. 53,
and Art. 72 PMM — each reading a capsule or a JSON input and writing a report you can hand
to an auditor. `experimental`. Full detail: `CHANGELOG.md` §[0.89.0].

## Highlights

### `nova export-compliance` — four exporters, one command group

Until now the ADR-0107 exporters were programmatic (`build_*` functions). This release
wraps four of them in a coherent CLI cohort. Each subcommand reads its input and writes
report JSON to `--out` (or stdout):

```
nova export-compliance genai-profile ./capsules/run-123 --evidence tool_permissions --out profile.json
nova export-compliance iso42001 --catalog controls.json --evidence eval_gate --capsule-id run-123 --out iso.json
nova export-compliance gpai53 --model my-gpai --fields art53.json --out form.json
nova export-compliance pmm --system triage --findings findings.json --occurred-at 2026-07-01 --out pmm.json
```

- **`genai-profile`** is capsule-driven: it builds the capsule's NIST-RMF report through
  the shipped `NISTAIRMFReporter` and overlays the NIST GenAI + CSA Agentic profile
  (NF-097) — a real end-to-end integration, not just a serializer.
- **`iso42001`** maps a declared control catalog to present evidence (NF-095). Honest by
  construction: without a `--capsule-id` to anchor a re-performable reference, evidenced
  controls degrade to `not_evidenced` rather than over-claim.
- **`gpai53`** seals the first revision of a GPAI Art. 53 documentation form (NF-093).
- **`pmm`** compiles an Art. 72 post-market-monitoring report; a serious finding refers an
  Art. 73 incident (NF-091), and a serious finding without a classification fails the
  command rather than silently dropping the escalation.

### The dashboard already knows about them

Adding CLI commands trips two coverage guards by design — the command registry the
dashboard's Commands tab renders, and the ADR-0200 parity classification. Both were
regenerated: `generatedCommands.ts` now lists 288 commands, `commandParity.json` classifies
the four new commands as `builder-only`, and the dashboard bundle was rebuilt. "Every CLI
capability is in the dashboard" stays true.

### Scope, honestly

The CLI only parses arguments and serialises results — all the compliance logic stays in
`novafabric.compliance.export`, tested without a CLI. Two ADR-0107 exporters are not yet
wrapped: NF-090 (Art. 12) already has its own `nova euaiact` surface, and NF-094 (Art. 50
dual-layer receipt) needs a C2PA-manifest input better suited to the existing
`nova export-c2pa` flow — both deliberate. Zero new dependencies.

## Upgrade notes

Additive — a new command group (`nova export-compliance`) and its module; regenerated
dashboard registry, parity classification, and static bundle. No breaking changes, no new
dependencies.
