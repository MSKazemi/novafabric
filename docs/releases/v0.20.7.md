# v0.20.7 — Topology white/light theme

**Released:** 2026-05-19

## What changed

Topology panel backgrounds (2D Sigma container and TV-5 Three.js canvas) switched from dark to `bg-white` / `bg-slate-50` to match the Tailwind light theme used across the rest of the dashboard.

## Upgrade

```bash
pip install novafabric==0.20.7
```

No migration required.
