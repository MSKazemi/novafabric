# v0.19.2 — Dashboard stability + lineage graph routing

**Released:** 2026-05-18

Three targeted fixes eliminating an infinite API request loop, correcting lineage
graph edge routing, and refreshing the cost price table.

---

## What shipped

### Fixed

**Infinite API request loops on Lineage, Audit, Registry, Evidence tabs**

All four tabs had `onCountChange` in their `useCallback` dependency arrays.
Because `onCountChange` is a new function reference on every parent render, this
caused an unbounded re-render cascade (1000+ requests/sec on mount). Fix: remove
`onCountChange` from every tab's `useCallback` dep list; access it via a stable
`useRef` instead. RunsTab already used this pattern; now consistent across all tabs.

**Lineage graph edges routed vertically instead of horizontally**

dagre `rankdir: 'LR'` layout requires `sourcePosition: Right` and
`targetPosition: Left` on every ReactFlow node. Previously both were `Bottom/Top`,
causing edges to exit and enter from the wrong sides of nodes.

**Cost price table outdated**

`PRICE_TABLE` in `cost/interceptor.py` updated with:
- Claude 4.x: Opus 4.7, Sonnet 4.6, Haiku 4.5 / Haiku 4 (current per-token prices)
- OpenAI: gpt-4o-2024-11-20, o1, o3-mini, gpt-4o-mini (current pricing)
