# NovaFabric v0.1.0

## Summary

NovaFabric v0.1.0 is the first self-contained AI Asset Registry release.

## Highlights

- YAML AI asset specification
- Pydantic validation
- SQLite local registry
- CLI commands:
  - register
  - list
  - inspect
  - promote
  - eval
  - diff
  - report
  - validate
- Agent lifecycle management
- Eval-gated agent promotion
- OTel `@novafabric.agent` decorator
- Markdown and JSON reporting
- Getting-started guide
- CLI reference

## Quality gates

- 56 tests passing
- 90% coverage
- ruff passed
- mypy passed
- smoke test passed

## Out of scope

- Web UI

- Authentication/authorization
- HPC/SLURM execution
