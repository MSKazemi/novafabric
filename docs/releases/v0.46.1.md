# NovaFabric v0.46.1 — Type-integrity patch (mypy 85 → 0)

**Released:** 2026-06-11 · **Status:** experimental · **Breaking changes:** none

## Summary

The v0.46.0 environment rebuild (stale venv shebangs from the repo move)
unmasked 85 pre-existing `mypy --strict` errors across 35 files. This patch
fixes all of them — including one **real runtime bug** the type checker
caught — and adds a CI job that prevents the class of drift from recurring.

## Fixed

### Sigstore signer ported to sigstore-python 4.x (runtime bug)

`SigstoreSigner.sign_artifact` / `verify_bundle` were written against the
removed 3.x API (`Signer.production()`, `Verifier.verify`, string
`Hashed.algorithm`) and would have crashed on any live keyless sign or
verify (tests only exercised the ImportError paths). Now:

- signing uses `SigningContext.from_trust_config(ClientTrustConfig.production())`
  with ambient-credential detection (`detect_credential`, e.g. GitHub
  Actions / GCP) and an interactive `Issuer` OAuth fallback;
- verification uses `Verifier.verify_artifact(artifact, bundle, UnsafeNoOp())` —
  the same no-identity-policy semantics as before: signature, SCT, and Rekor
  inclusion are verified; the signing identity is extracted and surfaced for
  human review.

### Other correctness fixes

- **RFC 3161 chain validation** (`trust/_rfc3161.py`): typed
  `get_extension_for_class` extension access; isinstance narrowing of issuer
  public keys (EC / RSA, explicit failure message for unsupported types);
  guard for hash-less (Ed25519/Ed448) issuer signatures.
- **GCP KMS signing**: passes a typed `kms.Digest(sha256=…)` message instead
  of a raw dict.
- **`nova redact`** seal step skips cleanly when the NovaSeal profile has no
  key/cert paths (previously crashed into the warning handler).

### Type hygiene

- 27 stale `# type: ignore` comments removed; wrong ignore codes corrected.
- Wire-hook monkey-patching (`requests`, `urllib3`, `aiohttp`, `openai`,
  replay dispatcher) annotated with precise `method-assign` ignores.
- Bare `dict` generics filled in (`kg/`, `cli/asset.py`); Avro deserializers
  narrow records before `dict()`; `count_cached_runs` returns a real `int`.

## CI

- New **`typecheck` job**: `uv sync --frozen --all-extras` + `mypy strict`,
  so optional integrations (sigstore, kuzu, clickhouse, adapters, …) are
  type-checked against their real APIs instead of being silenced as missing
  imports. The unit-test job stays lean so the 90% coverage gate's
  denominator is unchanged.
- `clickhouse_connect`, `weasyprint`, `presidio_analyzer` added to the
  pyproject mypy overrides (installed-but-untyped optional deps).

## Upgrade

```bash
uv pip install --upgrade novafabric
```

No schema, CLI, or API breaking changes.
