# v0.22.0 — Evidence Fabric scale-out + TV-5 3D topology completions

**Released:** 2026-05-19

## What changed

This release closes the remaining Tier B and selected Tier A correctness gaps
identified in the 2026-05-19 nova-design audit (593 docs). Four independent
tracks merged into main.

### Added

#### B-1 — TV-5 3D topology component completions

- **`LODController.tsx`** — `useLOD(camera, clusters, focalClusterId)` hook
  runs inside `useFrame` each tick; collapses clusters below 60 px
  screen-diameter into Sprite supernodes; sets non-focal opacity to 0.15. All
  state lives in refs — zero React reconciler re-renders.
- **`TimeSlider.tsx`** — 3-phase animated time slider: fade-out (200 ms) →
  topology swap → fade-in (200 ms). Play/pause at 2 s interval. LIVE badge
  toggled between `<span>` and `<button>`.
- **`tv5Store.ts`** — Zustand 5 cross-panel state store: `selectedNodeId`,
  `focalClusterId`, `selectedWindowId`, `cameraState`.
- **`visualization/models.py`** — Pydantic v2 contracts `NodeRecord`,
  `ClusterRecord`, `WindowRecord`, `TopologySnapshot`. `from_raw()` maps
  `compute_node → compute`.
- **TTL retention in `SnapshotStore3D`** — `evict_expired()` removes
  fine-tier snapshots >24 h and coarse-tier >7 d. Background asyncio loop
  runs every 300 s on router startup.
- **Prometheus metrics** — `novafabric_layout_duration_seconds`,
  `novafabric_layout_run_total`, `novafabric_snapshot_size_bytes`. Gracefully
  absent when `prometheus_client` not installed.
- **msgpack deserialization in `TV5Panel.tsx`** — `Accept: application/msgpack`;
  JSON fallback retained.
- New npm deps: `zustand ^5.0.0`, `@msgpack/msgpack ^3.1.3` (MIT/Apache-2.0).

#### B-3 — Evidence Fabric scale-out (cap-002, ADR-0066)

- **ClickHouse AggregatingMergeTree MV** (`nova.cost_by_model_mv`) — stores
  `sumState`/`countState` partial aggregates; new `query_cost_report()` queries
  via `sumMerge`/`countMerge` for efficient per-tenant/model/date breakdowns.
  `nova cost report --mv` flag activates MV path.
- **DualObjectStore** — `split_and_store()` routes the redacted compliance
  payload and the raw PII payload to separate S3 buckets via `NovaObjectStore`.
  PII path is gated on `NOVA_CAP003_ENABLED=1`.
- **LineageConsumer bulk COPY** — `bulk_insert_edges()` writes edges to a
  temporary Parquet file via DuckDB→PyArrow then `COPY FROM` into KuzuDB;
  temp file removed on success and error; `pyarrow` guard raises `ImportError`
  with install hint when absent.
- **LineageConsumer NATS JetStream pull consumer** — `run_from_nats()` pulls
  from a JetStream subject; `NOVA_INTEGRATION` feature gate; asyncio task
  lifecycle with clean shutdown.

### Fixed

#### A-1 — Live delta push (topology correctness)

`DeltaBuffer.enqueue()` now immediately notifies all registered WS subscriber
callbacks. Spawn-to-canvas latency drops from ~10 s (heartbeat cycle) to <1 s.

#### A-2 — Binary Arrow IPC delta transport

All 7 TDP delta event types are now sent via `websocket.send_bytes()` as
`ads.v1.delta_event` Arrow IPC frames. `TDPClient._handleBinaryFrame()` routes
frames by schema ID through `_decodeDeltaEventFrame()` back into existing
handlers. Matches ADR-002 binary transport spec.

#### A-3 — Collector dead-letter queue

`collector/internal/spool/dlq.go`: file-based DLQ written on `spool.Write()`
failure. Path configurable; `dlq_entries_total` Prometheus counter; DLQ tests
in `dlq_test.go`.

#### A-7 — Ed25519 envelope support

`trust/novaseal/envelope.py` now verifies Ed25519 public keys alongside ECDSA
P-256. Aligns Python verifier with the Go collector's Ed25519 signature
emission; backward-compatible (existing ECDSA capsules continue to verify).

## Upgrade

```bash
pip install novafabric==0.22.0
```

No migration required. All new features are additive or gated on opt-in env
vars (`NOVA_CAP003_ENABLED`, `NOVA_INTEGRATION`, `NOVA_CLICKHOUSE_URL`).
