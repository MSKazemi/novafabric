# v0.101.0 — the enterprise-grade program: ten first slices

**Released 2026-08-07.** One theme: before this release, a NovaFabric deployment was
*single-instance, single-key, single-region, best-effort-on-restart, and contractually
silent*. Ten design decisions (ADRs 0240–0249) each got their first working slice —
every one additive, off-by-default where it changes behavior, and honest in its docs
about what stays planned.

## What's in it

| Area | What you can do now |
|---|---|
| **Durable jobs** (ADR-0242) | Replay jobs survive restarts and report correct status across `--workers` processes; interrupted work reads `failed` with an explicit error — never silently lost. The `novafabric.jobs` store/runner (lease-claimed, worker-guarded, bounded retries) is the substrate the other job kinds migrate onto. |
| **Native TLS** (ADR-0241) | `nova server start` and `nova serve --tls-cert/--tls-key` terminate TLS themselves — for HPC nodes and VMs with no reverse proxy. Fail-closed launch validation; proven by a real HTTPS round-trip test. |
| **Writer lease + fencing** (ADR-0244) | The split-brain-proof core: a Postgres-anchored (SQLite-twinned) single-writer lease whose fencing token bumps on every holder change. Automated promotion stays planned; manual failover is now hardenable. |
| **Per-tenant keys** (ADR-0243) | Each tenant's capsules can wrap DEKs under that tenant's own KEK; removing one tenant's key makes exactly that tenant's data unreadable — fail-closed, named error, tenant-scoped blast radius. |
| **Jurisdiction routing** (ADR-0247) | Capsule writes route to the backend registered for the tenant's jurisdiction, **fail closed** when unroutable; cross-border reads deny by default through the (previously unconsumed) ADR-0077 residency gate. New: `docs/ops/data-residency.md`. |
| **Step-up auth + audit fix** (ADR-0246) | Role grant/revoke now writes the hash-chained audit log. Opt-in step-up: destructive calls (role mutations, capsule delete) require fresh OIDC auth or get 401 `step_up_required`. |
| **Dashboard API contract** (ADR-0240) | `api/openapi-dashboard.yaml` — the serve surface (198 routes) generated, drift-guarded, with a shrink-only annotation ratchet (195 pending) and the legal-holds family fully declared + conformance-tested. |
| **SLO catalog** (ADR-0248) | `docs/slo.md` — every published performance number labelled `gated`/`measured`/`target`; the three CI gate files read their thresholds from the same catalog, so a claim and its gate cannot disagree; stale measurements expire visibly. |
| **Support policy** (ADR-0245) | `docs/support-policy.md` — what "supported" means today (latest tag), what upgrading promises (the N/N+1 gate), the runtime matrix, and the v1.0 LTS intent. The documented release gate now names every CI job, guarded. |
| **Air-gap bundle** (ADR-0249) | `make airgap-bundle` + an offline verifier: one tar with a DSSE-signed manifest; a flipped byte fails naming the member; unsigned stowaways are findings. |

## Upgrade notes

- **No breaking changes.** All schema changes are additive (`EncryptedBlob.tenant_key_id`,
  jobs/lease tables are new); every pre-existing envelope, capsule, and API response shape
  stays valid. New behaviors (TLS, step-up, tenant keys, jurisdiction routing) are opt-in.
- Replay job state now lives in `$NOVAFABRIC_HOME/jobs.db`; the old in-memory job table
  simply disappears (it never survived a restart anyway).
- New env vars, all optional: `NOVA_TLS_*`, `NOVAFABRIC_SERVER_STEP_UP_*`,
  `NOVA_OBJECT_STORE_TENANT_KEK_DIR`, `NOVAFABRIC_JOBS_DB`.
