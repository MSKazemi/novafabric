# v0.13.1 — Shared EmptyState Component (DU-10)

Released: 2026-05-15

Consolidates eight ad-hoc empty-state patterns across the dashboard into a single
reusable `<EmptyState>` component with three layout variants.

---

## Background

Prior to v0.13.1, each tab implemented its own empty-state differently: some used
a bordered card, some used a flex-centred `<p>`, some showed an inline message.
Audit of the eight call sites found inconsistent spacing, border radius, and color
usage. DU-10 normalises all of them.

---

## Added

### `web/src/components/ui/EmptyState.tsx`

New component with the following interface:

```typescript
interface EmptyStateProps {
  message: ReactNode;          // Main empty-state text
  hint?: ReactNode;            // Optional secondary text
  cliCommand?: string;         // Shorthand for a <code> block hint
  variant?: 'bordered' | 'fill' | 'inline';  // Layout (default: 'bordered')
  className?: string;
}
```

- **`bordered`** — `rounded-lg border` card; default variant. Used when the
  empty state is the primary content of a panel.
- **`fill`** — `flex flex-col items-center justify-center h-full`; used inside
  containers that define their own height (e.g. the LineageGraph canvas area).
- **`inline`** — `p-4 text-center`; used inside scrollable lists where a full card
  would look over-engineered.
