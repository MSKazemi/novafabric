# NovaFabric v0.47.0 — Topology readability + evidence-grade gating primitives

**Released:** 2026-06-11 · **Status:** experimental · **Breaking changes:** none

## Summary

Merges the `arch/cluster-scale-v0.47` track into main and ships the topology
dashboard readability overhaul. Three feature groups, all additive.

## Topology dashboard: multi-view switcher

The live topology view (`nova serve --topology`) defaulted to the 3D (TV-5)
layer, which on real data (217 nodes / 87 clusters) rendered as an unreadable
label-soup hairball. The binary 2D/3D toggle is replaced by a five-mode view
switcher, defaulting to the most readable lens:

| Mode | What it shows |
|---|---|
| **Cluster** (default) | 2D force layout of cluster super-nodes; click to expand |
| **Call-graph** | 2D layered dagre layout — run → model → tool flow |
| **Treemap** | Area proportional to agent count |
| **Table** | Sortable, searchable exact cluster list |
| **3D (experimental)** | TV-5 orbit view; labels on hover/selection only |

Readability work: +/−/Fit zoom controls, fit-on-load, label declutter,
degree-0 singleton runs collapsed into a single "misc" super-node
(`collapse_isolated`, default on), deterministic Louvain (`random_state=42`).
New deps `@dagrejs/dagre` (MIT) and `d3-hierarchy` (ISC) — Tier A per ADR-0024.

## Statistical-significance primitives (gap-004, ADR-0080)

New `novafabric.eval.significance` (pure stdlib, no new dependency):

- `wilson_interval()` — binomial pass-rate confidence intervals;
- `sprt_bernoulli()` — a Wald SPRT returning a three-valued verdict
  (`ACCEPT_H0` / `ACCEPT_H1` / `CONTINUE`) so a regression gate can PASS,
  FAIL, or *defer for more evidence* instead of firing on noise.

Runs offline on stored capsules at zero token cost. Primitive only — does not
change `nova promote` defaults yet.

## Inference numerical-determinism facet (gap-007)

The Run Capsule's `env.lock` now records an optional `hardware.inference`
block (engine, engine_version, tensor/pipeline parallel sizes, dtype,
batch_size, attention_backend, seed, deterministic), populated best-effort
from the `NOVAFABRIC_INFERENCE_*` env-var contract. This captures the signal
that separates *environmental drift* from *genuine behavioral regression*
during replay/diff. Additive and backward-compatible — omitted entirely when
no inference env vars are set.

## Fixed: promote policy gate received no eval data

With a real `opa` binary on PATH, the default `promote_gate.rego` denied
**every** promotion ("eval score below threshold") because `promote_asset`
never passed `eval_score` into the policy input; without the binary, the
`NoopEngine` allowed everything — so neither path enforced the documented
gate. The service now passes the asset's latest eval score and `asset_type`,
and the default gate scopes the 0.90 threshold to **agents** (tools, datasets,
and prompts carry no eval requirement). 8 new Rego unit tests; `opa test`
22/22. The same wiring gap denied every `nova export-evidence`: the builder
validated `redaction-proof.json` + unsafe skips but passed neither to the
`evidence_export.rego` gate. It now passes the verified facts (an explicit
`--allow-unsafe-skips` waiver reports an effective count of 0).

If you maintain a custom policy bundle: `resource.asset_type`,
`resource.eval_score`, `resource.redaction_proof_present`, and
`resource.unsafe_skips` are now populated with real values.
