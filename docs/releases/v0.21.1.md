# v0.21.1 — ClickHouse + topology flags in experiment Docker stack

**Released:** 2026-05-19

## What changed

### Added

- `docker/docker-compose.experiment.yml` — ClickHouse service (`clickhouse/clickhouse-server:25.4`) for cost aggregation experiments, wired to the `nova serve` cost store via `NOVA_CLICKHOUSE_DSN`.
- `--tv5` and `--topology` flags passed through to `nova serve` in the experiment stack so the topology dashboard and TV-5 3D view start automatically.

## Upgrade

```bash
pip install novafabric==0.21.1
```

No migration required. Docker Compose experiment stack is opt-in.
