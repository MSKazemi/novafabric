# NovaFabric v0.90.0 — 2026-07-25

**Root-cause that follows the causal graph — and never over-claims.** ADR-0101's No-LLM
causal-graph attribution (NF-019) ships: reconstruct the span dependency graph of a failed
run and back-trace to the *earliest* failure on each causal path — deterministically, with
no LLM at debug time, and every candidate honestly marked unverified until a replay
confirms it. `experimental`. Full detail: `CHANGELOG.md` §[0.90.0].

## Highlights

### Causal-graph back-trace (ADR-0101 §NF-019)

`causal_root_candidates(capsule_dir)` complements the existing ordinal `attribute_failure`
(ADR-0084) with the graph-structural view. It:

- reconstructs the **span parent/child causal graph** from the recorded trace
  (`parent_span_id` → `span_id`);
- finds the **root failure nodes** — a failing node whose entire ancestor chain is
  error-free is a causal root; a failing node *downstream* of another failure is not,
  because its failure is already explained by the earlier one;
- ranks the roots deterministically (shallower graph depth first, then earliest rollout
  ordinal), and classifies each with the shared `AgentErrorTaxonomy`.

It runs **no LLM inference at debug time** — it is fast, cheap, and reproducible, and it is
exactly the ranked shortlist that will bound the (deferred) intervention-replay search.

### The verification gate holds (ADR-0101 §NF-022)

A static graph walk cannot *prove* causation — only a replay that flips the outcome can. So
every candidate this layer emits carries `verification = "unverified"` and is described as a
*ranked candidate, not a proven root cause*. The `CONFIRMED` / `REFUTED` verdicts stay the
exclusive output of the replay-backed `verify_hypothesis` (NF-017/018). The audit record can
never mistake a hypothesis for a proven root cause.

### Integrates with the existing diagnose core

The new module reuses `attribution.py`'s step loader, error detector, and taxonomy
classifier, and is exposed alongside the rest of the package:

```python
from novafabric.diagnose import causal_root_candidates

attr = causal_root_candidates("./capsules/run-123")
for c in attr.root_candidates:      # ranked, most-upstream first
    print(c.step_id, c.depth, c.taxonomy.value, c.verification)  # -> "unverified"
```

### Scope, honestly

A pure-code, offline, read-only analysis — no infrastructure, no new dependencies. The
deferred half is the *replay* confirmation: NF-017 (`nova diagnose --intervene`) and NF-018
(counterfactual root-cause search) need the ADR-0086 intervention-replay engine; NF-021
span-level claim auditing is future design. ADR-0101 moved `proposed → accepted` for this
static slice under delegated authority.
