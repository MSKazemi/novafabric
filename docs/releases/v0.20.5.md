# v0.20.5 — TV-5 sphere radius fix

**Released:** 2026-05-19

## What changed

Fix TV-5 Three.js sphere radius — nodes were rendered at `0.5` units which was sub-pixel at the default camera depth of 200. Changed to `5` so all agent/model/cluster spheres are clearly visible in the 3D topology view.

## Upgrade

```bash
pip install novafabric==0.20.5
```

No migration required.
