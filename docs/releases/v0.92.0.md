**Which answers were made with no evidence behind them?** ADR-0101's span-level claim

## Highlights

### The claim grounding audit (ADR-0101 §NF-021)

`audit_claims(capsule_dir)` reads a capsule's recorded span tree and classifies:

- a **claim** — a model/generation span, which asserts content;
- **evidence** — a tool/retrieval span, which grounds content.

A claim is **`grounded`** when at least one evidence span precedes it on the answer path
(the supporting evidence ids are carried on the finding), and **`ungrounded`** when no
evidence span comes before it. An ungrounded claim — a model output produced with zero
prior tool or retrieval grounding — is a **hallucination-risk finding**.

```python
from novafabric.diagnose import audit_claims

audit = audit_claims("./capsules/run-123")
for c in audit.claims:
    print(c.step_id, c.grounding.value, c.supporting_evidence_ids)
print(audit.n_ungrounded, "of", audit.n_claims, "claims ungrounded")
```

### Structural, deterministic, and honest about it

This is a **structural** signal, not a semantic truth judgment: it says "this answer had no
retrieval or tool call behind it on its causal path," which is exactly the shape of a
hallucination risk — but it never claims the answer is *false*. The audit is deterministic
and runs no LLM at debug time, so it is cheap, reproducible, and auditable. An ungrounded
claim is the kind of scored, sealed finding the eval layer (ADR-0099) consumes.

### Integrates with the diagnose core

It reuses the diagnose step loader and composes with the causal-graph attribution shipped
in v0.90.0 (`causal_root_candidates`) and the verified-hypothesis layer — one coherent
`novafabric.diagnose` surface for root cause *and* grounding.

### Scope, honestly

A pure-code, offline, read-only analysis — no infrastructure, no new dependencies. The
**conflicting**-claim half of NF-021 — flagging two claims that semantically contradict each
other — is a semantic comparison and remains future design; this slice ships the grounding
(supported / unsupported) half. ADR-0101's status now records the NF-019/NF-021/NF-022
static slices as accepted; the NF-017/018 intervention-replay half stays deferred on the
ADR-0086 engine.
