# NovaFabric v0.80.0 — 2026-07-25

**EU AI Act Article 12 — turn captured evidence into a record-keeping conformance
report.** The first of ADR-0107's seven standards exporters ships: it maps what a
run capsule already recorded to the Art. 12 record-keeping requirements, honestly
marked. `experimental`. Full detail: `CHANGELOG.md` §[0.80.0].

## Highlights

### `build_art12_report` (ADR-0107 §NF-090)

Article 12 of the EU AI Act (Regulation (EU) 2024/1689) requires high-risk AI
systems to automatically record events for traceability.
`compliance/export/euaiact_art12.py` is a **render-from-sealed-facts** exporter —
the same pattern as the Annex IV / NIS2 exporters — that reads a run capsule and
maps its captured evidence to the six Art. 12 requirements:

| Requirement | Evidence |
|---|---|
| automatic event recording | the capsule's model/tool-call + trace streams |
| period of use | manifest `created_at` / `finished_at` |
| traceability | the execution trace |
| input/output records | model-call records |
| tamper-evidence | a NovaSeal envelope, if present |
| retention | operator-declared retention period |

### Honest provenance, not certification

Each requirement is marked `complete` / `missing` **with an ADR-0197
`evidence_source`**, so a consumer can tell a capsule-verified fact from an
operator assertion:

- capsule-derived facts are `capsule_verified` with a re-performable reference when
  present, and `unverifiable` when absent — an expected-but-missing record (e.g.
  no seal ⇒ tamper-evidence unverifiable) is reported, never silently downgraded;
- operator-declared retention is `operator_asserted`.

The report has **no verdict field** — it renders evidence that *supports* an
Art. 12 assessment; a qualified human makes the determination. It runs offline
against a local capsule (ADR-0107 R-5): no server mode, no network.

### Scope, honestly

This ships the NF-090 exporter core (the programmatic `build_art12_report`). A
`nova export-*` CLI wrapper is a documented follow-on (deferred to avoid
regenerating the command registry mid-slice). ADR-0107's six sibling exporters
(Art. 72 PMM, Annex IV compiler, GPAI Art. 53 form, Art. 50 marking log, ISO
42001/42005 mapper, NIST GenAI/CSA mapper) remain future design. ADR-0107 was
accepted (NF-090 slice) under delegated authority.
