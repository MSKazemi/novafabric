# v0.6.4 — `nova api-proxy` (Path A first cut)

Released: 2026-05-09

This patch ships the long-queued **Path A** — a transparent HTTP proxy
for capturing LLM API calls from non-Python clients (Claude Code,
Cursor, Continue, custom Node/Go/Rust agents). The promotion ADR
([ADR-0026](../../design/adr/0026-api-proxy-promotion.md)) lands first and locks
scope.

## What's new

### `nova api-proxy`

```bash
nova api-proxy \
  --capsule-dir /path/to/.novafabric/runs/01HX... \
  --listen 127.0.0.1:8765 \
  --upstream-url https://api.openai.com
```

Then point any HTTP-speaking LLM client at the proxy:

```bash
export OPENAI_BASE_URL=http://127.0.0.1:8765
claude  # or cursor, or continue, or ...
```

Every POST forwarded to the upstream produces one `model-calls.jsonl`
record in the active capsule. Authorization headers and other request
context are forwarded through to the upstream unchanged — the proxy is
record-only, never mutating.

### Reuses every wire-level primitive built in v0.6

The api-proxy goes through the exact same pipeline the in-process
hooks use:

- **URL registry** classifies the request (`gen_ai.system: "openai"`,
  `"anthropic"`, `"aws.bedrock"`, etc.)
- **Body adapters** (C-3.3b) normalize Bedrock-Anthropic / Cohere /
  Titan / Llama bodies into OpenAI shape so `gen_ai.request.model`
  populates correctly
- **OTel GenAI extractor** (C-4) populates the full set of "Required
  when applicable" semconv fields — `temperature`, `top_p`, `top_k`,
  `max_tokens`, `stop_sequences`, `seed`, `frequency_penalty`,
  `presence_penalty`, `choice.count`
- **Response-side fields** (`gen_ai.response.id`, `gen_ai.response.model`)
  populated when the upstream returns parseable JSON

This means: a Claude Code session captured via api-proxy produces
records *byte-identical* in shape to a Python LangChain session captured
via the in-process anthropic SDK hook.

### Schema additions (additive — no breaking changes)

- `extensions.io.novafabric.capture_method = "api-proxy"` (parallel to
  existing `"hook"` and `"proxy"` for stdio MCP)
- `extensions.io.novafabric.transport_kind = "http"`
- `extensions.io.novafabric.streaming.{streamed, chunk_count}` when the
  upstream returned `Content-Type: text/event-stream`

### Streaming responses

OpenAI-style streaming (SSE delta streams) is **forwarded through to the
client unchanged** so the client's streaming UX is preserved. The record
captures the request fully and flags `streaming: true` with the chunk
count, but does NOT yet merge the deltas into a synthesized response
envelope. Full delta-merge is queued for v0.6.5 — it's structurally
different from MCP's match-by-id aggregation (already shipped in v0.6.3)
and warrants a focused round.

### Robustness

- **Upstream unreachable** (`httpx.ConnectError`, etc.): the proxy
  returns HTTP 502 with a synthesized JSON error body and records the
  attempt with `status=error`. Audit trail intact.
- **GET / DELETE / PUT requests** (e.g. `GET /v1/models` discovery):
  forwarded to the upstream but NOT recorded — these aren't LLM calls.
- **Bookkeeping failures** (writer errors): swallowed silently. The
  proxy is a transport, never a policy point.
- **Hop-by-hop headers** (Connection, TE, Transfer-Encoding, Host,
  Content-Length, etc.) stripped per RFC 7230 §6.1 before forwarding.

### Anti-patterns enforced (per ADR-0026)

- ✗ No TLS MITM with local CA. Permanently rejected.
- ✗ No request modification — bytes that go upstream are bit-identical
  to what the client sent. Tested explicitly.
- ✗ No phone-home / heartbeat.
- ✗ No multi-upstream routing (one proxy, one upstream).
- ✗ No response caching.

No migration. Capsules captured under v0.6.3 are unaffected.

## Try it (capture Claude Code)

```bash
# 1. Allocate a capsule directory
RUN=01$(date +%y%m%d-%H%M%S | tr -d '-')000000000000
mkdir -p .novafabric/runs/$RUN/{inputs,outputs}
touch .novafabric/runs/$RUN/{model-calls,tool-calls,trace,assets}.jsonl

# 2. Start the proxy in one terminal
nova api-proxy \
  --capsule-dir .novafabric/runs/$RUN \
  --listen 127.0.0.1:8765 \
  --upstream-url https://api.anthropic.com

# 3. In another terminal, run Claude Code via the proxy
ANTHROPIC_BASE_URL=http://127.0.0.1:8765 claude

# 4. Inspect the captured calls
jq '.["gen_ai.request.model"], .["gen_ai.response.id"]' \
  .novafabric/runs/$RUN/model-calls.jsonl
```
