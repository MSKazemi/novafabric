# v0.20.8 — Remove canvas background hack

**Released:** 2026-05-19

## What changed

Removed the `canvas { background: transparent }` workaround that caused 2D Sigma nodes to be hidden behind the Three.js WebGL canvas when both views were mounted. The 2D and 3D topology panels now render independently in separate containers.

## Upgrade

```bash
pip install novafabric==0.20.8
```

No migration required.
