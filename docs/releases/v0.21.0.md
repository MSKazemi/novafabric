# v0.21.0 — Auto-seed topology + cost per run in dashboard

**Released:** 2026-05-19

## What changed

### Added

- **Auto-seed topology on startup** — `nova serve --topology` now runs a background seed pass on startup, populating the topology view immediately without a manual `POST /api/topology/seed` call.
- **Cost per run in RunsTab** — each run row shows `total_cost_usd` formatted as `$X.XXXXXX` (USD) when ClickHouse cost data is available; displays `—` otherwise.
- **Cost summary card on HomeTab** — `HomeCostCard` shows aggregate cost across all runs for the current session, with a link to the full CostTab for breakdown.

## Upgrade

```bash
pip install novafabric==0.21.0
```

No migration required.
