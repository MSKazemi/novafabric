## Highlights

### The NIST GenAI + CSA Agentic mapper (ADR-0107 §NF-097)

NovaFabric already produces a NIST AI RMF 1.0 report (`NISTRMFReport`, with GOVERN / MAP /
MEASURE / MANAGE scores). NF-097 **extends** that evidence — it does not restate it — to
two overlay profiles that regulators and security teams increasingly ask for:

- the **NIST GenAI Profile** (NIST AI 600-1) four focus areas: **Governance**, **Content
  Provenance**, **Pre-deployment Testing**, **Incident Disclosure**. Each is anchored to a
  base RMF function, so a focus area is **auto-evidenced** when the base report already
  carries a score for its function — the GenAI overlay inherits the RMF evidence rather
  than asking you to re-supply it.
- the **CSA Agentic Profile** subcategory actions: agent identity, tool authorization,
  action governance, memory integrity, human oversight, incident response — mapped to the
  governance evidence present for the deployment.

`build_genai_csa_profile(rmf_report, present_evidence=…, declared=…)` marks each mapping
`evidenced` / `not_evidenced` / `declared` with an ADR-0197 `evidence_source`, reusing the
same criterion→evidence projection as every other NovaFabric control mapper. Evidence is
*bound*, never fabricated; an absent mapping is an honest gap.

### Scope, honestly

A pure-code, offline mapper — no infrastructure, no new dependencies — that integrates
with the shipped `NISTRMFReport`. A `nova export-*` CLI wrapper cohort surfacing these
exporters remains a deliberate follow-on (kept separate to manage the command-registry
regeneration in one focused change). ADR-0107 §NF-097 marked shipped under delegated
authority.
