# v0.12.1 — Asset Suggestion Engine (C-2)

Released: 2026-05-14

This release ships `nova suggest-register`, the Asset Suggestion Engine (C-2 from the
deferred backlog). It inverts the onboarding workflow: capture your agent runs first,
then let NovaFabric analyze the evidence and suggest which assets to register.

## What's new

### `nova suggest-register` CLI command

New command that analyzes captured run capsules and suggests unregistered assets:

**Three modes:**

- **Interactive** (default) — iterates over suggestions; prompts `y` (register),
  `n` (skip), `e` (open in `$EDITOR`), `s` (skip).
- `--draft-only` — writes draft YAML specs to `--output-dir` without registering.
- `--auto --min-confidence 0.8` — registers all suggestions above the confidence
  threshold without prompting.

**Confidence scoring:**

| Asset type | Confidence | Threshold |
|---|---|---|
| model | 1.0 | every observed call |
| tool | 0.8 | ≥ 2 calls across the capsule |
| agent | 0.7 | capsule.yaml present with `command` |

**Evidence-based draft YAML:** Each suggestion includes a ready-to-edit spec YAML
populated from observed data — model provider, artifact path, tool transport,
agent command, top model used, and tool list.

**Version normalisation:**
- `gpt-4o-2024-08-06` → name `gpt-4o`, version `2024.8.6`
- `claude-3-5-sonnet-20241022` → name `claude-3-5-sonnet`, version `2024.10.22`
- Ollama tag syntax `qwen3.6:35b` → name `qwen3.6-35b`, version `0.1.0`

**Provider detection** from `gen_ai.system` field — correctly identifies Ollama
models by system field rather than model name alone.

**Deduplication** across multiple capsules in `analyze_recent()` — merges suggestions
by `(asset_type, detected_name)`, sums call counts, takes max confidence.

**Registry filtering** — already-registered assets are excluded from suggestions.

### Post-capture hint

After every successful `nova capture`, a one-line hint is printed when unregistered
assets are detected:

```
→ Unregistered assets detected: 2 models  1 agent
  Run: nova suggest-register
```

Disable with `NOVAFABRIC_SUGGEST=0`.

### Dashboard smart empty state (Registry tab)

When the registry is empty, the Registry tab now:

1. Fetches `GET /api/runs/suggest-register` to scan recent capsules.
2. Shows a suggestion table with type, name, version, calls, and confidence.
3. Provides a "register →" button per row that opens a draft spec modal.
4. Falls back to "Register asset manually" if no suggestions are found.

### `GET /v0/runs/suggest-register` API endpoint

New server-mode endpoint with `capsule_limit` query param (default 10, max 50).
Returns `{"total_capsules_analyzed": N, "suggestions": [...]}`.
