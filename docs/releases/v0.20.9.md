# v0.20.9 — ClickHouse cost aggregation + KG auto-ingest

**Released:** 2026-05-19

## What changed

### Added

- **ClickHouse cost store** (`novafabric/cost/clickhouse_store.py`) — `ClickHouseCostStore` reads per-run costs from the `nova_cost_mv` AggregatingMergeTree materialized view. Set `NOVA_CLICKHOUSE_DSN=clickhouse+native://localhost/nova` to enable.
- **KG auto-ingest** — `nova serve` now calls `KGIngestionPipeline.ingest_run()` for each newly captured capsule when the Knowledge Graph backend is initialized (`--kg` flag).

## Upgrade

```bash
pip install novafabric==0.20.9
```

No migration required. ClickHouse and KG features are opt-in via environment variable / flag.
