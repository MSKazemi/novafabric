# v0.12.8 — Eval UX fixes + doc backfill

Released: 2026-05-14

Patch release. Three display-quality fixes in the registry browser eval results panel,
a documentation backfill for v0.12.6/v0.12.7 dashboard features, and two new `Makefile`
targets. No CLI changes, no schema changes, no API-breaking changes.

---

## What's new

### Eval results panel — null score renders as "—" (EU-1)

When an eval suite completes but produces no numeric score — for example, a binary
pass/fail suite that does not emit a `score` field — the database stores
`score_json: {"score": null}`. Previously the dashboard parsed `Number(null) = 0` and
displayed `0.00`, which was misleading (an asset with a null score looked like it had
scored zero).

From v0.12.8:

- `score: null` renders as a muted `—` instead of `0.00`.
- The colour is muted grey rather than red, so it does not appear as a failure
  indication when no numeric score exists.
- The `passed` flag (stored separately) still drives the ✓ / ✗ icon.

Affected component: `RegistryBrowser` eval results panel. The `EvalResult` type is
updated to `score: number | null` throughout.

### Eval results panel — suite name fallback (EU-2)

If a `suite_name` value is absent, empty, or otherwise blank in the database, the
suite name slot previously rendered as empty whitespace. From v0.12.8 it shows an
italic muted `(unknown suite)` label so the row is visually complete and clearly
distinguishable from a row with a real suite name.

### Eval runner — null score documented as a valid sentinel (EU-3)

Added a comment in `eval/runner.py` at the `score_json` insert site clarifying that
`{"score": null}` is intentional: the suite ran successfully but returned only a
pass/fail signal, not a numeric score. This prevents future contributors from
"fixing" it by substituting `0`.

not fully updated in the release commit. This release adds:

- **`docs/cli-reference.md`** — v0.12.7 additions section added under `nova serve`.

## Makefile — `bundle` and `serve-local` targets

Two new targets:

```makefile
make bundle        # builds web dashboard, rsyncs to src/novafabric/serve/static/
make serve-local   # runs bundle then nova serve --experimental
```

`make bundle` replaces the manual `cd web && npm run build && rsync …` sequence used
during development. `make serve-local` is the single command to rebuild the dashboard
and verify it in a browser.
