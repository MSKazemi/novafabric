# NovaFabric v0.37.0 — Compliance Dashboard Parity

**Released:** 2026-05-20
**Type:** Feature — dashboard parity for regulated-industry CLI surfaces

---

## Summary

v0.37.0 brings the `ComplianceTab` dashboard to full parity with the four
compliance-export CLI commands introduced in v0.35.0. All four panels surface
real data via new `nova serve` REST endpoints — no command-line required for
compliance officers reviewing RoPA, AI-SBOM, and NIST AI RMF outputs.

---

## What's New

### GDPR Art.30 RoPA Export panel

The `ComplianceTab` now includes a **RoPA Export** panel that mirrors
`nova export-ropa`. Operators can enter optional controller name and
contact fields and download the Record of Processing Activities JSON
document without leaving the dashboard. The panel also shows a completeness
status and highlights any missing fields.

**New endpoint:** `POST /api/compliance/export/ropa`

### AI-SBOM Export panel

The **AI-SBOM Export** panel mirrors `nova export-aibom`. It renders the
CycloneDX 1.6 software-bill-of-materials component list — type, name, version,
and description — inline in the browser.

**New endpoint:** `POST /api/compliance/export/aibom`

### NIST AI RMF Report panel

The **NIST AI RMF Report** panel mirrors `nova export-nist-rmf`. It displays
score bars for the four GOVERN/MAP/MEASURE/MANAGE functions, a risk-level
badge, and a missing-evidence list. Useful for quarterly AI-risk governance
reviews.

**New endpoint:** `POST /api/compliance/export/nist-rmf`

### AI-SBOM Coverage Status panel

The **AI-SBOM Status** panel mirrors `nova aibom status`. It shows total,
covered, and missing capsule counts, a coverage progress bar, and the CRA
compliance deadline (2026-09-11). Updated live on each dashboard load.

**New endpoint:** `GET /api/aibom/status`

## Testing

8 new integration tests in `tests/test_serve_compliance.py`:

- AIBOM file counting correctness

---

## Upgrade Instructions

No breaking changes. `nova serve` picks up the four new endpoints automatically
on restart. No database migrations required.

Install or upgrade:

```bash
pip install --upgrade novafabric
```
