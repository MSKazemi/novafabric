# NovaFabric v0.3.0 — Replay + Diff

## Summary

NovaFabric v0.3.0 adds **Replay** and **Diff** — the two primitives that make captured runs
useful beyond archival. Every capsule from v0.2 can now be replayed in forensic or mocked
mode, and any two capsules can be structurally compared with a single command.

---

## What's new

### `nova replay <capsule>`

Replay a captured run from its capsule.

```bash
# Forensic: read-only inspection — no subprocess, no network
nova replay .novafabric/runs/01HXAY7M5JZ8R7K4P9DPBYK2WX/ --mode forensic

# Mocked: re-run the command, all model and tool calls served from cache
nova replay .novafabric/runs/01HXAY7M5JZ8R7K4P9DPBYK2WX/ --mode mocked

# Dry-run: show what would be mocked vs. executed, then exit
nova replay .novafabric/runs/01HXAY7M5JZ8R7K4P9DPBYK2WX/ --dry-run
```

Output: `.novafabric/replays/<replay-ulid>/replay_result.yaml`

**Safety ladder** — explicit opt-in required to re-invoke any tool that mutates state:

| Flag | Permits |
|---|---|
| _(default, implicit `--mock-tools`)_ | nothing — stored responses only |
| `--allow-readonly` | `read-only` mutation class |
| `--allow-mutating` | `idempotent-write`, `non-idempotent-write` |
| `--allow-external-side-effects` | `external-side-effect` |
| `--allow-unknown-mutation` | `unknown` (full permissiveness) |

### `nova diff <capsule-a> <capsule-b>`

Structural diff between two run capsules.

```bash
nova diff .novafabric/runs/01HX.../  .novafabric/runs/01HY.../

# JSON output
nova diff cap-a/ cap-b/ --output-format json

# GitHub Actions annotations (inline PR diffs)
nova diff cap-a/ cap-b/ --output-format github-annotation

# CI gate: exit 1 if any changes detected
nova diff cap-a/ cap-b/ --assert-no-regressions
```

Compares:
- Environment fields (Python version, OS, arch)
- Model call pairs aligned by `span_id` then sequence position
- Tool call pairs aligned by `(tool_name, arg_hash)` then sequence position
- Output file hashes (`stdout.txt`, `stderr.txt`)

The existing `nova diff name@v1 name@v2` (asset registry diff) is unchanged.
Smart routing: args containing `@` → asset diff; path args → capsule diff.

### Mock model response reconstruction

In mocked mode, stored `model-calls.jsonl` responses are played back via the same
hook points used during capture. Both OpenAI and Anthropic SDK calls are intercepted
and return `SimpleNamespace` objects matching the SDK response structure.

### Environment compatibility check

Every replay (including forensic) compares the recorded `env.lock` against the current
runtime. Python version and OS mismatches are reported as warnings in `replay_result.yaml`.
Replay always proceeds; warnings do not abort.

## New CLI commands

| Command | Description |
|---|---|
| `nova replay <capsule> [--mode mocked\|forensic] [--dry-run] [flags]` | Replay a capsule |
| `nova diff <capsule-a> <capsule-b> [--output-format] [--assert-no-regressions]` | Diff two capsules |

---

## Output schemas

| File | Description |
|---|---|
| `.novafabric/replays/<id>/replay_result.yaml` | Replay outcome: mode, status, env warnings, mocked counts |
| (inline JSON) | `nova diff --output-format json` emits a structured diff report |

## Out of scope for this release

- Exact replay mode (requires deterministic local models)
- Semantic replay mode (judge model for meaning comparison)
- `nova inspect <capsule>` — planned for v0.3.1
- Tool call re-invocation (tool hooks not yet in the capture layer)
- Signed evidence bundles (v0.4)
