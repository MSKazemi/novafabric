# v0.20.1 — Stable token across restarts + blank-on-stale-token fix

**Released:** 2026-05-18

Two targeted fixes: `nova serve` now survives process restarts without
invalidating browser sessions, and a stale token no longer leaves the
dashboard silently blank.

---

## What changed

### Token stability (`serve/auth.py` + `cli/serve.py`)

`generate_token()` follows a priority chain:

1. `NOVAFABRIC_SERVE_TOKEN` env var — pin a fixed token in Docker / CI.
2. Existing `~/.novafabric/.serve-token` file — survive restarts without breaking sessions.
3. Fresh `secrets.token_urlsafe(32)` — unchanged behaviour when neither is present.

`nova serve` no longer deletes the token file on shutdown. On SIGTERM
(e.g. `docker restart`), the file is preserved so the next start reuses it.

### Blank dashboard on stale token (`DashboardApp.tsx`)

When `validateToken()` rejects the initial URL token, the ConnectPanel now
shows an actionable error instead of rendering blank:

> Token rejected — get the current token from the terminal:
> `cat ~/.novafabric/.serve-token`
