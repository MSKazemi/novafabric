# v0.28.0 — G-A Correctness Gap Closure

Released: 2026-05-19

Closes three confirmed correctness gaps (G-A3, G-A6, G-A7) from the May 19
nova-design gap audit. The remaining G-A gaps (G-A1, G-A2, G-A4, G-A5) were
already resolved before this release; G-B1/B2/B3 partial-implementation
items were also verified present.

---

## What's fixed

### G-A7 — ECDSA P-256 signer in Go collector

**File:** `collector/pkg/novaseal/signer.go`

Added `ECDSAP256Signer` and `NewECDSAP256Signer(keyID, *ecdsa.PrivateKey)`.
Signatures are DER-encoded `SEQUENCE { INTEGER r, INTEGER s }` (ASN.1 DER),
matching the default output of Python's `cryptography` library. SHA-256 is
applied to canonical bytes before signing, matching the Python prehash
convention.

Also added `ECDSASignatureFromBase64` (accepts 64–80 bytes for the full legal
DER range of P-256) and `GenerateECDSAP256KeyPair` for tests.

The existing `Ed25519Signer` is unchanged; both types satisfy the `Signer`
interface. 15 new tests; all 32 package tests green.

**Why it matters:** The Python NovaSeal service rejects Ed25519 keys with
"not an EC private key". Cross-language signature verification was silently
failing before this fix.

### G-A3 — DLQ wired into HPC leaf spool store

**File:** `collector/internal/hpc/leaf_spool_store.go`

`NewSpoolStore()` now reads `NOVA_DLQ_DIR` at startup. When set, it
instantiates `spool.DLQ` and attaches it via `sp.SetDLQ()`. Events dropped
under backpressure are routed to a daily-rotated JSONL file under that
directory instead of being silently lost.

`SpoolStore.Close()` now closes the DLQ; `SpoolStore.DLQDir()` returns the
configured path (empty string if no DLQ).

The DLQ struct and `SetDLQ()` were already implemented (in `dlq.go` and
`spool.go`) but were never instantiated in production setup.

### G-A6 — Manifest hash-chain verified by default on `get_capsule()`

**File:** `src/novafabric/object_capsule_store/client.py`

`ObjectCapsuleStore.get_capsule()` default changed from `verify_chain=False`
to `verify_chain=True`. Every read now walks the full `prev_commit_hash` chain
(OQ-027), raising `ChainIntegrityError` if any link is broken or missing.

Performance-critical callers (e.g., bulk rebuild paths) can opt out with
explicit `verify_chain=False`.

`verify_capsule_chain()` is retained as a self-documenting alias; it now
calls `get_capsule(verify_chain=True)`, which is the same as the default.

## Upgrade notes

- No breaking changes to Python public API.
- `get_capsule()` callers that relied on the old `verify_chain=False` default
  will now perform a chain walk. In practice this is fast (O(chain length));
  call `get_capsule(verify_chain=False)` explicitly if you need to skip it.
- Go collector users: set `NOVA_DLQ_DIR=/path/to/dlq` to activate the
  dead-letter queue. No change in behavior if the env var is absent.
