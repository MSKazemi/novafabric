# NovaFabric v0.63.0 — 2026-07-17

The enterprise-audit **second slices** release. Building on v0.62.0's first
slices of ADRs 0191–0195, this release completes the alerting, API-key, and
SDK surfaces to a genuinely usable state and surfaces them in the dashboard.
Everything new is `experimental`. Full detail: `CHANGELOG.md` §[0.63.0].

## Highlights

### Operational alerting is now end-to-end (ADR-0192)
- **Notification adapters** — Slack (incoming-webhook), PagerDuty (Events API v2,
  severity-mapped), and email (stdlib SMTP to a user-configured relay) render the
  canonical alert over the same webhook core. Selected per endpoint; zero new
  dependencies; payload shapes fixture-pinned.
- **Dashboard Alerts tab** — a severity-coded feed of operational alerts and their
  delivery outcomes (`GET /api/alerts/recent`), with stat tiles, per-row
  severity/outcome/endpoint, live refresh, and an honest "not configured" banner.

### API-key lifecycle completed (ADR-0193)
- **`nova server api-key rotate`** — bounded-overlap rotation (predecessor
  auto-revokes at verify time; zero-downtime credential swap) plus coarse
  `last_used_at` tracking.
- **`/v0/api-keys` REST resource** — RBAC-gated create/list/revoke/rotate.
- **Admin console API-keys panel** — a read-only, secret-free view of server keys
  (`GET /api/admin/api-keys`) in the dashboard Admin tab.

### TypeScript SDK helpers (ADR-0194)
- `submitScore()` and `otlpTraceEndpoint()` land; a path-scoped `sdk-ts` CI lane
  runs tsc + vitest + the openapi drift gate. Still zero runtime dependencies.

## Upgrade notes

- All new surfaces are additive and off/opt-in by default. Outbound alerting stays
  OFF until a `NOVA_ALERTS_*` endpoint is configured. API keys are created
  explicitly; no key exists until you create one.
- The `nova server api-key` store gains three columns via in-place
  `ALTER TABLE ADD COLUMN` migration on first use — no manual step.
- Security-Architect review remains a **pre-production blocking condition** for
  ADRs 0178/0184/0185/0186, and is recommended for 0193 (credential + key surface).
