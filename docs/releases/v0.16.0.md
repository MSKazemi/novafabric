# v0.16.0 — Governance, Audit, Judge Framework, HPC Expansion, NovaSeal Hardening

Released: 2026-05-17

This release is a large batch that closes 11 implementation gaps identified in a
full audit of the nova-design companion repository against the novafabric codebase.
All features work locally without server mode.

## What's new

### Risk-tier classification (`nova classify`)

New `src/novafabric/governance/` module with `RiskTierClassifier`, three regulatory
vocabularies (EU AI Act Annex III Reg. 2024/1689, NIST AI RMF AI 600-1, OMB M-24-10),
and a 4-stage classification pipeline (prohibited → Annex III high-risk → limited →
minimal).

```bash
nova classify run --system system.yaml           # classify from YAML
nova classify run --system system.yaml --vocabulary nist-ai-rmf/1.0.0
nova classify from-capsule .novafabric/runs/01HX...
nova classify list-vocabularies
```

Exit code 1 on prohibited tier. ADR-0056 implemented.

### Compliance audit engine (`nova audit`)

New `src/novafabric/compliance/audit/` module with `AuditEngine`, `AuditProfile`, and
six YAML-driven regulatory profiles:

| Profile | Standard |
|---|---|
| `nist-ai-rmf` | NIST AI Risk Management Framework |
| `eu-ai-act-high-risk` | EU AI Act Annex I high-risk system controls |
| `gdpr` | GDPR Articles 5, 13, 17, 22, 25, 32, 35 |
| `soc2-type2` | SOC 2 Type II Trust Service Criteria |
| `iso42001` | ISO/IEC 42001 AI Management System |
| `scientific-reproducibility` | ML reproducibility best practices |

```bash
nova audit map --profile nist-ai-rmf          # list evidence checkers
nova audit report --capsule .novafabric/runs/01HX... --profile gdpr
nova audit verify --capsule ... --profile eu-ai-act-high-risk --min-coverage 0.8
nova audit bundle --capsule ... --output audit.zip
nova audit coverage --capsule ...
```

`nova audit verify` exits 1 when coverage < `--min-coverage`.

### Examiner-mode exporters (`nova export-examiner`)

Three new regulatory archive formats:

```bash
nova export-examiner bagit .novafabric/runs/01HX... --output run.bagit.zip   # RFC 8493
nova export-examiner pccp .novafabric/runs/01HX... --output pccp.zip          # FDA 21 CFR Part 11
nova export-examiner iso42001 .novafabric/runs/01HX... --output iso42001.zip  # ISO/IEC 42001
```

### PBS + LSF HPC runners

Two new HPC job-scheduler runners:

- `PBSRunner` — PBS/Torque: `qsub` submit, `qstat` poll, `qdel` cancel
- `LSFRunner` — IBM Spectrum LSF: `bsub` submit, `bjobs` poll, `bkill` cancel

```python
from novafabric.runners import PBSRunner, LSFRunner
```

### LangGraph / AutoGen / CrewAI / DSPy framework adapters

Four drop-in capture wrappers in `src/novafabric/adapters/`:

```python
from novafabric.adapters.langgraph import wrap       # wrap(graph) → _WrappedGraph
from novafabric.adapters.autogen import wrap_agent   # patches initiate_chat
from novafabric.adapters.crewai import wrap_crew     # patches kickoff
from novafabric.adapters.dspy import wrap_program    # patches forward
```

All adapters are fail-open — capture errors never propagate to the wrapped framework.

### Extended capture event types

Three new structured event models in `src/novafabric/capture/events.py`:

- `FileEvent` — path, mode, size\_bytes, sha256
- `NetworkEvent` — url, method, status\_code, latency\_ms, is\_ai\_api
- `HumanApprovalEvent` — actor, decision, tool\_name, capsule\_id

Thread-safe `EventRecorder` singleton with 14-provider AI API classifier.
All capture errors are fail-open (logged, never raised).

### Judge framework

New `src/novafabric/judge/` module providing multi-judge evaluation with consensus
and OPA policy gating:

| Class | Description |
|---|---|
| `EmbeddingJudge` | Cosine similarity via `sentence-transformers`; Jaccard fallback |
| `NumericalJudge` | Exact match, regex, numeric range, length range |
| `LLMJudge` | OpenAI-compatible self-consistency (K=3 majority vote) |
| `JudgeFramework` | Fan-out orchestrator; `aggregate_judgments()` with Fleiss/Cohen kappa |
| `judgment_to_rego_input()` | OPA adapter; pairs with `judge_gate.rego` |

`judge_gate.rego` denies when kappa < 0.6 or consensus verdict is `fail`.

### NovaSeal: SigningIntent + RFC 3161 nonce replay protection

- `SigningIntent` enum (`AUTHORED / REVIEWED / APPROVED / WITNESSED / VERIFIED`)
  added to every DSSE envelope. `create_envelope(intent=...)`, `VerificationResult.signing_intent`.
- RFC 3161 nonce replay protection: DER byte-scanner in `_rfc3161.py` extracts the
  nonce from the TSR response; `TimestampError("nonce mismatch")` raised on mismatch.

### GCS WORM adapter (complete)

`src/novafabric/object_capsule_store/worm/gcs.py` now fully implements the 8-method
WORM interface using Google Cloud Storage per-object retention in `LOCKED` mode.
Previously a stub.

### NovaSeal proof-report sealing (G-CROSS-004 / FR-03)

`nova subject-proof` now writes a `.seal.json` NovaSeal bundle alongside the GDPR
Art.17 proof report.
