The wow moment

Click the Exact tab. It's greyed out — and the explanation is honest: exact replay of remote LLMs is impossible to promise. Many tools claim to do it anyway. We mark it disabled and document why.

On your machine

nova replay <run-id> --mode mocked
nova diff <run-a> <run-b>
nova diff <run-a> <run-b> --output github-annotation

The CLI is the canonical interface. This site is documentation — a showcase that explains what NovaFabric does, using a single baked-in example. It does not read your data and does not phone home.

pip install novafabric → nova capture python your_agent.py
