The wow moment

Click "Validate against schema" in the header. Your browser compiles run-capsule.schema.json — the same JSON Schema 2020-12 file committed under /schemas/ in the repo — and validates the fixture against it. Green check is real, not marketing.

On your machine

nova capture python your_agent.py
nova inspect <run-id>
nova validate <run-id>

The CLI is the canonical interface. This site is documentation — a showcase that explains what NovaFabric does, using a single baked-in example. It does not read your data and does not phone home.

pip install novafabric → nova capture python your_agent.py
