Primitive 04 — interactive demo

Lineage graph

Every run, asset, and artifact is a node. Every consumed,produced, replayed_from, or evaluated_byrelationship is an edge. Three toolbar modes mirror the CLI:nova lineage provenance,blast-radius,replay-chain.

The wow moment

Click code-review-promptand switch to Blast radius. You can see, in two seconds, every production run that depends on that prompt. Change it, and you know exactly what will be affected. No greps. No tribal memory.

On your machine

The same queries are available on the CLI. Output is JSON or text; no graph required.

nova lineage provenance run:01KR5SQZPDGTKE3MDP3ZRX8WP1
nova lineage blast-radius asset:code-review-prompt@0.1.0
nova lineage replay-chain run:01KR5SQZPDGTKE3MDP3ZRX8WP1

The CLI is the canonical interface. This site is documentation — a showcase that explains what NovaFabric does, using a single baked-in example. It does not read your data and does not phone home.

pip install novafabric→nova capture python your_agent.py
