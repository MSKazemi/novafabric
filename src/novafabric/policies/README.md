# `novafabric.policies`

**Policy definitions / data** — capture-level policy configuration
(`capture_level.py`) and bundled Rego under `novafabric/`.

**Not to be confused with [`novafabric.policy`](../policy/) (singular) — the
policy engine that evaluates requests.** `policies` = the rules/levels;
`policy` = the OPA/noop engine that applies them.
